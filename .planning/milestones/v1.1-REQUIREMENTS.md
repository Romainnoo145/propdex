## v1.1 Requirements

Requirements for production hardening. Each maps to roadmap phases.

### Testing

- [x] **TEST-01**: Auth module has unit tests covering registration, login, token refresh, and password reset — Phase 7, 20 unit tests
- [x] **TEST-02**: Auth module has integration tests verifying full request flows against the database — Phase 7, 31 integration tests
- [x] **TEST-03**: API client module (httpx) has unit tests for BAG, PDOK, DSO, and RCE clients with mocked responses — Phase 8, 55 unit tests
- [x] **TEST-04**: Cache manager has integration tests verifying JSONB cache read/write/TTL/invalidation against the database — Phase 8, 20 integration tests
- [x] **TEST-05**: Zoning and monument aggregators have unit tests covering data transformation and error handling — Phase 9, 43 unit tests
- [x] **TEST-06**: Zoning and monument aggregators have integration tests verifying full aggregation flows — Phase 9, 9 integration tests
- [x] **TEST-07**: AI document parsing module has unit tests for Claude API client and PDF processing with mocked responses — Phase 9, 14 unit tests
- [x] **TEST-08**: Report CRUD operations have integration tests covering save, list, search, and delete against the database — Phase 10, 15 integration tests + 12 HTTP tests (Phase 11)
- [x] **TEST-09**: PDF export has unit tests verifying template rendering and WeasyPrint output — Phase 10, 9 unit tests + 2 HTTP tests (Phase 11)
- [x] **TEST-10**: Multi-tenant isolation is verified by integration tests confirming cross-organization data is never leaked — Phase 10, 9 service + 2 HTTP isolation tests

### Security

- [x] **SEC-01**: Database connection uses app_role with enforced RLS policies instead of superuser bypass — Phase 6, fail-closed NULLIF policies on 7 tables

### Configuration

- [x] **CFG-01**: Single .env file in backend/ with root .env removed or symlinked — Phase 6, root .env deleted
- [x] **CFG-02**: Freshness threshold is configurable per organization (not hardcoded 24h) — Phase 6, Organization.freshness_threshold_hours with min enforcement

### Infrastructure

- [x] **INFRA-01**: ARQ worker lifecycle is integrated with main application startup/shutdown — Phase 9, 3 lifecycle tests

### Documentation

- [x] **DOC-01**: Phase 1 has a formal VERIFICATION.md confirming all original requirements were met — Phase 7, 01-VERIFICATION.md created
