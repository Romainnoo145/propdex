# Requirements: M050.5 Feature Tiering & Demo Lockdown

**Defined:** 2026-05-16
**Driver:** Phase 04.2 (commit `0d4a4864`) dichtte alleen het `score_breakdown` lek. De échte exposure is dat demo-users de volledige feature-surface zien — kaart + scans + parcel-details + scoring + alle waardevolle modaal-content. Een concurrent meldt zich aan en heeft binnen een uur een blueprint van het hele product. M050.5 maakt de demo een trailer ipv blueprint.

**Goal:** Drie product-tiers (`demo` / `paid` / `superadmin`) met server-side enforcement + frontend `<TierGate>` wrapper + Pro-badge UX. Demo ziet 1 gemeente (Venlo), totaalscore, factor-namen + omschrijvingen. Alle waarde-toevoegende features (eigendom, marktsignalen, opportunities, building metrics, subsidies, jurisprudentie, rapporten, favorieten, custom-profiel, document-upload) achter Pro-gate.

**Parallel-runnable met:** M049 (admin hub — geen overlap), M050 (Vindsubsidies — coordinatie: M050 bouwt feature mét tier-gate ingebakken).

## v1 Requirements

### Tier (infrastructure)

- [ ] **TIER-01**: `Organization.tier` enum-veld (`demo` / `paid` / `superadmin`) — default `demo` voor nieuwe orgs
- [ ] **TIER-02**: `get_current_org_tier` FastAPI dependency exposeert tier aan routers (cached per request)
- [ ] **TIER-03**: `requires_tier(min_tier)` helper — returnt 403 bij onvoldoende tier, gebruikt voor endpoint-level gating
- [ ] **TIER-04**: `tier_redacts(payload, tier, feature_keys)` helper — strip JSON-velden uit response per tier (gebruikt voor inline-gating in shared endpoints zoals `at-point`)
- [ ] **MIG-01**: Alembic migratie voegt `tier` kolom toe; bestaande orgs met superuser-account → `superadmin`, anderen → `demo`; paid-tier vullen we handmatig

### API (backend feature gates)

- [ ] **API-01**: `GET /api/scans/parcels/{id}/eigendom` requires `paid+` — demo krijgt 403
- [ ] **API-02**: `vacancy_signal`, `vacancy_confidence`, `vacancy_reasons`, `vacancy_model_version`, `market_signals` gestript uit scan responses voor `demo`
- [ ] **API-03**: `opportunity_signals` + `building_metrics` gestript voor `demo`
- [ ] **API-04**: Subsidies endpoints (`/api/subsidies/*`) requires `paid+`
- [ ] **API-05**: Jurisprudence endpoints (`/api/jurisprudence/*`) requires `paid+`
- [ ] **API-06**: Reports endpoints (`/api/reports/*`) requires `paid+`
- [ ] **API-07**: Favorites endpoints (`/api/favorites/*`, `/api/portfolio/*`) requires `paid+`
- [ ] **API-08**: Custom score-profile endpoints (factor pins, weight overrides) requires `paid+`
- [ ] **API-09**: Document upload endpoints (`/api/documents/*`, `/api/policy-documents/*`) requires `paid+`
- [ ] **API-10**: Scan creation endpoints requires `paid+` — demo kan alleen bestaande scans bekijken
- [ ] **API-11**: Tile endpoint + at-point restricts to Venlo (`gemeente_code='GM0983'`) voor `demo` tier — andere gemeenten krijgen 403/404

### UI (frontend gates)

- [ ] **UI-01**: `<TierGate feature="..." minTier="paid">` wrapper-component met Pro-badge fallback + lock-icon (Amber accent)

- [ ] **UI-09**: Jurisprudentie-content gegated
- [ ] **UI-10**: "Rapport genereren" button shows Pro-badge disabled state
- [ ] **UI-11**: Favorites/Portfolio nav-pill toont Pro-badge voor demo
- [ ] **UI-12**: Settings → custom score-profiel sectie hidden voor demo
- [ ] **UI-13**: Document upload buttons (in workspace, parcel detail) hidden voor demo

## v2 Requirements (deferred)

### Self-service upgrade flow

- **UPGD-01**: Demo user kan op Pro-badge klikken → upgrade-form ("Vraag Pro-toegang aan", emailt info@klarifai.nl)
- **UPGD-02**: Superadmin panel om tier-upgrades handmatig toe te kennen
- **UPGD-03**: Email-notificatie naar user wanneer tier wordt gepromoot

### Trial period

- **TRIAL-01**: `tier=trial` met expiry-date (e.g. 14 dagen full access)
- **TRIAL-02**: Automatic demotion naar `demo` bij expiry
- **TRIAL-03**: Visual countdown banner voor trial-users

## Out of Scope

| Feature | Reason |
|---------|--------|
| Stripe / payment integration | I-01 staat al apart op de roadmap; deze milestone gaat over de gate-infrastructuur, niet over geld innen |
| Per-feature granular tiers (Bronze/Silver/Gold) | 3 tiers volstaat voor MVP; verfijning kan later |
| Per-user tier (binnen org) | Tier is org-level; binnen één org delen users dezelfde tier |
| Tier-based rate-limits per endpoint | Per-org tile-limit uit Phase 04.2 volstaat; granulair quoting komt bij payment-milestone |
| Watermarking demo-screenshots | Cosmetic, niet effectief tegen serieuze copy-cats |
| Geo-IP-based demo restrictions | Onderhoudsoverhead, omzeilbaar via VPN |
