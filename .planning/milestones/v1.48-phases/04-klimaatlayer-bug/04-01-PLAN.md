<objective>
Phase 4 ships a single-line React fix for BUG-01 (KlimaatLayer ghost verdict on gemeente switch) plus three Storybook play-function stories that pin the three success criteria from the roadmap.

Purpose: The KlimaatLayer currently shows stale gemeente-A data after the user clicks gemeente B because `<GemeenteContextPanel>` is reused across gemeente transitions — its internal `activeLayer` useState survives the prop change, and the React Query cache (5-min staleTime on `useGemeenteProfile`) serves A's verdict before B's fetch resolves. Adding `key={activePanel.code}` to the render call-site in `map.tsx` forces React to unmount the old instance and mount a fresh one on every gemeente switch, atomically resetting all internal state and detaching old query subscriptions.

Output:
- `frontend/src/routes/_authenticated/map.tsx` — `key={activePanel.code}` added to `<GemeenteContextPanel>` (one-line fix)
- `frontend/src/stories/gemeente/KlimaatLayer.stories.tsx` — three play-function stories: PropSwap (SC#1+SC#2), RapidSwitch (SC#3), NoStaleDataOnSwitch (regression pin for the staleTime=5min scenario)
</objective>

```tsx
function KlimaatLayerSwitcher({ options, preloadAll = false }: { options: string[]; preloadAll?: boolean }) {
  const [current, setCurrent] = useState(options[0])
  const fixture = GEMEENTE_FIXTURES[current]
  return (
    <div className="flex flex-col gap-2 p-4">
      <div className="flex gap-2">
        {options.map((g) => (
          <button
            key={g}
            type="button"
            onClick={() => setCurrent(g)}
            aria-label={`switch-to-${g.toLowerCase()}`}
            className="px-3 py-1 rounded bg-amber-500 text-white text-sm"
          >
            {g}
          </button>
        ))}
      </div>
      <div className="h-[600px] w-[420px] bg-white rounded-[24px] overflow-hidden">
        <KlimaatLayer
          key={current}
          gemeenteNaam={current}
          gemeenteCode={fixture.code}
        />
      </div>
    </div>
  )
}
```
