Create a new file following the EXACT pattern of `MonitoredWijkOverlay.tsx`. This module provides functions to add/remove/update a GeoJSON overlay for wijken that have completed scans.

Constants:
- `SCANNED_SOURCE_ID = 'scanned-wijken'`
- `SCANNED_FILL_LAYER = 'scanned-wijken-fill'`
- `SCANNED_LINE_LAYER = 'scanned-wijken-line'`

Export three functions:

1. `addScannedWijkHighlight(map, wijkGeojson, scannedWijkNames)`:
   - Guard: `if (map.getSource(SCANNED_SOURCE_ID)) return`
   - Filter `scannedWijkNames` to remove falsy values (`filter(Boolean)`)
   - Build `Set` from filtered names
   - Filter `wijkGeojson.features` where `feature.properties?.statnaam` is in the set
   - If no matching features, return early (do not add empty source)
   - Add GeoJSON source with filtered features
   - Determine `beforeLayer`: use `'wijk-fill'` if that layer exists, else `undefined`
   - Add fill layer with amber color: `'fill-color': 'rgba(245, 158, 11, 0.25)'`, `'fill-antialias': true`
   - Add line layer with amber border: `'line-color': 'rgba(245, 158, 11, 0.7)'`, `'line-width': 2`
   - Both layers inserted before `beforeLayer` to render BELOW wijk boundaries

2. `removeScannedWijkHighlight(map)`:
   - Remove line layer, then fill layer, then source (check existence before each removal)

3. `updateScannedWijkHighlight(map, wijkGeojson, scannedWijkNames)`:
   - Call `removeScannedWijkHighlight`, then `addScannedWijkHighlight`

Use `import type maplibregl from 'maplibre-gl'` for the Map type parameter.

Amber is chosen to visually distinguish from:
- Unscanned wijken: emerald green (#10b981) from WijkBoundariesLayer
- Monitored wijken: blue (rgba(59,130,246,0.15)) from MonitoredWijkOverlay
