2. Set `activeScanId` to the URL value
3. Clear `scan_id` from URL with `navigate({ to: '/map', search: {}, replace: true })` to prevent re-triggering on hot reload

Place this effect after the existing `handledReportRef` pattern (similar logic). Extract `scan_id` as `urlScanId` from `Route.useSearch()` alongside existing destructured params.

```typescript
const { postcode, huisnummer, reportId, panel, scan_id: urlScanId } = Route.useSearch()

// Restore scan context from /resultaten navigation
useEffect(() => {
  if (!urlScanId || activeScanId) return
  setActiveScanId(urlScanId)
  // Clear from URL to prevent re-trigger

}, [urlScanId, activeScanId, navigate])
```
