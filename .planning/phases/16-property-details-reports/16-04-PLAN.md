  <action>
    Add report API functions to the EXISTING `frontend/src/lib/api.ts` file. Do NOT create a new file. Follow the existing `apiFetch` pattern with Bearer token auth.

    Add a new constant: `const REPORTS_BASE = '/api/reports'`

    **Functions to add:**

    1. `fetchReports(filters: ReportFilters, accessToken: string | null): Promise<ReportListResponse>`
       - GET `/api/reports` with query params from filters
       - Build URLSearchParams from non-undefined filter values
       - Use `apiFetch<ReportListResponse>`

    2. `fetchReport(reportId: string, accessToken: string | null): Promise<ReportDetailResponse>`
       - GET `/api/reports/{reportId}`
       - Use `apiFetch<ReportDetailResponse>`

    3. `saveReport(request: ReportSaveRequest, accessToken: string | null): Promise<ReportDetailResponse>`
       - POST `/api/reports`
       - Body: JSON.stringify(request)
       - Use `apiFetch<ReportDetailResponse>`

    4. `deleteReport(reportId: string, accessToken: string | null): Promise<void>`
       - DELETE `/api/reports/{reportId}`
       - For void response, use a custom fetch (apiFetch expects JSON). Handle by checking response.ok.
       - Alternative: adjust apiFetch or create a separate function.

    5. `fetchReportFreshness(reportId: string, accessToken: string | null): Promise<ReportFreshnessResponse>`
       - GET `/api/reports/{reportId}/freshness`
       - Use `apiFetch<ReportFreshnessResponse>`

    6. `refreshReport(reportId: string, accessToken: string | null): Promise<ReportDetailResponse>`
       - PUT `/api/reports/{reportId}/refresh`
       - Use `apiFetch<ReportDetailResponse>`

    7. `exportReportPDF(reportId: string, accessToken: string | null): Promise<Blob>`
       - GET `/api/reports/{reportId}/export/pdf`
       - This returns a PDF blob, NOT JSON. Use raw fetch with credentials + Authorization header.
       - Return `response.blob()`

    8. `fetchCities(accessToken: string | null): Promise<string[]>`
       - GET `/api/reports/cities`
       - Use `apiFetch<string[]>`

    Import all needed types from `@/lib/types/report`.

  <action>
    1. **Create `frontend/src/hooks/useReports.ts`:**

       Import from `@tanstack/react-query`: useQuery, useMutation, useQueryClient
       Import from `@/lib/auth/useAuth`: useAuth
       Import API functions from `@/lib/api`
       Import types from `@/lib/types/report`

       **Hooks to create:**

       a. `useReports(filters: ReportFilters = {})`
          - Uses `useQuery` with queryKey `['reports', filters]`
          - Calls `fetchReports(filters, accessToken)`
          - `staleTime: 5 * 60 * 1000` (5 minutes)
          - `enabled: !!accessToken` (only fetch when authenticated)

       b. `useReport(reportId: string | null)`
          - Uses `useQuery` with queryKey `['report', reportId]`
          - Calls `fetchReport(reportId!, accessToken)` — only when reportId is non-null
          - `enabled: !!reportId && !!accessToken`
          - `staleTime: 5 * 60 * 1000`

       c. `useSaveReport()`
          - Uses `useMutation`
          - `mutationFn`: calls `saveReport(request, accessToken)`
          - `onSuccess`: invalidate `['reports']` queries (so list refreshes)
          - Returns mutation object

       d. `useDeleteReport()`
          - Uses `useMutation`
          - `mutationFn`: calls `deleteReport(reportId, accessToken)`
          - `onSuccess`: invalidate `['reports']` queries

       e. `useReportFreshness(reportId: string | null)`
          - Uses `useQuery` with queryKey `['report-freshness', reportId]`
          - Calls `fetchReportFreshness(reportId!, accessToken)`
          - `enabled: !!reportId && !!accessToken`
          - `staleTime: 10 * 60 * 1000` (10 minutes — don't check too often)

       f. `useRefreshReport()`
          - Uses `useMutation`
          - `mutationFn`: calls `refreshReport(reportId, accessToken)`
          - `onSuccess`: invalidate both `['report', reportId]` and `['reports']`

       g. `useExportPDF()`
          - Uses `useMutation`
          - `mutationFn`: calls `exportReportPDF(reportId, accessToken)`
          - Returns the Blob for download handling by the caller

       h. `useCities()`
          - Uses `useQuery` with queryKey `['report-cities']`
          - Calls `fetchCities(accessToken)`
          - `staleTime: 30 * 60 * 1000` (30 minutes — cities rarely change)

    2. **Create `frontend/src/hooks/useRecentViewed.ts`:**

       Follow the research document's Pattern 4 exactly:

       ```typescript
       interface RecentItem {
         id: string           // nummeraanduiding_id
         report_name: string  // "Straat Huisnummer"
         postcode: string
         woonplaats: string
         viewed_at: number    // Date.now() timestamp
       }
       ```

       - `STORAGE_KEY = 'propdex_recent_viewed'`
       - `MAX_RECENT = 10`
       - Load from localStorage on mount (useEffect with empty deps)
       - `addRecentItem(item: Omit<RecentItem, 'viewed_at'>)`:
         - Remove existing entry with same id (dedup)
         - Prepend new item with current timestamp
         - Slice to MAX_RECENT
         - Persist to localStorage (try/catch for quota errors)
       - `clearRecent()`: Clear localStorage key and reset state
       - Return `{ recent, addRecentItem, clearRecent }`

       Export both the hook and the `RecentItem` type.
