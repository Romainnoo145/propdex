    1. **Create `frontend/src/components/reports/PDFExportModal.tsx`:**

       Tier 3 modal for PDF export options.

       Props:
       - `reportId: string | null` — saved report ID (if report is saved). If null, report must be saved first.
       - `propertyData: PropertyReportResponse | null` — current property data (for saving if needed)
       - `isOpen: boolean`
       - `onClose: () => void`

       Implementation:
       - Uses `<Modal>` primitive from Plan 01
       - Import `{ toast }` from 'sonner'
       - Import `useExportPDF` and `useSaveReport` from hooks

       **Content:**
       - Title: "Rapport exporteren als PDF"
       - If no reportId (unsaved): Show message "Rapport moet eerst worden opgeslagen" with save button
       - If reportId exists: Show export options

       **Export options (simple radio/checkbox list):**
       - "Volledig rapport" — all sections (default, checked)
       - "Alleen Kadaster" — kadaster section only
       - "Inclusief bestemmingsplankaart" — checkbox
       Note: Backend PDF endpoint may not support section filtering yet. For now, always export full report. Show the options UI but send full export request.

       **Export flow:**
       a. User clicks "Exporteren" button
       b. Show loading toast: `toast.loading('PDF wordt gegenereerd...')`
       c. Call `exportPDF.mutate(reportId)` — this returns a Blob
       d. On success: Create download link with `URL.createObjectURL(blob)`, trigger download with `<a>` click, revoke URL, update toast to success: `toast.success('PDF download gereed!')`
       e. On error: `toast.error('PDF export mislukt')`
       f. Close modal on success

       **Button:** "Exporteren" — `bg-white/15 hover:bg-white/25 text-white rounded-lg px-4 py-3 w-full font-medium`

    2. **Create `frontend/src/components/reports/SaveReportFlow.tsx`:**

       Encapsulates the save logic used by the drawer header.

       This is a custom hook + small UI component pattern.

       **Create `useSaveReportFlow` hook:**
       - Takes `propertyData: PropertyReportResponse | null`
       - Uses `useSaveReport()` mutation from hooks
       - `handleSave()` function:
         a. If no data, return
         b. Build ReportSaveRequest: `{ report_data: propertyData as Record<string, unknown>, notes: null, project_id: null }`
         c. Call `saveReport.mutate(request)`
         d. On success: `toast.success('Rapport opgeslagen')` — return the saved report ID
         e. On error: `toast.error('Opslaan mislukt')`
       - Returns `{ handleSave, isSaving: saveReport.isPending, savedReportId: saveReport.data?.id }`

       Export this as a hook, not a component. The drawer header calls `handleSave` directly.
