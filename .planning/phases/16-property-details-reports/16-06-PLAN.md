    2. **Create `frontend/src/components/property/FreshnessIndicator.tsx`:**

       Props:
       - `sectionName: string` — section identifier for display (e.g., "Kadaster")
       - `ageSeconds: number | null` — age of data in seconds (from backend)
       - `freshnessThresholdDays: number` — threshold in days for staleness
       - `onRefresh?: () => void` — callback for "Update nu" button
       - `isRefreshing?: boolean` — shows spinner when refreshing

       **Freshness thresholds (per user decision):**
       - Kadaster (eigendom): 7 days = 604800 seconds
       - Bestemmingsplan (zoning): 30 days = 2592000 seconds
       - Monument/Erfgoed: 180 days = 15552000 seconds
       - Bouwregels (BAG): 30 days = 2592000 seconds

       **Logic:**
       - If `ageSeconds` is null: show nothing (no indicator)
       - If age < threshold: show nothing (fresh = default, no green badge per user decision)
       - If age >= threshold: show amber warning

       **Stale warning design:**
       - Small inline warning next to section title area
       - Amber exclamation icon (text-amber-400, small SVG inline)
       - On hover/click: reveals text "Deze data is {X} dagen oud." + "[Update nu]" link
       - Use a simple hover-reveal pattern: `group` + `group-hover:opacity-100 group-hover:visible`
       - "Update nu" is a small text button (text-amber-400 underline text-xs) that calls `onRefresh`

       **Refreshing state:**
       - When `isRefreshing` is true: show semi-transparent overlay over section content + small spinner
       - Old data stays visible underneath (optimistic UI per user decision)
       - Overlay: `absolute inset-0 bg-black/20 flex items-center justify-center` with a simple spinning SVG

       **Helper function:**
       Create a `formatAge(seconds: number): string` function:
       - < 60: "zojuist"
       - < 3600: "{X} minuten geleden"
       - < 86400: "{X} uur geleden"
       - < 604800: "{X} dagen geleden"
       - >= 604800: "{X} weken geleden"

       Export a constant map for section thresholds:

         bouwregels: 30,
