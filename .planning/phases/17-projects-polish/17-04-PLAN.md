**2. Add force_refresh support to lookupProperty** (`frontend/src/lib/api.ts`):

Update `lookupProperty` signature to accept optional third parameter:

```typescript
export async function lookupProperty(
  input: AddressInput,
  accessToken: string | null,
  options?: { forceRefresh?: boolean }
): Promise<PropertyReportResponse> {
  const params = new URLSearchParams()
  if (options?.forceRefresh) {
    params.set('force_refresh', 'true')
  }
  const queryString = params.toString()
  const url = `${API_BASE}/lookup${queryString ? `?${queryString}` : ''}`

  return apiFetch<PropertyReportResponse>(url, {
    method: 'POST',
    accessToken,
    body: JSON.stringify(input),
  })
}
```

**3. Update usePropertyLookup hook** (`frontend/src/hooks/usePropertyLookup.ts`):

return useMutation<PropertyReportResponse, Error, AddressInput & { forceRefresh?: boolean }>({
