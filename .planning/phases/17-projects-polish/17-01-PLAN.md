```typescript
// ProjectCreate — POST /api/projects body
export interface ProjectCreate {
  name: string        // max 100 chars
  description?: string | null
}

// ProjectUpdate — PATCH /api/projects/{id} body
export interface ProjectUpdate {
  name?: string | null
  description?: string | null
}

// ProjectResponse — single project from API
export interface ProjectResponse {
  id: string           // UUID
  name: string
  description: string | null
  created_at: string   // ISO datetime
  updated_at: string   // ISO datetime
  report_count: number
}

// ProjectListResponse — GET /api/projects
export interface ProjectListResponse {
  projects: ProjectResponse[]
  total: number
}
```

Add project API functions to `frontend/src/lib/api.ts`:

1. Add `const PROJECTS_BASE = '/api/projects'` constant near existing BASE constants
2. Add import of project types at the top
3. Add these functions following the same patterns as existing report functions:

- `fetchProjects(accessToken)` — GET /api/projects, returns ProjectListResponse
- `createProject(data: ProjectCreate, accessToken)` — POST /api/projects, returns ProjectResponse
- `updateProject(projectId: string, data: ProjectUpdate, accessToken)` — PATCH /api/projects/{projectId}, returns ProjectResponse
- `deleteProject(projectId: string, accessToken)` — DELETE /api/projects/{projectId}, returns void (use raw fetch like deleteReport since 200 returns JSON dict, not standard schema)
- `assignReportToProject(reportId: string, projectId: string | null, accessToken)` — PATCH /api/reports/{reportId}/project, body: `{ project_id: projectId }`, returns ReportDetailResponse

Use `apiFetch<T>()` for JSON responses. For deleteProject, use raw fetch pattern matching deleteReport (backend returns `{"message": "...", "project_id": "..."}` which is fine to discard).

All hooks:
- Import useAuth for accessToken
- Import useQueryClient for cache invalidation
