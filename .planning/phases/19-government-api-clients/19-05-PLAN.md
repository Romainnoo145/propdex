    **test_rate_limiter.py** — Test APIRateLimiter class:

    1. `test_semaphore_limits_concurrent`:
       - Create limiter with max_concurrent=2, max_per_hour=9999
       - Fire 5 concurrent tasks that hold the context manager for 0.1s each
       - Verify: at most 2 are running simultaneously (use a counter + asyncio.Event)
       - This proves the semaphore is enforced

    2. `test_token_bucket_limits_throughput`:
       - Create limiter with max_concurrent=999, max_per_hour=5 (very low)
       - Acquire 5 times rapidly — should succeed (bucket starts full)
       - Verify the 6th acquire is delayed (takes measurable time)

    3. `test_disabled_mode_skips_limiting`:
       - Create limiter, set `enabled = False`
       - Acquire 100 times — should complete near-instantly (no semaphore, no token bucket)

    4. `test_context_manager_releases_on_exception`:
       - Acquire and raise inside `async with`
       - Verify semaphore is released (next acquire succeeds immediately)

    1. `test_single_page_response`:
       - Mock client returns JSON with 50 features, numberReturned=50, numberMatched=50

    3. `test_truncation_detection`:
       - Mock returns exactly 1000 features with numberMatched=1000 (genuine 1000, not truncated)

    4. `test_empty_bbox_returns_empty`:
       - Mock returns 0 features, numberReturned=0, numberMatched=0

    5. `test_api_error_propagates`:

    6. `test_pand_count_uses_hits_result_type`:
       - Mock GET response for resultType=hits
