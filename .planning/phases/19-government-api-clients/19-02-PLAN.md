    Create `bag_wfs.py` in `backend/app/government_apis/` following the existing bag_api.py pattern:

    1. `BAGWFSClient` class with:
       - `BASE_URL = "https://service.pdok.nl/lv/bag/wfs/v2_0"` (PDOK BAG WFS endpoint)
       - `PAGE_SIZE = 1000` (PDOK maximum per request)

    2. `get_panden_in_bbox` method:
       - Parameters: `minx, miny, maxx, maxy: float` (EPSG:28992 bounding box), `client: httpx.AsyncClient`
       - Returns: `list[dict]` (GeoJSON features with pand geometries and properties)
       - Implementation:
         a. Loop with count/startIndex pagination:
            - WFS params: service=WFS, version=2.0.0, request=GetFeature, typeName=bag:pand,
              bbox={minx},{miny},{maxx},{maxy},urn:ogc:def:crs:EPSG::28992,
              outputFormat=application/json, count=1000, startIndex=0
            - Use `async with bag_wfs_limiter:` around EACH page request (rate limit per request, not per full query)
            - Call `handle_api_response(response, source="bag-wfs")` for consistent error handling
         b. Truncation detection:
            - Extract `numberReturned` and `numberMatched` from response JSON
            - If `numberReturned < PAGE_SIZE` or `len(all_features) >= numberMatched`: stop (all data fetched)
            - If `numberReturned == PAGE_SIZE` and `len(all_features) < numberMatched`: increment startIndex, fetch next page
         c. Log pagination progress: `"BAG WFS: fetched {len(all_features)}/{numberMatched} panden (page {page_num})"`
         d. Set timeout=30.0 per request

    3. `get_pand_count_in_bbox` method (lightweight count-only query):
       - Parameters: same bbox + client
       - Returns: `int` (total number of panden in bbox)
       - Implementation: Use `resultType=hits` WFS parameter which returns numberMatched without fetching features
       - Purpose: Pre-check before full fetch to estimate pagination needs

    4. Module-level singleton: `bag_wfs_client = BAGWFSClient()`

    5. Follow existing patterns:
       - Module docstring explaining purpose
       - `logging.getLogger(__name__)` for structured logging
       - Type hints everywhere
       - Import from `base.py`: handle_api_response, GovernmentAPIError
       - Import from `rate_limiter.py`: bag_wfs_limiter

    NOTE: The BAG WFS endpoint is public (no API key needed, unlike the BAG individual queries endpoint). Do NOT add API key headers -- this is a different service from bag_api.py.
