  <action>
    Create `brk_bevragen.py` in `backend/app/government_apis/`:

    1. `_create_brk_ssl_context()` module-level helper:
       - Creates `ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)`
       - Loads CA bundle: `context.load_verify_locations(settings.BRK_CA_BUNDLE_PATH)`
       - Loads client cert + key: `context.load_cert_chain(certfile=settings.BRK_CLIENT_CERT_PATH, keyfile=settings.BRK_CLIENT_KEY_PATH)`
       - Sets `context.check_hostname = True` and `context.verify_mode = ssl.CERT_REQUIRED`
       - Returns SSLContext

    2. `BRKBevragenClient` class:
       - `BASE_URL = "https://api.brk.kadaster.nl/esd-eto/bevragen/v2"` (mTLS endpoint, NOT the API-key-only endpoint)
       - Constructor:
         a. Check if BRK is configured: `self._configured = bool(settings.BRK_API_KEY and settings.BRK_CLIENT_CERT_PATH)`
         b. If configured, validate cert paths exist (Path.exists()), raise RuntimeError if missing
         c. If configured, create SSLContext via `_create_brk_ssl_context()` and store as `self._ssl_context`
         d. If NOT configured, log warning "BRK Bevragen not configured -- eigendomsdata queries disabled" and set `self._configured = False`
       - This allows the app to start in development without BRK certificates.

    3. `create_client()` method:
       - Returns `httpx.AsyncClient(verify=self._ssl_context, timeout=30.0)`
       - Caller must use as async context manager: `async with brk_client.create_client() as client:`
       - Raises RuntimeError if not configured

    4. `get_kadastraal_object` method:
       - Parameters: `identificatie: str`, `client: httpx.AsyncClient`
       - Returns: `dict` with cadastral object data
       - Implementation:
         a. Check `self._configured`, raise GovernmentAPIError if not
         b. Rate limit: `async with brk_limiter:`
         c. URL: `{BASE_URL}/kadastraalonroerendezaken/{identificatie}`
         d. Headers: `{"X-Api-Key": settings.BRK_API_KEY, "Accept-Crs": "epsg:28992"}`
         e. Call `handle_api_response(response, source="brk-bevragen")`

    5. `get_eigendom` method:
       - Parameters: `identificatie: str`, `client: httpx.AsyncClient`
       - Returns: `dict` with ownership/rights data (eigenaren, rechten)
       - Implementation:
         a. Same pattern as get_kadastraal_object
         b. URL: `{BASE_URL}/kadastraalonroerendezaken/{identificatie}/zakelijkegerechtigden`
         c. Add `expand=true` to include persoon (owner) details in response
       - CRITICAL: Add docstring noting "NEVER cache or store this data (Kadaster Tier 3 terms)"

    6. Module-level singleton: `brk_client = BRKBevragenClient()`
       - Will gracefully handle missing config (logs warning, disables eigendom queries)

    Follow existing patterns: module docstring, logging, type hints, import from base.py and rate_limiter.py and config.py.

    IMPORTANT design decisions:
    - BRK client creates its OWN httpx.AsyncClient (with mTLS SSLContext), NOT reusing the shared app client
    - Every method checks `self._configured` first and raises descriptive error if not
    - NEVER store response data to DB, file, or cache -- return directly to caller
