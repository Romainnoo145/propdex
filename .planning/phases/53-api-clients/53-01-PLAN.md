Create `backend/app/government_apis/ep_online.py` following the established government API client pattern (see `brk_bevragen.py` for reference).

**Class: `EPOnlineClient`**
- `BASE_URL = "https://public.ep-online.nl/api/v5"`
- `_is_configured()` -> checks `bool(settings.EP_ONLINE_API_KEY)`
- `_headers` property -> returns `{"Authorization": f"Bearer {settings.EP_ONLINE_API_KEY}"}` (Note: auth format is MEDIUM confidence — may need to be changed to `X-Api-Key` header during live validation. Use Bearer as default per research.)

**Method: `async def get_by_vbo_id(self, vbo_id: str, client: httpx.AsyncClient) -> EnergyLabel | None`**
- If not configured: return None (unconfigured = section hidden, no error)
- Use `async with ep_online_limiter:` for rate limiting (import from rate_limiter.py, already exists)
- URL: `f"{self.BASE_URL}/PandEnergielabel/AdresseerbaarObject/{vbo_id}"`
- Call `response = await client.get(url, headers=self._headers)`
- Call `data = handle_api_response(response, source="ep-online")`
- Call `_parse_energy_label(data, vbo_id)` to map response to EnergyLabel
- Catch `APINotFoundError` specifically: return `EnergyLabel(is_geregistreerd=False, niet_geregistreerd_reden="Niet geregistreerd", bag_vbo_id=vbo_id)` — 404 is normal for ~20-30% of properties (NRG-03)
- Catch `httpx.TimeoutException`: raise `GovernmentAPIError("ep-online", "Request timed out")`

**Helper: `_parse_energy_label(data: dict, vbo_id: str) -> EnergyLabel`**
- Explicit field mapping from API camelCase to schema snake_case (do NOT use `EnergyLabel(**data)` — pitfall 1 from research):
  - `energieklasse=data.get("energieKlasse")`
  - `registratie_datum=data.get("registratieDatum")`
  - `geldig_tot=data.get("geldigTot")`
  - `berekenings_type=data.get("berekeningType")`
  - `soort_opname=data.get("soortOpname")`
  - `opname_datum=data.get("opnameDatum")`
  - `bag_vbo_id=vbo_id`
  - `is_geregistreerd=True`
- Compute `is_geldig`: compare `geldig_tot` to `datetime.utcnow()` if geldig_tot is present (use `datetime.strptime` for ISO date string)
- All field names are MEDIUM confidence — add a comment noting Phase 53 executor should make a live test call and correct field names if needed
- If data is a list (EP-Online may return multiple labels per VBO), take the first item

**Module-level singleton:** `ep_online_client = EPOnlineClient()`

**Docstring:** Follow three-state contract documentation pattern:
- Data found -> return EnergyLabel with is_geregistreerd=True
- No label registered (404) -> return EnergyLabel with is_geregistreerd=False (NRG-03)
- API error/timeout -> raise GovernmentAPIError
- API unconfigured -> return None (section hidden)

**Step 2: Create `backend/app/government_apis/woz_waardeloket.py`**

Follow the same pattern as EP-Online client.

**Class: `WOZWaardeloketClient`**
- `BASE_URL = "https://api.kadaster.nl/lvwoz/wozwaardeloket-api/v1"`
- No auth required (public endpoint)

**Method: `async def get_by_nummeraanduiding_id(self, nummeraanduiding_id: str, client: httpx.AsyncClient) -> WOZData | None`**
- Use `async with woz_waardeloket_limiter:` for rate limiting
- URL: `f"{self.BASE_URL}/wozwaarde/nummeraanduiding/{nummeraanduiding_id}"`
- Call `response = await client.get(url)`
- Call `data = handle_api_response(response, source="woz-waardeloket")`
- Call `_parse_woz_data(data)` to map response to WOZData
- Catch `APINotFoundError`: return None (no WOZ object for this address — normal)
- Catch `httpx.TimeoutException`: raise `GovernmentAPIError("woz-waardeloket", "Request timed out")`
- CRITICAL (user decision): Do NOT silently return None on unexpected response format. If `_parse_woz_data` cannot extract required fields (vastgesteldeWaarde and peildatum), raise `GovernmentAPIError("woz-waardeloket", "Unexpected response format: missing required fields", status_code=200)` and log the raw response at WARNING level for monitoring.

**Helper: `_parse_woz_data(data: dict) -> WOZData`**
- Explicit field mapping (field names are LOW confidence — comment this):
  - Extract WOZ objects from response structure (may be nested under a key)
  - Map to `WOZWaarde` items and `WOZData` container
  - `woz_objectnummer=data.get("wozObjectnummer")`
  - For latest value: `vastgestelde_waarde=..., peildatum=...`
  - Set `meest_recente_waarde` and `meest_recente_peildatum` from the most recent WOZWaarde
- ALWAYS set on every successful response (user decision, WOZ-04):
  - `low_confidence=True`
  - `low_confidence_reden="Bron: WOZ Waardeloket (indicatief)"`
  - `bron="WOZ Waardeloket"`
- If response structure is unexpected (missing critical fields), raise GovernmentAPIError instead of returning None (user decision from CONTEXT.md)
