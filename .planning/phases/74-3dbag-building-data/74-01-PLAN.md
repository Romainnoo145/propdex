**Create `backend/app/government_apis/bag_3d.py`:**

Follow the established API client pattern (see bodemloket_arcgis.py for reference):
- Import `GovernmentAPIError`, `retry_with_backoff` from `base.py`
- Import `bag_3d_limiter` from `rate_limiter.py`
- `BASE_URL = "https://api.3dbag.nl/collections/pand/items"`
- Class `BAG3DClient` with docstring explaining 3D BAG OGC API Features (TU Delft)
- Key fields documented in docstring: `b3_h_dak_50p` (median roof NAP), `b3_h_maaiveld` (ground NAP), `b3_bouwlagen` (floor count)
- Building height formula: `b3_h_dak_50p - b3_h_maaiveld`

Method `get_panden_in_bbox(self, minx, miny, maxx, maxy, client: httpx.AsyncClient) -> dict[str, dict]`:
- Parameters: EPSG:28992 bounding box coordinates + shared httpx client
- Returns dict keyed by BAG pand identificatie (e.g. "NL.IMBAG.Pand.0363100012345678")
- Value: `{"actual_bouwhoogte": float | None, "actual_bouwlagen": int | None}`
- Raises `GovernmentAPIError` on HTTP errors

Implementation:
- Query params: `bbox="{minx},{miny},{maxx},{maxy}"`, `bbox-crs="http://www.opengis.net/def/crs/EPSG/0/28992"`, `limit=1000`, `f="json"`
- HTTP Basic Auth: `auth=(settings.BAG_3D_USERNAME, settings.BAG_3D_PASSWORD)` — read from settings at call time. If both username and password are empty strings, skip auth parameter (allow unauthenticated access for testing).
- Use `retry_with_backoff` wrapping the `client.get()` call with `source="bag-3d"`, `retry_on_errors=True`
- Rate limit with `async with bag_3d_limiter:` before each request
- Pagination: while loop, stop when `len(features) < 1000`, otherwise increment offset
- For each feature: extract `id` (pand identificatie), `properties.b3_h_dak_50p`, `properties.b3_h_maaiveld`, `properties.b3_bouwlagen`
- Compute `actual_bouwhoogte = round(b3_h_dak_50p - b3_h_maaiveld, 1)` with sanity bounds `1.5 <= hoogte <= 200.0`
- Compute `actual_bouwlagen = int(round(bouwlagen))` with sanity bounds `1 <= bouwlagen <= 100`
- Handle 401 with specific `GovernmentAPIError` message about auth
- Handle non-200 with generic `GovernmentAPIError`
- Module-level singleton: `bag_3d_client = BAG3DClient()`
