**7. Merge actual dimensions in Phase 4 `final_bm` assembly:**
In Phase 4, after unpacking `bag_identificaties` from `scored_parcels`, add the 3D BAG join:
```python
# 3D BAG actual dimensions — join by pand identificatie
actual_hoogte: float | None = None
actual_lagen: int | None = None
for pand_id in (bag_identificaties or []):
    full_id = f"NL.IMBAG.Pand.{pand_id}" if not pand_id.startswith("NL.") else pand_id
    bag_3d_entry = bag_3d_data.get(full_id)
    if bag_3d_entry:
        h = bag_3d_entry.get("actual_bouwhoogte")
        bl = bag_3d_entry.get("actual_bouwlagen")
        if h is not None:
            actual_hoogte = h if actual_hoogte is None else max(actual_hoogte, h)
        if bl is not None:
            actual_lagen = bl if actual_lagen is None else max(actual_lagen, bl)

# Merge into final_bm (after existing pand_oppervlakte_m2 merge)
if actual_hoogte is not None:
    final_bm["actual_bouwhoogte"] = actual_hoogte
if actual_lagen is not None:
    final_bm["actual_bouwlagen"] = actual_lagen
```
Uses max() across all intersecting panden — the tallest/largest building represents the parcel's actual envelope for comparison with permitted maximums.

**CRITICAL: BAG Pand ID format mismatch.** BAG WFS returns numeric-only IDs (e.g. "0363100012345678"). 3D BAG OGC API returns IDs as "NL.IMBAG.Pand.0363100012345678". When looking up, prepend "NL.IMBAG.Pand." to the numeric BAG WFS identificatie. The lookup code handles both formats (check `startswith("NL.")`).
