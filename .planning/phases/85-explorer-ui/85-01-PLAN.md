  <action>
    Add `GET /explorer` endpoint to jurisprudence router with the following behavior:

    **Query parameters:**
    - `gemeente` (optional string) — filter by extracted_gemeente or gemeente_query
    - `vergunningstype` (optional string) — filter by vergunningstype column
    - `uitkomst` (optional string) — filter by uitkomst column
    - `rechtsgrond` (optional string) — filter by rechtsgronden JSONB (use `@>` operator for array containment)
    - `rechtbank_niveau` (optional string) — filter by court level derived from instantie: "Rechtbank", "Gerechtshof", "Raad van State". Use CASE/LIKE expression: instantie ILIKE 'Rechtbank%' → Rechtbank, ILIKE 'Gerechtshof%' → Gerechtshof, ILIKE '%Raad van State%' → Raad van State
    - `periode` (optional string) — one of "1jaar", "3jaar", "5jaar", "alles". Convert to date_from filter using datum_uitspraak >= calculated date string
    - `offset` (int, default 0) — pagination offset
    - `limit` (int, default 20, max 50) — page size

    **Response structure:**
    ```json
    {
      "results": [...ruling objects with ecli, court_code, instantie, datum_uitspraak, title, summary, extracted_gemeente, uitkomst, vergunningstype, rechtsgronden, doorlooptijd_dagen, ai_analysis],
      "total_count": 47,
      "has_more": true,
      "facets": {
        "gemeente": [{"value": "Venlo", "count": 23}, ...],
        "vergunningstype": [{"value": "nieuwbouw", "count": 12}, ...],
        "uitkomst": [{"value": "toegewezen", "count": 20}, ...],
        "rechtsgrond": [{"value": "procedurefout", "count": 8}, ...],
        "rechtbank_niveau": [{"value": "Rechtbank", "count": 30}, ...]
      }
    }
    ```

    **Critical: Cross-faceted counts.** For each facet dimension, compute counts with ALL other filters applied EXCEPT that dimension's own filter. This means if the user has gemeente=Venlo AND uitkomst=toegewezen active:
    - gemeente facet counts: computed with uitkomst=toegewezen filter only (not gemeente filter)
    - uitkomst facet counts: computed with gemeente=Venlo filter only (not uitkomst filter)
    - vergunningstype facet counts: computed with gemeente=Venlo AND uitkomst=toegewezen

    Implementation approach:
    - Build a `build_where_clauses(filters, exclude_dimension=None)` helper that constructs WHERE conditions, optionally excluding one dimension
    - Main results query: all filters applied, ORDER BY datum_uitspraak DESC, OFFSET/LIMIT with +1 detection for has_more
    - Facet queries: 5 parallel subqueries, each excluding its own dimension from filters
    - For rechtsgrond facet: since it's a JSONB array, use `jsonb_array_elements_text(rechtsgronden)` to unnest before GROUP BY
    - For rechtbank_niveau facet: use the CASE expression to derive level from instantie, then GROUP BY the derived level

    Serialize ruling results similarly to existing get_gemeente_rulings but include rechtsgronden and ai_analysis summary fields.

    Include `from app.auth.dependencies import get_current_active_user` and `Depends(get_current_active_user)` for auth.
