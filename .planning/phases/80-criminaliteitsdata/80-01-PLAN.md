  <action>
Create `backend/app/government_apis/cbs_crime.py` with a `CbsCrimeClient` class. This is a SEPARATE client from CBSODataClient because dataderden.cbs.nl uses OData v3 (different base URL, TypedDataSet entity, space-padded keys).

Constants:
- `CRIME_BASE_URL = "https://dataderden.cbs.nl/ODataApi/odata/47018NED"`
- `LATEST_PERIOD = "2024JJ00"` (most recent full-year Definitief data)
- Crime type code constants with 6-char space-padding: totaal="0.0.0 ", vermogensdelicten codes (1.1.1, 1.1.2, 1.2.1, 1.2.2, 1.2.3, 1.2.4, 1.6.2), vernieling="2.2.1 ", geweld codes (1.4.3, 1.4.4, 1.4.5, 1.4.6, 1.4.7). All padded to 6 chars with ljust(6).

Methods:
1. `_pad_key(value: str, width: int) -> str` -- pad with trailing spaces
2. `_resolve_wijk_key(client, gemeente_code, wijk_naam) -> str | None` -- query WijkenEnBuurten entity with `startswith(Key, 'WK{gemeente_code}')` filter, match by Title, return 10-char padded Key. Always include `$format=json`.
3. `get_crime_data(client, gemeente_code, wijk_naam, inwoners) -> dict | None` -- resolve wijk key, query TypedDataSet with filters for WijkenEnBuurten + Perioden + all crime codes. Parse GeregistreerdeMisdrijven_1 values. Aggregate subcategory counts into vermogensdelicten/vernieling/geweld totals. Compute per-1000 rates using `_per_1000(count, inwoners)` helper (guard against None/zero inwoners). Return dict matching the research payload structure: `{bron, dataset, peiljaar, totaal_misdrijven, per_1000_inwoners, categorien: {vermogensdelicten: {aantal, per_1000}, vernieling: {aantal, per_1000}, geweld: {aantal, per_1000}}}`.

Use `retry_with_backoff` from base.py for HTTP calls. Use `GovernmentAPIError` for error handling. Follow three-state contract: return dict | None | raise GovernmentAPIError.

CRITICAL OData v3 gotchas:
- Always include `$format=json` in params (v3 defaults to XML)
- Space-pad ALL filter values: WK keys to 10 chars, SoortMisdrijf to 6 chars
- Response data is in `response.json()["value"]` for OData v3

In rate_limiter.py: Register a new `cbs_crime_limiter = APIRateLimiter(...)` singleton following the existing pattern (e.g., 10 requests/second like other CBS limiters).
