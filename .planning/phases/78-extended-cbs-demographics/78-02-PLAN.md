Create four card components following the EXACT styling pattern of `CbsNeighborhoodCard.tsx` (rounded-xl border, section header with icon, p-4 body, text-xs labels, text-grey-400 for labels, text-grey-100 for values).

**AgeDistributionCard.tsx:**
- Props: `{ leeftijdsverdeling: CbsLeeftijdsVerdeling }`
- Returns null if ALL 5 age group values are null
- Renders 5 horizontal percentage bars (one per age group: 0-14, 15-24, 25-44, 45-64, 65+)
- Bar pattern: matching the Koop/Huur bar in CbsNeighborhoodCard — `<div className="h-1.5 w-full rounded-full bg-grey-800">` outer, inner div with percentage width
- Use amber-accent/70 for the bar fill color (consistent with existing card)
- Below the bars, show a vergrijzing/verjonging indicator:
  - Derive direction: compute ratio = perc_65_plus / ((perc_0_14 ?? 0) + (perc_15_24 ?? 0) || 1)
  - ratio > 1.5 = "Vergrijzend" (show with upward arrow icon, text-orange-400)
  - ratio < 0.6 = "Verjongend" (show with downward arrow icon, text-green-400)
  - else = "Stabiel" (show with horizontal arrow, text-grey-400)
- Section header: people icon, "Leeftijdsverdeling" title

**HouseholdCard.tsx:**
- Props: `{ huishoudens: CbsHuishoudens, leeftijdsverdeling?: CbsLeeftijdsVerdeling }`
- Returns null if huishoudens.totaal is null
- Display: three rows for eenpersoons / zonder kinderen / met kinderen, each as percentage of totaal (compute client-side: `(count / totaal) * 100`). Handle null counts gracefully (skip row).
- Show gemiddelde_grootte as "Gem. huishoudensgrootte: X.X" if available
- Include DoelgroepLabel at the bottom of the card if leeftijdsverdeling is provided
- Section header: home icon, "Huishoudenssamenstelling" title

**IncomeCard.tsx:**
- Props: `{ inkomen: CbsInkomen, wozWaarde: number | null }`
- Returns null if ALL income values are null
- Display income metrics formatted with `Intl.NumberFormat('nl-NL')` and EUR prefix:
  - gem_per_ontvanger as "Gem. inkomen (ontvanger)"
  - gem_per_inwoner as "Gem. inkomen (inwoner)"
  - gem_gestandaardiseerd as "Gem. huishoudinkomen (gestd.)"
- Display income distribution as a simple two-row display:
  - "Laagste 40%: X.X% van personen"
  - "Hoogste 20%: X.X% van personen"
- WOZ/Inkomen ratio indicator:
  - Compute: `(wozWaarde * 1000) / gem_per_ontvanger` (WOZ is in thousands in CBS data)
  - Display as "WOZ/Inkomen ratio: X.X"
  - Color coding: ratio > 8 = text-orange-400 ("Hoge marktdruk"), ratio < 5 = text-green-400 ("Betaalbaar"), else text-grey-300 ("Gemiddeld")
  - Only show if both wozWaarde and gem_per_ontvanger are non-null
- Section header: banknote icon, "Inkomen & Vermogen" title

**DoelgroepLabel.tsx:**
- Export a `deriveDoelgroep()` function AND a `DoelgroepLabel` component
- `deriveDoelgroep(leeftijdsverdeling, huishoudens)` returns one of: 'studentenwijk' | 'gezinswijk' | 'vergrijzend' | 'gemengd'
- Classification rules (per research):
  - studentenwijk: perc_15_24 > 20 AND eenpersoons/totaal > 0.5
  - vergrijzend: perc_65_plus > 25
  - gezinswijk: perc_0_14 > 20
  - else: gemengd
- Component renders a colored badge:
  - studentenwijk: blue-ish (bg-blue-500/10 text-blue-400 border-blue-500/20)
  - gezinswijk: green-ish (bg-green-500/10 text-green-400 border-green-500/20)
  - vergrijzend: orange-ish (bg-orange-500/10 text-orange-400 border-orange-500/20)
  - gemengd: grey (bg-grey-700/50 text-grey-300 border-grey-700)
- Returns null if insufficient data to classify

Do NOT use any charting library. Use Tailwind div bars matching existing CbsNeighborhoodCard pattern.
Do NOT add any npm dependencies.
