Create integration tests for `fetch_monument_status` that test the full pipeline with real database for cache operations.

**Fixtures:**
- `org_id(test_db)`: Same pattern as zoning integration tests.

**Key insight:** `fetch_monument_status` calls `_fetch_rce` which internally uses `get_cached_or_fetch` with the real DB session. So the cache operations happen through the RCE fetcher. We need to mock the RCE API client (`app.government_apis.rce_monuments._rce_client.query_by_location`) but let the cache manager work with real DB.

**Approach:** Patch `app.government_apis.rce_monuments._rce_client` with a MagicMock that has an AsyncMock `query_by_location` method. This lets _fetch_rce run its real logic (cache check, response parsing) while mocking only the external API call.

**Test class: TestMonumentFullFlow**
- test_rce_monument_found_full_flow: Mock _rce_client.query_by_location returning `[{"rce_objrijksnr": "12345", "rce_objnaam": "Historisch Pand"}]`. Call fetch_monument_status. Assert:
  - result.is_monument is True
  - result.consensus_status == "rijksmonument"
  - result.has_conflict is False
  - result.restrictions_summary has 4 items (rijksmonument restrictions)
  - RCE source in result.sources has monument_nummer="12345"
  - Direct DB assertion: CachedAPIResponse exists with source="rce", cache_key starting with "rce:monument:"

- test_rce_no_monument_full_flow: Mock _rce_client.query_by_location returning `[]`. Assert:
  - result.is_monument is False
  - result.consensus_status == "geen_monument"
  - RCE source in result.sources has is_monument=False

- test_rce_cache_hit: Call fetch_monument_status twice with same coordinates. Assert _rce_client.query_by_location called only once (second call hits cache).

- test_rce_api_error_handled: Mock _rce_client.query_by_location raising httpx.HTTPError. Assert:
  - result is not None (graceful degradation)
  - RCE source has error message
  - consensus_status is None (no definitive sources)

For `client` and `session` parameters: client is AsyncMock(spec=httpx.AsyncClient), session is the real test_db fixture. The `_fetch_rce` function passes client and session to get_cached_or_fetch, which uses the real session for DB operations.

Use coordinates x=121687.0, y=487484.0 (Amsterdam Centraal RD) for consistency.
