  <action>
Create unit tests for all three helper functions in zoning_aggregator.py. Follow established project patterns: unittest.mock only, AsyncMock for async, pytest.mark.parametrize for edge cases.

**Test class: TestFindContainingFeatures**
Test `_find_containing_features(property_point, features, geometry_key)`:
- Point inside polygon returns feature (use shapely Point(50, 50) inside Polygon [[0,0],[100,0],[100,100],[0,100],[0,0]])
- Point outside polygon returns empty list (Point(200, 200) with same polygon)
- Point on polygon boundary returns feature (intersects=True)
- Multiple features, only containing ones returned
- Feature with missing geometry key is skipped (no error)
- Feature with invalid geometry data is skipped (logs warning, doesn't crash)
- Empty features list returns empty list
- Custom geometry_key parameter works (e.g. geometry_key="geometry" instead of default "geometrie")

**Test class: TestExtractBuildingDimensions**
Test `_extract_building_dimensions(maatvoeringen, property_point)`:
Use pytest.mark.parametrize for dimension field mapping:
- ("bouwhoogte", "12.5", "max_bouwhoogte", 12.5)
- ("max bouwhoogte", "10 meter", "max_bouwhoogte", 10.0)
- ("goothoogte", "8.0", "max_goothoogte", 8.0)
- ("bebouwingspercentage", "60", "max_bebouwingspercentage", 60.0)
- ("bebouwingspercentage", "45%", "max_bebouwingspercentage", 45.0)
- ("hoogte", "15", "max_hoogte", 15.0) -- generic hoogte
- ("fsi", "2.5", "max_floor_area_ratio", 2.5)
- ("vloeroppervlakte", "500", "max_floor_area_ratio", 500.0)

Additional tests:
- Empty maatvoeringen returns BuildingDimensions with all None (has_any_data is False)
- Maatvoeringen outside property point are excluded (spatial filtering applied)
- Non-numeric waarde is skipped gracefully
- First matching value wins (subsequent ignored per `is None` guard)

**Test class: TestFilterAndSortPlans**
Test `_filter_and_sort_plans(plans)`:
- Plans with "vastgesteld" status are kept, others filtered out
- Plans sorted by datum descending (newest first)
- If no vastgesteld plans, falls back to "ontwerp" plans
- Plans with missing datum sort correctly (empty string)
- Empty plan list returns empty list
- Mixed case planStatus ("Vastgesteld", "VASTGESTELD") handled (lowered comparison)

All maatvoeringen/features test data must use valid GeoJSON polygons that contain Point(50, 50) when testing containment, and polygons NOT containing Point(50, 50) when testing exclusion.
