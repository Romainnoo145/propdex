**2. Create hooks in `frontend/src/hooks/useScoreWeights.ts`:**

`useOrgScoreWeights()` — TanStack Query hook:
- queryKey: `['org', 'score-weights']`
- queryFn: `apiFetch<ScoreWeightsResponse>('/api/users/org/score-weights', { accessToken })`
- staleTime: 5 minutes

`useSaveScoreWeights()` — TanStack Mutation hook:
- mutationFn: PUT `/api/users/org/score-weights` with SaveScoreWeightsRequest body
- onSuccess: invalidate `['org', 'score-weights']` query

`useRescoreJobStatus(jobId)` — TanStack Query hook for polling:
- queryKey: `['org', 'rescore-job', jobId]`
- queryFn: GET `/api/users/org/score-weights/job/{jobId}`
- refetchInterval: 2000 (poll every 2s while status !== 'complete' && status !== 'failed')
- enabled: `!!jobId`

Follow patterns from `frontend/src/hooks/useSettings.ts` for auth and apiFetch usage.
