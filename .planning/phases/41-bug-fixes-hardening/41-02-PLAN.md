Replace this code:

for parcel, score, category, factors, _centroid in qualifying:
    scan_result = ScanResult(
        organization_id=org_id,

        parcel_id=parcel.id,

With this bulk idempotent insert:
```python
if qualifying:
    qualifying_values = [
        {
            "organization_id": org_id,
            "scan_id": scan.id,
            "parcel_id": parcel.id,
            "score": score,
            "flags": {"category": category, "factors": factors},
        }
        for parcel, score, category, factors, _centroid in qualifying
    ]
    stmt = pg_insert(ScanResult).values(qualifying_values).on_conflict_do_nothing(
        index_elements=["scan_id", "parcel_id"]
    )
    await session.execute(stmt)

await session.flush()
await session.commit()
```

**Key details:**
- Use `index_elements=["scan_id", "parcel_id"]` (NOT `constraint="uq_scan_results_scan_parcel"`) — the index_elements form is more robust.
- Batch all qualifying values into a single execute call (not N individual calls in a loop) — faster and cleaner.
- Keep `await session.flush()` and `await session.commit()` after the insert — matches the existing transaction pattern.
- Wrap in `if qualifying:` guard to avoid executing empty values list.
- Do NOT change any other code in the function — only the ScanResult insertion block.
