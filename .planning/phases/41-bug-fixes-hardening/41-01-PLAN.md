4. **test_refresh_token_rotation** — This is the biggest change:
   - After register, the refresh_token is set as httpOnly cookie. httpx AsyncClient's cookie jar stores it automatically.
   - BUT: The cookie `path="/api/auth"` may not match `/auth/refresh` (the actual endpoint path). httpx AsyncClient matches cookies by domain + path.
   - **Workaround**: Extract the refresh_token from the response's `set-cookie` header manually, then set it on subsequent requests via `async_client.cookies.set("refresh_token", value, path="/api/auth")` or by passing `cookies={"refresh_token": value}` to the request.
   - After the first refresh call, extract the NEW refresh_token from the refresh response's set-cookie header.
   - Assert `new_refresh_token != original_refresh_token` (rotation works).
   - Assert new `access_token` is present in JSON response.

5. **test_refresh_revokes_old_token** — Same cookie extraction pattern. After first refresh, manually set the OLD refresh_token cookie and assert 401.

6. **test_logout_success** — Extract refresh_token from register response's set-cookie header. Send logout request with that cookie. Assert 200 + "Logged out successfully".

7. **test_logout_then_refresh_fails** — After logout (which clears cookie), send refresh request (no cookie) → assert 401.

8. **test_full_auth_lifecycle** — Update all 6 steps to use cookies instead of JSON body for refresh tokens.

**Cookie extraction helper** — Add a helper function at the top of the file:

```python
def _extract_refresh_cookie(response) -> str:
    """Extract refresh_token from Set-Cookie header."""
    for header_value in response.headers.get_list("set-cookie"):
        if header_value.startswith("refresh_token="):
            # Extract value between = and first ;
            return header_value.split("=", 1)[1].split(";")[0]
    raise AssertionError("No refresh_token cookie in response")
```

**For sending the cookie on subsequent requests**, use:
```python
async_client.cookies.set("refresh_token", token_value)
```
or pass directly:
```python
await async_client.post("/auth/refresh", cookies={"refresh_token": token_value})
```

The httpx AsyncClient cookie jar approach is simpler. However, because the cookie has `path=/api/auth` and the test sends to `/auth/refresh` (without `/api` prefix since the test client uses ASGITransport directly to the app), the path won't match for automatic forwarding. Use explicit `cookies={}` on each request that needs the refresh_token.

**For logout**, the endpoint now reads from `request.cookies.get("refresh_token")` too. Send the cookie explicitly.
