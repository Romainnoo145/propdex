<objective>
Enforce the Kadaster Tier 3 never-cache/never-store constraint by stripping BRK ownership from report data before DB save, and re-fetching BRK live when serving saved reports.

Purpose: BRK-04 requires that eigendomsdata is never persisted in the database. The save layer must actively strip BRK data, and the view layer must re-fetch it live to provide "actueel opgevraagd" real-time ownership data.

Output: BRK data stripped in both save_report() and update_report_data(); GET /{report_id} re-fetches BRK from stored cadastral percelen; integration tests prove enforcement.
</objective>

       ```python
       report = await service.get_report(
           report_id=report_id,
           organization_id=organization_id,
           session=db,
       )

       # BRK was stripped before save — re-fetch live for each view
       # (Kadaster Tier 3: data must be "actueel opgevraagd")
       report_data = dict(report.report_data)  # copy of stored JSONB
       if report_data.get("brk_ownership") is None:
           try:
               stored_parcels = [
                   CadastralParcel.model_validate(p)
                   for p in report_data.get("cadastral_parcels", [])
               ]
               brk_section = await fetch_brk_ownership(stored_parcels)
               report_data["brk_ownership"] = brk_section.model_dump(mode="json")
           except Exception as e:
               logger.warning("BRK re-fetch on view failed: %s", str(e))
               # Leave brk_ownership as None — frontend handles gracefully

       return ReportDetailResponse(
           id=report.id,
           report_name=report.report_name,
           report_data=report_data,  # Use enriched copy, not raw stored data
           postcode=report.postcode,
           city=report.city,
           notes=report.notes,
           project_id=report.project_id,
           created_at=report.created_at,
           updated_at=report.updated_at,
       )
       ```
