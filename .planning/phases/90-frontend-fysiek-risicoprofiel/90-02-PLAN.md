    1. In backend/app/services/tile_proxy.py, add a `foundation_risk_level` computed column to the `mvt_data` CTE in the `generate_mvt_tile` function.

    Add this SQL CASE expression to the SELECT list inside mvt_data (after the existing columns, before `(rep.id IS NOT NULL) AS has_report`):

    ```sql
    CASE
        WHEN pc.bouwjaar IS NULL THEN 'onbekend'
        WHEN pc.bouwjaar < 1970 THEN 'hoog'
        WHEN pc.bouwjaar < 1990 THEN 'middel'
        ELSE 'laag'
    END AS foundation_risk_level
    ```

    This is a simplified bouwjaar-only proxy for foundation risk in tile context. The full risk assessment (bouwjaar x bodemtype) is available via the per-parcel API. Tile coloring uses bouwjaar alone because:
    - Soil type is not stored per-parcel in scan results
    - Bouwjaar is the primary risk driver (pre-1970 = wooden pile era)
    - Visual clustering at map scale doesn't need per-parcel soil precision
