Add a `@media print` block at the end of `index.css` (after the light mode overrides). This block handles the structural and visual transformation for PDF output.

**Print CSS rules to add:**

```css
/* ─── Print / PDF export ────────────────────────────────────── */

@media print {
  /* Force light background — readable on paper */
  body {
    background: white !important;
    color: #111 !important;
    -webkit-print-color-adjust: exact;
    print-color-adjust: exact;
  }

  /* Override CSS custom properties for print readability */
  :root {
    --color-grey-950: white;
    --color-grey-900: #f9fafb;
    --color-grey-850: #f3f4f6;
    --color-grey-800: #e5e7eb;
    --color-grey-700: #d1d5db;
    --color-grey-600: #6b7280;
    --color-grey-400: #374151;
    --color-grey-300: #1f2937;
    --color-grey-100: #111827;
    --color-overlay: black;
    --color-amber-accent: #b45309;
    --color-error: #dc2626;
    --color-warning: #d97706;
    --color-info: #2563eb;
    --color-success: #059669;
  }

  /* Hide navigation, interactive elements, decorative blurs */
  nav,
  .print-hide,
  [class*="blur-3xl"] {
    display: none !important;
  }

  /* Force single-column layout — no sidebar grid in print */
  .report-grid {
    display: block !important;
  }

  .report-aside {
    position: static !important;
    display: block !important;
    margin-top: 1rem;
  }

  /* Section cards — visible borders on white, avoid page breaks inside */
  .section-card {
    background: white !important;
    border: 1px solid #d1d5db !important;
    break-inside: avoid;
    margin-bottom: 0.75rem;
    page-break-inside: avoid;
  }

  /* Page break after actie vereist section */
  .actie-vereist-section {
    break-after: page;
  }

  /* Print-only elements (PDF header/footer) */
  .pdf-only {
    display: block !important;
  }

  /* Ensure images print (satellite thumbnail) */
  img {
    max-width: 100% !important;
    page-break-inside: avoid;
  }

  /* Remove shadows in print */
  * {
    box-shadow: none !important;
    text-shadow: none !important;
  }

  /* Page margins for PDF */
  @page {
    margin: 1.5cm 1cm;
  }
}

/* Screen: hide print-only elements */
.pdf-only {
  display: none;
}
```

**Key decisions:**
- Override CSS custom properties inside `@media print` to invert the color scheme (research Pitfall 1). This avoids adding `html.light` class via JS which requires a timeout hack.
- Use `.report-grid` and `.report-aside` class names — these will be added to the grid container and aside element in ReportDetailPage.tsx.
- Use `.section-card` class — each section component already uses `rounded-2xl border border-overlay/[0.08] bg-grey-900` which we will add this class to.
- `break-inside: avoid` with `page-break-inside: avoid` fallback for older browsers.
- `-webkit-print-color-adjust: exact` ensures background colors print (for severity badges).
