   - **ECLI regex validator:**
     ```python
     _ECLI_RE = re.compile(r'^ECLI:[A-Z]{2}:[A-Z0-9]{1,7}:\d{4}:[A-Z0-9.]{1,25}$', re.IGNORECASE)
     def validate_ecli(ecli: str) -> bool:
         return bool(_ECLI_RE.match(ecli.strip()))
     ```

   - **Helper function** `_text(element, tag)` that returns element text or empty string.

   - **`RechtspraakClient` class** with two methods:

     a. `search_jurisprudence(query, client, max_results=10, sort="DESC")`:
        - Build params dict: `searchterms=query`, `subject=OMGEVINGSRECHT_URI` (hardcoded omgevingsrecht filter per RECHT-01), `max=max_results`, `sort=sort`, `return=DOC` (only results with available documents).
        - Use `async with rechtspraak_limiter:` then `retry_with_backoff(lambda: client.get(SEARCH_URL, params=params, timeout=15.0), source="rechtspraak")`.
        - Parse response with `etree.fromstring(response.content, parser=_parser)`.
        - Extract entries from Atom feed using `{ATOM_NS}entry` xpath.
        - For each entry: extract ecli (id), title, summary, updated date.
        - Validate ECLI format; skip entries with invalid ECLI.
        - Normalize summary: if summary is "-" or empty, set to "".
        - Return list of dicts.
        - Error handling: `httpx.TimeoutException` -> `APITimeoutError("rechtspraak", "...")`, `httpx.RequestError` -> `APITimeoutError("rechtspraak", "...")`, `etree.XMLSyntaxError` -> `GovernmentAPIError("rechtspraak", "...")`. **Always use two-arg signature.**

     b. `get_jurisprudence_document(ecli, client)`:
        - Build params: `id=ecli`.
        - Use `async with rechtspraak_limiter:` then `retry_with_backoff(...)`.
        - If 404: return None.
        - Parse XML with lxml `_parser`.
        - Extract content: iterate `root.iter()`, match local name `uitspraak` or `conclusie`, get `itertext()`.
        - Extract metadata: `creator` -> instantie, `issued` -> datum_uitspraak via local name matching.
        - Return dict with ecli, text, instantie, datum_uitspraak.
        - On XML parse error: raise `GovernmentAPIError("rechtspraak", "Failed to parse document XML")`. Do NOT silently return None or error dicts — follow the three-state contract.

   - **Module-level singleton:** `rechtspraak_client = RechtspraakClient()`
