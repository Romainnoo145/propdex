**Mocking strategy (CRITICAL):** Mock INTERNAL orchestration functions at the `app.services.property_aggregator` module level — NOT external API clients. This follows the Phase 9 pattern.

Functions to mock:
- `app.services.property_aggregator.resolve_address` — returns `AddressResolution` with address + building data
- `app.services.property_aggregator.fetch_zoning_data` — returns `ZoningData | None`
- `app.services.property_aggregator.fetch_monument_status` — returns `MonumentStatus | None`
- `app.services.property_aggregator.get_cached_or_fetch` — for cadastral parcel fetching (used inside nested `fetch_cadastral_parcels`)

Use `arq_pool=None` for all tests (AI parsing tested separately in Phase 9).

**Test cases to implement (~10 tests):**

1. `test_full_orchestration_all_sections_available` — Mock all functions returning valid data. Verify: result has address, building, zoning, monuments, cadastral_parcels, completeness_score > 0.5, data_sources includes "BAG API v2", section_sources populated.

2. `test_address_not_found_raises_404` — Mock `resolve_address` raising `APINotFoundError`. Verify: HTTPException with status 404 raised.

3. `test_address_upstream_error_raises_502` — Mock `resolve_address` raising `GovernmentAPIError`. Verify: HTTPException with status 502 raised.

4. `test_partial_failure_zoning_unavailable` — Mock `fetch_zoning_data` raising an Exception. Verify: result still has address/building, zoning is None, errors list contains zoning error message, completeness_score reflects missing section.

5. `test_partial_failure_monuments_unavailable` — Mock `fetch_monument_status` raising an Exception. Similar verification to zoning test.

6. `test_partial_failure_cadastral_unavailable` — Mock `get_cached_or_fetch` raising an Exception inside cadastral fetch. Verify: cadastral_parcels is empty, other sections still populated.

7. `test_no_coordinates_skips_parallel_fetches` — Mock `resolve_address` returning address with building that has no geometry. Verify: zoning, monuments, cadastral are all None/empty (parallel fetches skipped). Completeness score reflects only address section.

8. `test_polygon_geometry_extracts_centroid` — Mock `resolve_address` returning building with Polygon geometry. Verify: parallel fetches are called (coordinates were extracted from polygon).

9. `test_completeness_score_calculation` — Mock all sections as available. Verify score is 5/6 (since arq_pool=None means AI parsing is "not_available"). Then mock with no building/zoning/monuments — verify lower score.

10. `test_ai_parsing_section_without_arq_pool` — Verify that when arq_pool=None, ai_parsing section has status "not_available" with appropriate error message.
