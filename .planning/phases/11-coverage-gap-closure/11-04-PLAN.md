**Test cases to implement (~12 tests):**

**Save endpoint (POST /api/reports):**
1. `test_save_report_returns_201` — POST with valid report_data + auth token. Verify: 201 status, response has "id", "report_name" derived from address, "postcode", "city".

2. `test_save_report_without_auth_returns_401` — POST without auth header. Verify: 401.

3. `test_save_report_with_notes` — POST with report_data and notes="Important property". Verify: 201, response.notes == "Important property".

**Get endpoint (GET /api/reports/:id):**
4. `test_get_report_returns_detail` — Create report via POST, then GET /api/reports/{id}. Verify: 200, response has report_data JSONB, report_name, timestamps.

5. `test_get_nonexistent_report_returns_404` — GET /api/reports/{random_uuid}. Verify: 404.

**Delete endpoint (DELETE /api/reports/:id):**
6. `test_delete_report_soft_deletes` — Create report via POST, DELETE it, then GET it. Verify: DELETE returns 200 with "deleted" message, subsequent GET returns 404 (soft-deleted).

7. `test_delete_nonexistent_report_returns_404` — DELETE /api/reports/{random_uuid}. Verify: 404.

**PDF export (GET /api/reports/:id/export/pdf):**
8. `test_export_pdf_returns_pdf_content` — Create report, then GET /api/reports/{id}/export/pdf. Verify: 200, content-type is "application/pdf", content-disposition has filename, response body has bytes. Note: This calls real WeasyPrint — may need `asyncio.to_thread` to not block. If WeasyPrint is not available in test env, mock `generate_report_pdf` at the router level.

9. `test_export_pdf_without_auth_returns_401` — GET /api/reports/{uuid}/export/pdf without auth. Verify: 401.

**Freshness endpoint (GET /api/reports/:id/freshness):**
10. `test_freshness_check_returns_result` — Create report with section_sources, then GET /api/reports/{id}/freshness. Verify: 200, response has "report_id", "has_updates", "updated_sections" keys.

11. `test_freshness_without_auth_returns_401` — GET /api/reports/{uuid}/freshness without auth. Verify: 401.

**Multi-tenant isolation:**
12. `test_cross_org_report_access_returns_404` — Create two orgs with users. Org A saves report. Org B tries to GET /api/reports/{report_a_id}. Verify: 404 (not 403). This prevents resource enumeration.
