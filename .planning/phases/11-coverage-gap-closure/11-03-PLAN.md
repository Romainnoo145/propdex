**Key insight:** The lookup endpoint calls `aggregate_property_data` which requires external APIs. For HTTP-level tests, mock `aggregate_property_data` at the router level (`app.services.property_aggregator.aggregate_property_data`) to return a valid `PropertyReportResponse`. This tests the router/auth/validation layer without hitting external services.

Similarly, mock `_pdok_client.suggest` for the suggest endpoint.

**Auth token pattern (from test_auth_flow.py):**
```python
async def _get_auth_token(client, email, password="TestPass123!"):
    """Helper to login and get access token."""
    resp = await client.post("/auth/login", json={"email": email, "password": password})
    return resp.json()["access_token"]
```

**App state setup:** The router accesses `request.app.state.http_client` and `request.app.state.arq_pool`. These must be set on the app before tests run. Set them as mock objects in a fixture or at top of test module:
```python
from unittest.mock import AsyncMock, MagicMock
from app.main import app

# Set mock app state before tests
app.state.http_client = AsyncMock()
app.state.arq_pool = None  # AI parsing not needed for router tests
```

**Test cases to implement (~8 tests):**

1. `test_lookup_without_auth_returns_401` — POST /api/properties/lookup without Authorization header. Verify: 401 status.

2. `test_lookup_invalid_postcode_returns_422` — POST /api/properties/lookup with auth but invalid postcode (e.g., "invalid"). Verify: 422 validation error.

3. `test_lookup_success_returns_property_report` — Mock `aggregate_property_data` to return a valid `PropertyReportResponse`. POST /api/properties/lookup with auth + valid input. Verify: 200 status, response has "address", "completeness_score", "data_sources" keys.

4. `test_lookup_address_not_found_returns_404` — Mock `aggregate_property_data` raising `HTTPException(404)`. POST /api/properties/lookup. Verify: 404 status with "not found" in detail.

5. `test_lookup_upstream_error_returns_502` — Mock `aggregate_property_data` raising `HTTPException(502)`. POST /api/properties/lookup. Verify: 502 status.

6. `test_suggest_without_auth_returns_401` — GET /api/properties/suggest?q=Amsterdam without auth. Verify: 401.

7. `test_suggest_short_query_returns_400` — GET /api/properties/suggest?q=A with auth. Verify: 400 with "at least 2 characters" message.

8. `test_suggest_success_returns_suggestions` — Mock `_pdok_client.suggest` to return a list of suggestion dicts. GET /api/properties/suggest?q=Amsterdam with auth. Verify: 200 status, response is a list.
