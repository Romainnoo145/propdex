These tests use real database (test_db fixture) since freshness detection queries Organization and CachedAPIResponse tables directly.

**Test data setup pattern:** For each test, create Organization (with specific threshold), SavedReport (with section_sources in report_data containing cached_at timestamps), and CachedAPIResponse entries (with fetched_at timestamps). Use `datetime.utcnow()` for all timestamps (naive UTC, NOT timezone-aware).

**Test cases to implement (~10 tests):**

1. `test_freshness_exceeds_threshold_flags_update` — Create org with 24h threshold. Report has zoning section cached_at 48h ago. Create newer cache entry (fetched_at now). Verify: has_updates=True, updated_sections has 1 entry for "zoning" with age_hours >= 24.

2. `test_freshness_within_threshold_no_update` — Create org with 48h threshold. Report has zoning cached_at 12h ago. Cache entry fetched_at 24h ago. Verify: has_updates=False, updated_sections is empty (age diff < threshold).

3. `test_multiple_sections_mixed_freshness` — Report has both "zoning" and "monuments" sections. Zoning is stale (exceeds threshold), monuments are fresh. Verify: has_updates=True, updated_sections contains only "zoning".

4. `test_org_custom_threshold_respected` — Create org with custom freshness_threshold_hours=72. Report cached_at 50h ago, cache entry now. Age diff = 50h. Verify: has_updates=False (50 < 72 threshold).

5. `test_min_threshold_enforced` — Create org with freshness_threshold_hours=0 (below system minimum). Verify: system minimum (from settings.MIN_FRESHNESS_THRESHOLD_HOURS) is used instead. Create data that exceeds system minimum but not 0. Verify it IS flagged as stale.

6. `test_no_organization_uses_default_threshold` — Pass a non-existent organization_id. Verify: uses default 24h threshold (max(24, settings.MIN_FRESHNESS_THRESHOLD_HOURS)).

7. `test_missing_cached_at_in_section_skips` — Report has section_source with no "cached_at" key. Verify: section is skipped, has_updates=False.

8. `test_no_cache_entry_for_section_skips` — Report has valid section_source with cached_at, but no matching CachedAPIResponse in database. Verify: section skipped, has_updates=False.

9. `test_invalid_iso_timestamp_skips` — Report has section_source with "cached_at": "not-a-date". Verify: section skipped gracefully (no crash), has_updates=False.

10. `test_section_to_cache_mapping_all_sections` — Verify each section type maps to correct cache key patterns. Create report with sections "zoning", "monuments", "address". Create cache entries with matching patterns ("dso:*", "rce:*", "bag:*"). Verify: all three sections are evaluated correctly.
