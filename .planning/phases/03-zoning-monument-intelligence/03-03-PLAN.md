Build the RCE Rijksmonument API client and monument aggregation service. The client queries the RCE Solr API using WGS84 coordinates (requiring pyproj coordinate transformation from RD). The aggregator fetches monument status from three sources in parallel (RCE, BAG indicators, Kadaster indicators), detects conflicts between sources, and generates plain-language heritage restriction summaries.

Purpose: Monument/heritage status is critical for property investment decisions -- a rijksmonument has severe renovation restrictions that can cost hundreds of thousands of euros. Multi-source checking (per user decision: RCE + BAG + Kadaster) catches cases where one registry is outdated.

Output: RCEMonumentClient class and fetch_monument_status function returning MonumentStatus with conflict detection.

**Coordinate transformer (module-level):**
```python
from pyproj import Transformer

# RD New (EPSG:28992) to WGS84 (EPSG:4326) transformer
# RCE API uses WGS84 lat/lon, while all other Dutch APIs use RD
_rd_to_wgs84 = Transformer.from_crs("EPSG:28992", "EPSG:4326", always_xy=True)

def rd_to_wgs84(x: float, y: float) -> tuple[float, float]:
    """Convert RD coordinates to WGS84 (longitude, latitude)."""
    lon, lat = _rd_to_wgs84.transform(x, y)
    return lon, lat
```

Also create a reverse transformer for use in map data:
```python
_wgs84_to_rd = Transformer.from_crs("EPSG:4326", "EPSG:28992", always_xy=True)

def wgs84_to_rd(lon: float, lat: float) -> tuple[float, float]:
    """Convert WGS84 coordinates to RD (x, y)."""
    x, y = _wgs84_to_rd.transform(lon, lat)
    return x, y
```

**Class: `RCEMonumentClient`**

BASE_URL: `"https://api.rijksmonumenten.info/select/"`

No constructor needed (no authentication, public API).

Methods:

1. `async def query_by_location(self, x: float, y: float, client: httpx.AsyncClient, distance_km: float = 0.05) -> list[dict]`:
   - Convert RD coordinates to WGS84: `lon, lat = rd_to_wgs84(x, y)`
   - Note: distance_km default is 0.05 (50 meters) — wider than research suggested 10m because building footprints can be offset from coordinates
   - Build Solr params:
     ```python
     params = {
         "q": "*:*",
         "fq": "{!geofilt}",
         "sfield": "abc_locatie",
         "pt": f"{lat},{lon}",  # NOTE: lat,lon order for Solr geofilt
         "d": str(distance_km),
         "wt": "json",
         "rows": 10,
     }
     ```
   - GET to BASE_URL with params, timeout=30.0
   - Parse response: `data.get("response", {}).get("docs", [])`
   - Note: RCE API may not use standard HTTP error codes the same way. Use a try/except around handle_api_response, and if it fails, try parsing the raw response for Solr error format instead.
   - Log: monument count found
   - Wrap httpx.TimeoutException as APITimeoutError
   - Return list of monument docs

2. `async def get_by_monument_number(self, monument_number: str, client: httpx.AsyncClient) -> dict | None`:
   - Solr query: `q=rce_objrijksnr:{monument_number}`
   - params: `{"q": f"rce_objrijksnr:{monument_number}", "wt": "json", "rows": 1}`
   - GET to BASE_URL
   - Return first doc or None

Create `backend/app/services/monument_aggregator.py` — orchestrates monument status checking from 3 sources with conflict detection.

**Main function: `async def fetch_monument_status(x: float, y: float, pand_id: str | None, verblijfsobject_id: str | None, client: httpx.AsyncClient, organization_id: uuid.UUID, session: AsyncSession, force_refresh: bool = False) -> MonumentStatus | None`**

Accept RD coordinates (x, y) plus optional BAG identifiers (pand_id, verblijfsobject_id) for BAG/Kadaster monument field lookups.

Flow — three parallel source fetches using asyncio.gather:

1. **RCE source fetch** (inner async function `_fetch_rce`):
   - cache_key: `f"rce:monument:{x}:{y}"`
   - Use get_cached_or_fetch with source="rce", force_refresh=force_refresh
   - fetch_fn calls `_rce_client.query_by_location(x, y, client)`
   - Parse RCE docs:
     - If docs found: `is_monument=True`, `monument_type="rijksmonument"`
     - Extract `monument_nummer` from doc field `rce_objrijksnr`
     - Extract `monument_naam` from doc field `rce_objnaam` or `abc_beschrijving`
   - Return MonumentSourceResult with source="RCE", is_monument, monument_type, monument_nummer, monument_naam, cached_at, age_seconds
   - On error: return MonumentSourceResult with source="RCE", is_monument=None, error=str(e)

2. **BAG source fetch** (inner async function `_fetch_bag_monument`):
   - Note per research pitfall 2: BAG monument fields may be linked, not embedded. The BAG verblijfsobject response may not have a direct monument field.
   - If verblijfsobject_id is None: return MonumentSourceResult with source="BAG", is_monument=None, error="Geen verblijfsobject ID beschikbaar"
   - Try to check if the existing BAG data (from Phase 2 address resolution) contains monument indicators.
   - For MVP: The BAG API v2 verblijfsobject endpoint may not expose monument status directly. Check for the field `heeftAlsNevenAdres` or any `monumenten` related field in the response data.
   - If no monument field found in BAG response: return MonumentSourceResult with source="BAG", is_monument=None, error="Monument status niet beschikbaar via BAG API"
   - This is an honest approach — we check but acknowledge when the data isn't available rather than pretending it is.
   - Do NOT make additional BAG API calls here — the verblijfsobject data should already be in cache from Phase 2. Use cache_manager to look it up.

3. **Kadaster source fetch** (inner async function `_fetch_kadaster_monument`):
   - Similar to BAG: Check if cached cadastral parcel data has monument indicators
   - Kadaster perceel data (from Phase 2 PDOK Cadastral) may have a monument field in properties
   - If no monument field found: return MonumentSourceResult with source="Kadaster", is_monument=None, error="Monument status niet beschikbaar via Kadaster API"
   - Honest about data availability

Execute all three with `asyncio.gather(return_exceptions=True)`.

**Conflict detection logic:**
```python
# Collect results that have definitive answers (is_monument is not None)
definitive_sources = [r for r in results if isinstance(r, MonumentSourceResult) and r.is_monument is not None]

# Check for conflicts
monument_statuses = {r.is_monument for r in definitive_sources}
has_conflict = len(monument_statuses) > 1  # Some say True, some say False

# If conflict, build Dutch conflict note
if has_conflict:
    positive = [r.source for r in definitive_sources if r.is_monument]
    negative = [r.source for r in definitive_sources if not r.is_monument]
    conflict_note = f"{', '.join(positive)} registreert dit als monument, {', '.join(negative)} geeft geen monumentstatus aan"
```

**Consensus status:**
- If all definitive sources agree is_monument=True and any says "rijksmonument": `consensus_status = "rijksmonument"`
- If all agree True and type is gemeentelijk: `consensus_status = "gemeentelijk_monument"`
- If all agree False: `consensus_status = "geen_monument"`
- If conflict or no definitive sources: `consensus_status = None`

For geen_monument or None: empty list
