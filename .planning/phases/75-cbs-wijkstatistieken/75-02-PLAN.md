<objective>
Rewrite the CBS OData client from deprecated v3 to v4 API and harden with rate limiting, retries, and timeouts per project conventions.

Purpose: The existing CBS client uses the deprecated `opendata.cbs.nl` v3 endpoint with broken `substringof()` filters, v3-only entities (`TypedDataSet`, `WijkenEnBuurten`), a stale dataset ID (85618NED = 2023), and has no rate limiter or timeout. This plan rewrites it to use the v4 endpoint (`datasets.cbs.nl`) with correct entity model and hardens it per established government API patterns.

Output: Rewritten cbs_odata.py, cbs_odata_limiter in rate_limiter.py, CBS_DATASET_ID in config.py, and gemeente_code passed from area_scan job.
</objective>

    **cbs_odata.py (FULL REWRITE):**
    Replace entire file content with a v4-compatible CBS client. Key requirements:

    1. **Imports**: `httpx`, `logging`, `GovernmentAPIError` + `retry_with_backoff` from `base.py`, `cbs_odata_limiter` from `rate_limiter.py`, `settings` from `core.config`

    2. **Constants**:
       - `BASE_URL = "https://datasets.cbs.nl/odata/v1/CBS"`
       - `MEASURE_CODES` dict mapping human keys to CBS codes:
         ```python
         MEASURE_CODES = {
             "woz": "M001642",            # Gemiddelde WOZ-waarde van woningen
             "stedelijkheid": "ST0001",    # Mate van stedelijkheid (1-5)
             "oad": "ST0003",             # Omgevingsadressendichtheid
             "inwoners": "T001036",       # Aantal inwoners
             "woningvoorraad": "M000297", # Woningvoorraad
             "koopwoningen": "1014800",   # Koopwoningen
             "huurwoningen": "1014850_2", # Huurwoningen totaal
             "dichtheid": "M000100",      # Bevolkingsdichtheid
             "inkomen": "M000223",        # Gemiddeld inkomen per inkomensontvanger
         }
         ```
       - `DATASET_PEILJAAR` dict mapping dataset IDs to years: `{"85318NED": 2022, "85618NED": 2023, "85984NED": 2024, "86165NED": 2025}`
       - `STEDELIJKHEID_MAP` dict: `{1: "Zeer sterk stedelijk", 2: "Sterk stedelijk", 3: "Matig stedelijk", 4: "Weinig stedelijk", 5: "Niet stedelijk"}`

    3. **Class `CBSODataClient`**:
       - `__init__(self)`: store `self.dataset_id = settings.cbs_dataset_id`, `self.peiljaar = DATASET_PEILJAAR.get(self.dataset_id, 2025)`
       - `_headers` property: `{"Accept": "application/json", "User-Agent": "Propdex/1.0"}`

       - `async def _resolve_wijk_identifier(self, client, gemeente_code, wijk_naam) -> str | None`:
         - Use `cbs_odata_limiter` as async context manager
         - GET `{BASE_URL}/{dataset_id}/WijkenEnBuurtenCodes` with params:
           `$filter=startswith(Identifier, 'WK{gemeente_code}')`, `$top=50`
         - `timeout=10.0` on the request
         - Filter results in Python: case-insensitive `wijk_naam.lower() in record["Title"].lower()`
         - Return `match["Identifier"]` or `None`
         - On error: log warning, return None (non-fatal)

       - `async def _resolve_gemeente_identifier(self, client, gemeente_code) -> str | None`:
         - Similar to wijk but with `$filter=startswith(Identifier, 'GM{gemeente_code}')`, `$top=1`
         - Return first match `Identifier` or None

       - `async def _fetch_observations(self, client, region_identifier) -> dict[str, float | None]`:
         - Build measure filter: `" or ".join(f"Measure eq '{code}'" for code in MEASURE_CODES.values())`
         - Use `cbs_odata_limiter`
         - GET `{BASE_URL}/{dataset_id}/Observations` with params:
           `$filter=WijkenEnBuurten eq '{region_identifier}' and ({measure_filter})`
           `$select=Measure,Value,ValueAttribute`
         - `timeout=10.0`
         - Build result dict: for each observation, only use `Value` when `ValueAttribute` is empty string `""` — otherwise treat as None. Use a reverse lookup from MEASURE_CODES to get human keys.
         - On error: raise `GovernmentAPIError("cbs", f"Failed to fetch observations: {detail}")`

       - `async def get_neighborhood_data(self, client, gemeente_naam, wijk_naam=None, gemeente_code=None) -> dict | None`:
         - **Signature change**: add `gemeente_code: str | None = None` parameter
         - If `gemeente_code` and `wijk_naam`: try `_resolve_wijk_identifier(client, gemeente_code, wijk_naam)`
         - If no wijk found and `gemeente_code`: try `_resolve_gemeente_identifier(client, gemeente_code)`
         - If no `gemeente_code`: log warning and return None (cannot do safe lookup without code)
         - If no identifier resolved: return None
         - Call `_fetch_observations(client, identifier)`
         - Build and return output dict matching current structure:
           ```python
           {
               "bron": "CBS StatLine OData v4",
               "dataset": f"{self.dataset_id} - Kerncijfers wijken en buurten",
               "peiljaar": self.peiljaar,
               "data": {
                   "gemiddelde_woz_waarde": data.get("woz"),
                   "stedelijkheid": {
                       "klasse": int(mvs) if (mvs := data.get("stedelijkheid")) else None,
                       "omschrijving": STEDELIJKHEID_MAP.get(int(mvs), "Onbekend") if mvs else "Onbekend",
                       "omgevingsadressendichtheid": data.get("oad"),
                   },
                   "demografie": {
                       "aantal_inwoners": data.get("inwoners"),
                       "percentage_huurwoningen": data.get("huurwoningen"),
                       "percentage_koopwoningen": data.get("koopwoningen"),
                   },
                   "bouwjaar_distributie": {
                       "percentage_bouwjaar_voor_2000": None,  # v4 uses rolling 10yr, not pre-2000
                       "percentage_bouwjaar_vanaf_2000": None,  # Omit to avoid misleading labels
                   },
               },
           }
           ```
         - NOTE on bouwjaar: The v4 measure codes M008209/M008210 are "meer dan 10 jaar geleden" / "afgelopen 10 jaar" (rolling window), NOT the old pre-2000/post-2000 boundary. Set these to None to avoid misleading users. The research flagged this as an open question. Safe to omit since WijkDetailView never displayed bouwjaar_distributie before.

    4. Module-level singleton: `cbs_client = CBSODataClient()`
