1. `addWijkBoundariesLayer(map, geojson, onWijkClick)`:
   - **Source**: GeoJSON source with `promoteId: 'statcode'` (same as gemeente)
   - **Fill layer** (`wijk-fill`):
     - Color: `#10b981` (emerald green, distinct from gemeente blue `#3b82f6`)
     - Opacity: feature-state hover `0.4` / default `0.2`
   - **Line layer** (`wijk-line`):
     - Color: `#10b981`, width: `2`, opacity: `0.8`
   - **Label layer** (`wijk-labels`):
     - Type: `symbol`
     - Layout: `text-field: ['get', 'statnaam']`, `text-size: 12`, `text-anchor: 'center'`
     - Paint: `text-color: '#065f46'` (dark emerald), `text-halo-color: '#ffffff'`, `text-halo-width: 1.5`
     - `minzoom: 12` (only show labels at gemeente zoom level, not NL overview)
   - **Layer insertion**: Insert BEFORE `gemeente-fill` layer if it exists (wijken are smaller, render on top). Use `const beforeLayer = map.getLayer('gemeente-fill') ? 'gemeente-fill' : undefined;`
   - **Click handler**:
     - Extract `statcode` and `statnaam` from `feature.properties`
     - CRITICAL: Look up full geometry from the geojson parameter (NOT from rendered feature) -- MapLibre clips rendered features at tile boundaries when zoomed in. Store geojson in module-level variable `let wijkGeoJSONData: GeoJSON.FeatureCollection | null = null;` for lookup.
     - Calculate bbox using `calculateBboxFromGeometry` from `@/lib/geo-utils`
     - Call `onWijkClick(statcode, statnaam, bbox, geometry)`
   - **onWijkClick callback signature**:
     ```typescript
     onWijkClick: (
       wijkCode: string,
       wijkNaam: string,
       bbox: [number, number, number, number],
       geometry: GeoJSON.Polygon | GeoJSON.MultiPolygon
     ) => void
     ```
   - **Hover handlers**: IDENTICAL pattern to gemeente layer -- mousemove sets feature-state hover, mouseleave clears it, mouseenter sets cursor to pointer

2. `removeWijkBoundariesLayer(map)`:
   - Clear `hoveredWijkId` and `wijkGeoJSONData`
   - Reset cursor
   - Remove layers: labels, line, fill (order matters -- labels first)
   - Remove source

3. `setWijkBoundariesVisibility(map, visible)`:
   - Toggle visibility for all 3 layers (fill, line, labels)
   - Same pattern as gemeente visibility toggle
