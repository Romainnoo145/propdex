**Helper function:**
```python
async def _get_favorite_or_404(db, org_id, user_id, parcel_id) -> ParcelFavorite:
    result = await db.execute(
        select(ParcelFavorite).where(
            ParcelFavorite.organization_id == org_id,
            ParcelFavorite.user_id == user_id,
            ParcelFavorite.parcel_id == parcel_id,
        )
    )
    fav = result.scalar_one_or_none()
    if not fav:
        raise HTTPException(status_code=404, detail="Favorite not found")
    return fav
```

**Endpoint 1: POST /api/parcels/favorites** (BACK-02)
- `@limiter.limit("30/minute")`
- Accepts `FavoriteCreate` body
- Idempotent: check existing by (org_id, user_id, parcel_id). If exists, return it with status 200 (NOT 201)
- If new: create ParcelFavorite with pipeline_stage="Gesignaleerd", db.add() + await db.commit() + await db.refresh()
- Return `FavoriteResponse` with status_code=201 for new
- CRITICAL: Use `db.add(fav)` / `await db.commit()` — NEVER `async with db.begin()`

**Endpoint 2: GET /api/parcels/favorites** (BACK-02)
- `@limiter.limit("30/minute")`
- Returns list[FavoriteResponse] for current user in current org
- `select(ParcelFavorite).where(org_id, user_id).order_by(ParcelFavorite.created_at.desc())`

**Endpoint 3: DELETE /api/parcels/favorites/{parcel_id}** (BACK-02)
- `@limiter.limit("30/minute")`
- parcel_id is path param (str) — Kadaster string with hyphens, FastAPI handles fine
- Use _get_favorite_or_404, then `await db.delete(fav)` + `await db.commit()`
- Return 204 No Content (use `status_code=204, response_class=Response` from starlette)

**Endpoint 4: PATCH /api/parcels/favorites/{parcel_id}/pipeline** (BACK-03)
- `@limiter.limit("30/minute")`
- Accepts `PipelineUpdateRequest` body — Pydantic Literal validates stage automatically (422 for invalid)
- Use _get_favorite_or_404, update fav.pipeline_stage = body.stage
- If body.stage == "Afgerond": also set fav.afgerond_reden = body.afgerond_reden, fav.notitie = body.notitie
- If body.stage != "Afgerond": clear fav.afgerond_reden = None, fav.notitie = None
- `await db.commit()` + `await db.refresh(fav)`
- Return FavoriteResponse

**Endpoint 5: GET /api/portfolio** (BACK-04)
- On `portfolio_router`, NOT `router`
- `@limiter.limit("30/minute")`
- Single GROUP BY query — no N+1:
```python
rows = (await db.execute(
    select(
        ParcelFavorite.gemeente_code,
        ParcelFavorite.gemeente_naam,
        ParcelFavorite.wijk_naam,
        func.count(ParcelFavorite.id).label("parcel_count"),
    )
    .where(ParcelFavorite.organization_id == organization_id)
    .group_by(
        ParcelFavorite.gemeente_code,
        ParcelFavorite.gemeente_naam,
        ParcelFavorite.wijk_naam,
    )
    .order_by(ParcelFavorite.gemeente_naam, ParcelFavorite.wijk_naam)
)).all()
```
- Aggregate in Python: build dict[gemeente_code, PortfolioGemeenteGroup] with wijken list and total_count
- Return PortfolioResponse with total_favorites sum

All endpoints use `Depends(get_current_active_user)` and `Depends(get_current_organization_id)` for auth + tenant isolation. Use `datetime.utcnow()` if needed (NEVER `datetime.now(timezone.utc)`).
