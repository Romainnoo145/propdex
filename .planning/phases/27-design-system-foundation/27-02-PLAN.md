    **Button.tsx** — Primary action primitive. Use CVA with forwardRef.

    Variants (per user decision: amber = primary action, teal = secondary):
    - `primary`: `bg-amber-accent text-grey-950 hover:bg-amber-accent-hover focus-visible:ring-amber-accent` — solid amber fill, dark text
    - `secondary`: `bg-teal-accent text-white hover:bg-teal-accent-hover focus-visible:ring-teal-accent` — teal for secondary interactive
    - `ghost`: `text-grey-100 hover:bg-grey-850 focus-visible:ring-grey-800` — minimal, transparent
    - `outline`: `border border-grey-800 bg-transparent text-grey-100 hover:bg-grey-900 focus-visible:ring-grey-800` — bordered
    - `destructive`: `bg-error text-white hover:bg-error/90 focus-visible:ring-error` — danger actions

    Sizes (compact/dense per user decision):
    - `sm`: `h-7 px-2.5 text-xs gap-1.5` — 28px height
    - `md`: `h-8 px-3 text-sm gap-2` — 32px height
    - `lg`: `h-9 px-4 text-sm gap-2` — 36px height

    Base classes: `inline-flex items-center justify-center rounded-md font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:ring-offset-grey-950 disabled:pointer-events-none disabled:opacity-50`

    Default: `variant: 'primary', size: 'md'`

    Export: `Button` (forwardRef), `ButtonProps`, `buttonVariants` (for extending).

    **Card.tsx** — Surface container with layered grey elevation system (NOT glassmorphism per user decision).

    Props: `elevation?: 'base' | 'card' | 'elevated'` (default: 'card')
    - `base`: `bg-grey-950` (#111)
    - `card`: `bg-grey-900` (#1A1A1A)
    - `elevated`: `bg-grey-850` (#222)

    All elevations get: `rounded-md border border-grey-800`

    Subcomponents (all forwardRef, accept className):
    - `CardHeader`: `flex flex-col gap-1.5 p-4`
    - `CardTitle`: `text-lg font-semibold text-grey-100`
    - `CardContent`: `p-4 pt-0`
    - `CardFooter`: `flex items-center p-4 pt-0`

    **Badge.tsx** — Status indicator with filled muted pattern (per Claude's discretion: muted fills work best for data-dense dark interfaces).

    Variants using CVA:
    - `default`: `bg-grey-850 text-grey-100 border border-grey-800`
    - `success`: `bg-success/15 text-success border border-success/25`
    - `error`: `bg-error/15 text-error border border-error/25`
    - `warning`: `bg-warning/15 text-warning border border-warning/25`
    - `info`: `bg-info/15 text-info border border-info/25`
    - `amber`: `bg-amber-accent/15 text-amber-accent border border-amber-accent/25`
    - `teal`: `bg-teal-accent/15 text-teal-accent border border-teal-accent/25`

    Base: `inline-flex items-center rounded-sm px-2 py-0.5 text-xs font-medium`

  <action>
    **Input.tsx** — Form input with recessed dark styling (per Claude's discretion: recessed/inset fits the layered grey system — the input appears "sunken" into the surface).

    Base classes:
    ```
    flex h-8 w-full rounded-md border border-grey-800 bg-grey-950 px-3 py-1.5 text-sm text-grey-100
    placeholder:text-grey-600
    focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-teal-accent focus-visible:border-teal-accent
    disabled:cursor-not-allowed disabled:opacity-50
    file:border-0 file:bg-transparent file:text-sm file:font-medium file:text-grey-100
    ```

    Note: bg-grey-950 (darkest) on a bg-grey-900 card creates the "recessed" effect.
    Focus ring is teal (secondary interactive color per user decision).
    Height h-8 (32px) matches dense/compact aesthetic.

    Props: extends `InputHTMLAttributes<HTMLInputElement>`. Use forwardRef.
    Export: `Input`, `InputProps`.

    **Select.tsx** — Native select with custom dark styling and ChevronDown icon from lucide-react.

    Structure: wrapper `<div>` containing native `<select>` + absolute-positioned ChevronDown icon.

    Select classes:
    ```
    flex h-8 w-full appearance-none rounded-md border border-grey-800 bg-grey-950 pl-3 pr-8 py-1.5 text-sm text-grey-100
    focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-teal-accent focus-visible:border-teal-accent
    disabled:cursor-not-allowed disabled:opacity-50
    ```

    ChevronDown icon: `absolute right-2 top-1/2 -translate-y-1/2 pointer-events-none text-grey-400` with `size={14}`.

    `appearance-none` hides native browser dropdown arrow. The custom ChevronDown replaces it.

    Props: extends `SelectHTMLAttributes<HTMLSelectElement>`. Use forwardRef. Accept `children` for `<option>` elements.
    Export: `Select`, `SelectProps`.

    **index.ts** — Barrel export for convenient imports:
    ```typescript
    export { Button, type ButtonProps, buttonVariants } from './Button';
    export { Card, CardHeader, CardTitle, CardContent, CardFooter, type CardProps } from './Card';
    export { Badge, type BadgeProps } from './Badge';
    export { Input, type InputProps } from './Input';
    export { Select, type SelectProps } from './Select';
    ```

    This enables `import { Button, Card, Input } from '@/components/primitives'`.
