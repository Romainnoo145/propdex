  <action>
    1. Initialize Storybook via CLI (this is the recommended approach — handles all config, peer deps, and framework detection):
       ```bash
       cd frontend && npx storybook@latest init --builder vite --type react --yes --skip-install
       ```
       The `--skip-install` flag prevents auto-install so we can use pnpm. After init:
       ```bash
       cd frontend && pnpm install
       ```

    2. After Storybook init, the CLI may create example stories in `src/stories/`. Delete any auto-generated example files (Button.tsx, Header.tsx, Page.tsx, etc.) — we want ONLY our primitives:
       ```bash
       rm -rf frontend/src/stories/*.tsx frontend/src/stories/*.ts frontend/src/stories/*.css frontend/src/stories/*.mdx 2>/dev/null
       ```

    3. Update `frontend/.storybook/main.ts` to include our primitives directory and configure path aliases:
       ```typescript
       import type { StorybookConfig } from '@storybook/react-vite';
       import { mergeConfig } from 'vite';
       import path from 'path';

       const config: StorybookConfig = {
         stories: ['../src/stories/**/*.stories.@(ts|tsx)'],
         addons: ['@storybook/addon-essentials'],
         framework: {
           name: '@storybook/react-vite',
           options: {},
         },
         viteFinal: (config) => {
           return mergeConfig(config, {
             resolve: {
               alias: {
                 '@': path.resolve(__dirname, '../src'),
               },
             },
           });
         },
       };

       export default config;
       ```
       IMPORTANT: The `viteFinal` is needed so `@/components/primitives` import alias works in Storybook. Without it, Storybook cannot resolve `@/` imports.

    4. Update `frontend/.storybook/preview.tsx` (create if not exists) for dark background and Tailwind:
       ```tsx
       import type { Preview } from '@storybook/react';
       import '../src/styles/index.css';

       const preview: Preview = {
         parameters: {
           backgrounds: {
             default: 'dark',
             values: [
               { name: 'dark', value: '#111111' },
               { name: 'card', value: '#1A1A1A' },
               { name: 'elevated', value: '#222222' },
             ],
           },
           controls: {
             matchers: {
               color: /(background|color)$/i,
               date: /Date$/i,
             },
           },
         },
       };

       export default preview;
       ```
       The `import '../src/styles/index.css'` loads all @theme tokens into Storybook.
       Dark background as default ensures components are tested as they will appear in production.

    5. Create `frontend/src/stories/primitives/` directory and add stories:

         - `Disabled`: args { children: 'Disabled', disabled: true }

       **Card.stories.tsx:**

       - Stories:

       **Badge.stories.tsx:**
