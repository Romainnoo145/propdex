3. Create `backend/app/professionals/router.py`:
   - `router = APIRouter(prefix="/api/professionals", tags=["professionals"])`
   - `require_admin_key` dependency:
     ```python
     def require_admin_key(x_admin_key: str = Header(alias="X-Admin-Key")) -> None:
         if not settings.ADMIN_API_KEY or x_admin_key != settings.ADMIN_API_KEY:
             raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Admin access required")
     ```
     When ADMIN_API_KEY is empty string, ALL admin requests are rejected (disabled mode). This prevents accidental open admin in dev.

   - **GET ""** (list_professionals): `response_model=ProfessionalListResponse`
     - Depends: `get_current_active_user` (auth gate), `get_db`
     - Query params: `gemeente: str | None = None`, `gevolgklasse: str | None = None`
     - Build query: `select(Professional).where(Professional.is_active == True)`
     - If gemeente: `.where(text("(:gemeente) = ANY(werkgebied)").bindparams(gemeente=gemeente))`
     - If gevolgklasse: `.where(text("gevolgklassen @> ARRAY[:gk]::text[]").bindparams(gk=gevolgklasse))`
     - Order by `Professional.naam`
     - Return ProfessionalListResponse with total count

   - **POST ""** (create_professional): `response_model=ProfessionalResponse, status_code=201`
     - Depends: `require_admin_key`, `get_db`
     - Body: ProfessionalCreate
     - `db.add(Professional(**data.model_dump()))`, `db.flush()`, `db.commit()`, `db.refresh()`
     - Return ProfessionalResponse

   - **PUT "/{professional_id}"** (update_professional): `response_model=ProfessionalResponse`
     - Depends: `require_admin_key`, `get_db`
     - Path param: `professional_id: uuid.UUID`
     - Body: ProfessionalUpdate
     - Fetch by id, 404 if not found
     - Apply `data.model_dump(exclude_unset=True)` via setattr loop
     - `db.flush()`, `db.commit()`, `db.refresh()`

   - **DELETE "/{professional_id}"** (deactivate_professional): `status_code=204`
     - Depends: `require_admin_key`, `get_db`
     - Soft delete: set `is_active = False`
     - 404 if not found

   Apply rate limiting: 30/min on GET list, 10/min on admin endpoints (consistent with reports router pattern). Use `@limiter.limit()` with `get_remote_address` key.

4. Register router in `backend/app/main.py`:
   - Add `from app.professionals.router import router as professionals_router`
   - Add `app.include_router(professionals_router)` after existing router registrations
