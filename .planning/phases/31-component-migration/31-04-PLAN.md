### DS-04 Rule Reminder
- Navigation chrome + data panels = solid `bg-grey-900` (NO backdrop-blur)
- Floating map cards = `bg-grey-900/90 backdrop-blur-md` (keep blur for map overlays)
- InspectorPanel is navigation chrome → solid background
- map.tsx inline floating elements (scan controls, progress) → keep `backdrop-blur-md` as they float over map canvas
