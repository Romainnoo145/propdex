const isParcelsVisibleRef = useRef(layerState.showParcels)

**5. Replace callback-based toggle handlers with direct hook calls:**

Remove these callback functions (they were the sync bridge):
- `handleParcelsLayerToggle` — replace with passing `layerActions.toggleParcels` to LayerToggle
- `handleGemeentenToggle` — replace with logic that calls `layerActions.toggleGemeenten()` AND manages gemeente context (activateGemeenteContext / deactivate). The toggle handler must stay in map.tsx because gemeenten toggle has side effects (loading wijken, setting activeGemeente).
- `handleBestemmingsplanToggle` — replace with passing `layerActions.toggleBestemmingsplan` to LayerToggle
- `handleWijkenToggle` — already removed in uncommitted changes

For gemeenten specifically, the toggle handler must:
```typescript
const handleGemeentenToggle = useCallback(() => {
  const next = !layerState.showGemeenten
  layerActions.setGemeenten(next)
  if (!next && mapRef.current) {
    // Turning off: clear gemeente context
    setActiveGemeente(null)
    removeWijkBoundariesLayer(mapRef.current)
    setWijkGeojson(null)
    setActivePanel(null)
    mapRef.current.flyTo({ center: NL_CENTER, zoom: NL_ZOOM, duration: 1000 })
  }
}, [layerState.showGemeenten])
```
