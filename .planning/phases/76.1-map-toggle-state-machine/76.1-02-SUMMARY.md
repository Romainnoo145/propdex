## Accomplishments

- Removed 4 mirror state variables from map.tsx (`basemap`, `showGemeentenLayer`, `showBestemmingsplan`, `isParcelsVisible`) — all replaced by `layerState.*` from `useMapLayerState()`
- Fixed stale closure bug in parcel click and cursor move handlers: added `isParcelsVisibleRef` synced every render, handlers now read `isParcelsVisibleRef.current`
- Click handler effect no longer depends on `isParcelsVisible` — handler re-registration on every parcel toggle eliminated
- Rewrote `handleGemeentenToggle` and `handleBestemmingsplanToggle` as no-arg callbacks using `layerActions`; all side effects (map visibility, panel reset, layer cleanup) preserved
- Moved `autoEnableParcelsKey` auto-enable logic from LayerToggle into map.tsx useEffect — map.tsx is now the sole authority for setting `showParcels: true`
- Removed `readPersistedMapLayerState` import and `BaseMapLayerId` type import — both now internal to hook
- Updated LayerToggle JSX to pass `layerState.*` fields and `layerActions.*` callbacks directly
