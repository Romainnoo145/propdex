# Phase 76.1 Plan 01: useMapLayerState Hook + Controlled LayerToggle Summary

**One-liner:** Extracted map toggle state into `useMapLayerState` hook and converted `LayerToggle.tsx` to a zero-useState controlled component receiving all boolean props from parent.

## What Was Built

### Task 1: useMapLayerState hook + layers.ts cleanup

Created `frontend/src/lib/map/useMapLayerState.ts`:
- `MapLayerState` type alias of `PersistedMapLayerState` (forward-compatible)
- `MapLayerActions` interface with typed setters: `setBasemap`, `toggle*`, `set*` for each layer
- `useMapLayerState()` hook: single `useState<MapLayerState>` + `useEffect` for persistence + `useCallback`-stable action functions
- Returns `{ state, actions } as const`

Cleaned `frontend/src/lib/map/layers.ts`:
- Removed `showWijken` from `PersistedMapLayerState` interface and `DEFAULT_MAP_LAYER_STATE`

### Task 2: LayerToggle controlled component conversion

Rewrote `frontend/src/components/map/LayerToggle.tsx`:
- Removed ALL `useState` calls for toggle booleans (was: `activeLayer`, `showParcels`, `showGemeenten`, `showBestemmingsplan`, `showBAGPanden`, `showScannedScope`, `showScore`, `showBuiltStatus`, `showReportStatus`, `showVacancySignal`, `showBuildCapacity` — 11 state vars)
- New required props: `basemap`, `showParcels`, `showGemeenten`, `showBestemmingsplan` (from parent)
- New required handlers: `onBasemapChange`, `onParcelsToggle()`, `onGemeentenToggle()`, `onBestemmingsplanToggle()` (no-arg callbacks)
- Removed dead props: `showScoreToggle`, `showBuiltStatusToggle`, `showReportStatusToggle`, `showVacancySignalToggle`, `showBuildCapacityToggle`, `showBAGPandenToggle`, `showScannedScopeToggle`, `showWijkenToggle`, `onWijkenToggle`
- Kept: `isStyleReady` guard, `didInitSyncRef` one-time init (deps: `[mapReady]` only), `autoEnableParcelsKey` effect, `setParcelOverlayMode` for overlay management
- `showGradientLegend` derived from `activeParcelOverlay` prop instead of internal state

Updated `frontend/src/routes/_authenticated/map.tsx`:
- Added `basemap` state + `handleBasemapChange` callback
- Added no-arg adapter wrappers: `handleParcelsToggleNoArg`, `handleGemeentenToggleNoArg`, `handleBestemmingsplanToggleNoArg`
- Updated LayerToggle JSX to pass new required props and use adapter wrappers
- Removed dead `showBAGPandenToggle`, `showScannedScopeToggle`, `showScoreToggle`, etc. props from LayerToggle call

Fixed `frontend/src/App.tsx`:
- Removed vestigial uncontrolled `<LayerToggle mapRef={mapRef} />` (had no handlers, never functional)
