       Add a function that triggers the scan using the stored bbox.
       This is called when user confirms by clicking a "Scan dit gebied" button.

       ```typescript
       const handleAreaScanTrigger = useCallback(() => {
         if (!areaScanBbox) return

         // Need a gemeente context for the scan -- use a generic gemeente code
         // For area scans, we still need gemeente_code/naam for the scan record
         // The user must have a gemeente selected (from gemeenten layer) or we use a placeholder
         triggerScan.mutate(
           {
             gemeente_code: '0000',  // Generic code for area scans
             gemeente_naam: 'Gebied selectie',
             bbox_wgs84: areaScanBbox,
           },
           {
             onSuccess: (data) => {
               setActiveScanId(data.scan_id)
               if (data.status === 'existing' && !data.needs_rescan) {
                 toast.info(`Bestaande scan gevonden`)
               }
             },
             onError: (err) => {
               toast.error(`Scan starten mislukt: ${err.message}`)
               // Remove bbox outline on error
               if (mapRef.current) {
                 removeBboxOutline(mapRef.current)
               }
               setAreaScanBbox(null)
             },
           }
         )
       }, [areaScanBbox, triggerScan])
       ```

       WAIT -- actually, looking at the existing gemeente scan flow more carefully: the gemeente_code is used for `get_existing_scan` lookup AND stored in the AreaScan record. For area scans, using '0000' would cause all area scans to collide in the existing scan check.

       Better approach: use a special gemeente_code format for area scans. The existing scan check in the backend looks up by org_id + gemeente_code. For area scans, we should ALWAYS create a new scan (no existing scan reuse). The simplest solution: pass `force_rescan: true` for area scans. This skips the existing scan check.

       Updated approach:
       ```typescript
       const handleAreaScanTrigger = useCallback(() => {
         if (!areaScanBbox) return

         triggerScan.mutate(
           {
             gemeente_code: 'AREA',
             gemeente_naam: 'Gebiedsscan',
             bbox_wgs84: areaScanBbox,
             force_rescan: true,  // Always create new scan for area selections
           },
           {
             onSuccess: (data) => {
               setActiveScanId(data.scan_id)
             },
             onError: (err) => {
               toast.error(`Scan starten mislukt: ${err.message}`)
               if (mapRef.current) removeBboxOutline(mapRef.current)
               setAreaScanBbox(null)
             },
           }
         )
       }, [areaScanBbox, triggerScan])
       ```
