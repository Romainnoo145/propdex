  <name>Task 1: Install drawing dependencies and create DrawingToolsControl</name>
  <files>
    frontend/package.json
    frontend/src/components/map/DrawingToolsControl.tsx
  </files>
  <action>
    1. Install dependencies:
       ```bash
       cd frontend && npm install terra-draw@^1.24.0 @turf/bbox@^7.2.0
       ```
       NOTE: Do NOT install @watergis/maplibre-gl-terradraw -- use terra-draw directly with TerraDrawMapLibreGLAdapter (the adapter is included in the terra-draw package itself).

    2. Create `frontend/src/components/map/DrawingToolsControl.tsx`:

       Props interface:
       ```typescript
       interface DrawingToolsControlProps {
         map: maplibregl.Map | null
         onAreaDrawn: (bbox: [number, number, number, number], geometry: GeoJSON.Geometry) => void
         disabled?: boolean
       }
       ```

       Component implementation:
       - Import `TerraDraw` and `TerraDrawMapLibreGLAdapter` from `terra-draw`
       - Import `TerraDrawRectangleMode`, `TerraDrawPolygonMode` from `terra-draw`
       - Import `bbox` from `@turf/bbox`
       - Use `useRef` for the TerraDraw instance (NOT useState -- avoids re-renders)
       - Use `useState` for `activeMode: 'rectangle' | 'polygon' | null`

       Initialization (useEffect on `map`):
       - Guard: if `!map` return
       - Create TerraDraw with `TerraDrawMapLibreGLAdapter({ map })`
       - Add `TerraDrawRectangleMode()` and `TerraDrawPolygonMode()`
       - Call `terraDraw.start()`
       - Register `terraDraw.on('finish', (id: string) => { ... })` handler:
         - Get snapshot: `const features = terraDraw.getSnapshot()`
         - Find completed feature by id
         - If feature found, calculate bbox: `const bounds = bbox(feature) as [number, number, number, number]`
         - The bbox will be in EPSG:4326 (lng/lat) because MapLibre uses 4326
         - Call `onAreaDrawn(bounds, feature.geometry)`
         - Call `terraDraw.clear()` to remove drawn shape
         - Reset `setActiveMode(null)`
       - Cleanup: `terraDraw.stop()` in effect return

       Mode buttons:
       - Rectangle button: calls `drawRef.current?.clear()` then `drawRef.current?.setMode('rectangle')` then `setActiveMode('rectangle')`
       - Polygon button: calls `drawRef.current?.clear()` then `drawRef.current?.setMode('polygon')` then `setActiveMode('polygon')`
       - Cancel button (only visible when activeMode !== null): calls `drawRef.current?.clear()` then `setActiveMode(null)`

       Styling:
       - Position: absolute, bottom-4 right-4, z-[var(--z-map-controls)]
       - Match existing LayerToggle aesthetic: bg-black/30 backdrop-blur-md rounded-lg
       - Active mode button gets highlight color (amber-500/30 for drawing active state)
       - Disabled state: opacity-50 cursor-not-allowed when `disabled` prop is true
       - Use inline SVG icons for rectangle (a simple square outline) and polygon (triangle/pentagon outline)
       - Dutch labels: "Rechthoek" for rectangle, "Polygoon" for polygon, "Annuleren" for cancel
  </action>

    Add optional `bbox_wgs84` field to the `ScanCreateRequest` interface:

    ```typescript
    export interface ScanCreateRequest {
      gemeente_code: string
      gemeente_naam: string
      force_rescan?: boolean
      /** Optional bounding box [minLon, minLat, maxLon, maxLat] in EPSG:4326 (WGS84).
       *  If provided, scan is limited to this area instead of entire gemeente.
       *  Backend converts to EPSG:28992 for BAG WFS queries. */
      bbox_wgs84?: [number, number, number, number]
    }
    ```

    This field is optional so existing gemeente-wide scans continue to work unchanged.
    The `_wgs84` suffix makes the coordinate system explicit and prevents confusion with EPSG:28992 bbox.
