    Create `frontend/src/lib/geo-utils.ts` with a `calculateBboxFromGeometry` function:

    ```typescript
    /**
     * Calculate bounding box from GeoJSON Polygon or MultiPolygon geometry.
     * Handles both single polygons and multi-polygons (e.g., island gemeentes).
     * Returns [minLon, minLat, maxLon, maxLat] in WGS84.
     */
    export function calculateBboxFromGeometry(
      geometry: GeoJSON.Polygon | GeoJSON.MultiPolygon
    ): [number, number, number, number]
    ```

    Implementation:
    - Handle `Polygon` type: wrap `geometry.coordinates` in array for uniform iteration
    - Handle `MultiPolygon` type: iterate all polygon arrays in `geometry.coordinates`
    - For each polygon, iterate the **exterior ring** (`polygon[0]`) only (interior rings are holes, irrelevant for bbox)
    - Track min/max lon/lat across ALL coordinates
    - Return `[minLon, minLat, maxLon, maxLat]` tuple matching backend `bbox_wgs84` field format

    Then update `GemeenteBoundariesLayer.tsx`:
    - Import `calculateBboxFromGeometry` from `@/lib/geo-utils`
    - Change `onGemeenteClick` callback signature from `(gemeenteCode: string, gemeenteNaam: string) => void` to `(gemeenteCode: string, gemeenteNaam: string, bbox: [number, number, number, number]) => void`
    - In the `handleClick` function, after extracting `statcode` and `statnaam`, also extract bbox:
      ```typescript
      const geometry = feature.geometry as GeoJSON.Polygon | GeoJSON.MultiPolygon
      if (geometry.type === 'Polygon' || geometry.type === 'MultiPolygon') {
        const bbox = calculateBboxFromGeometry(geometry)
        onGemeenteClick(statcode, statnaam, bbox)
      }
      ```
    - Guard: only call `onGemeenteClick` if geometry type is Polygon or MultiPolygon (skip Point, etc.)

    IMPORTANT: Do NOT change any other behavior in GemeenteBoundariesLayer (hover, visibility, source management).
