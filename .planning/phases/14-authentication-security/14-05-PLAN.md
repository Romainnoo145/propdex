2. Update `frontend/src/routes/auth/google-callback.tsx`:
   - Import `useAuth` from `@/lib/auth/useAuth`
   - Import `useNavigate`, `useSearch` from TanStack Router
   - On mount (useEffect), extract `code` from URL search params
   - If no code: navigate to `/auth`
   - If code present:
     - POST to `/api/auth/google/callback` with `{ code, redirect_uri: window.location.origin + '/auth/google-callback' }` and `credentials: 'include'`
     - On success: the backend sets the httpOnly cookie. Extract `access_token` from response.
     - Call `fetchUserApi(access_token)` to get user data, then update auth context
     - Navigate to `/map`
   - On error: navigate to `/auth`
   - Show "Authenticating with Google..." text while processing

   IMPORTANT: The Google callback needs to update the auth context after receiving the access token. Since `useAuth()` doesn't expose a `setAccessToken` method directly, add a `loginWithToken(accessToken: string)` method to the AuthContext that accepts an access token, fetches the user, and sets both. Update AuthContext.tsx and types.ts to include this method.

   Add to `AuthContextValue` type:
   ```typescript
   loginWithToken: (accessToken: string) => Promise<void>
   ```

   Add to `AuthProvider`:
   ```typescript
   const loginWithToken = useCallback(async (token: string) => {
     setAccessToken(token)
     const userData = await fetchUserApi(token)
     setUser(userData)
   }, [])
   ```
