    4. **Score category** -- single-select dropdown:
       - Label: "Score"
       - Options: "Alle" (empty), "High", "Medium", "Low"
       - Maps to `filters.score_category`
       - Same styling as bestemming dropdown

    5. **Clear filters** button:
       - Only visible when any filter is active
       - Text: "Wis filters"
       - Resets all filters to empty object (preserving sort/pagination)
       - Style: `text-white/50 hover:text-white/80 text-xs underline`

    6. **Results count** badge:
       - Show `{total} resultaten` at the right end
       - Style: `text-white/50 text-xs`

    For the debounce on the area input, use a local state + useEffect with setTimeout/clearTimeout pattern (don't add a debounce library). Example:
    ```typescript
    const [localMinArea, setLocalMinArea] = useState(filters.min_area_m2?.toString() ?? '')
    useEffect(() => {
      const timer = setTimeout(() => {
        const value = localMinArea ? Number(localMinArea) : undefined
        if (value !== filters.min_area_m2) {
          onChange({ ...filters, min_area_m2: value })
        }
      }, 500)
      return () => clearTimeout(timer)
    }, [localMinArea])
    ```
