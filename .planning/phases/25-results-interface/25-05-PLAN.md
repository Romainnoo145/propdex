    **In backend/app/scans/schemas.py**, add enrichment response schema:
    ```python
    class ParcelEnrichmentResponse(BaseModel):
        """On-demand Tier 2 enrichment data for a parcel."""
        parcel_id: uuid.UUID
        enrichment_data: dict | None = None
        enriched_at: datetime | None = None
        is_cached: bool = False
    ```

    **In backend/app/scans/router.py**, add new endpoint:

    ```python
    @router.get("/parcels/{parcel_id}/enrich", response_model=ParcelEnrichmentResponse)
    @limiter.limit("30/minute")
    async def enrich_parcel(
        request: Request,
        parcel_id: uuid.UUID,
        current_user: User = Depends(get_current_active_user),
        organization_id: uuid.UUID = Depends(get_current_organization_id),
        db: AsyncSession = Depends(get_db),
    ) -> ParcelEnrichmentResponse:
    ```

    Implementation:
    1. Query `ParcelCache` by `id=parcel_id` and `organization_id` (multi-tenant isolation)
    2. If not found, raise 404
    3. Check if enrichment is fresh: `parcel.enriched_at` exists and `(datetime.utcnow() - parcel.enriched_at).days < 7`
    4. If fresh, return cached data with `is_cached=True`
    5. If stale or missing:
       a. Extract postcode from `parcel.address` (pattern: last 7 chars like "1234 AB" or "1234AB"). Use regex: `r'\b(\d{4}\s?[A-Z]{2})\b'`
       b. If no postcode extractable, return `enrichment_data=None` with a note
       c. Get httpx client from `request.app.state.httpx_client`
       d. Call `sru_client.query_by_postcode(postcode, httpx_client, max_records=20)`
       e. Store result: `parcel.enrichment_data = {"vergunningen": [dict(r) for r in records]}`
       f. Set `parcel.enriched_at = datetime.utcnow()`
       g. `db.add(parcel)` then `await db.commit()`
       h. Return with `is_cached=False`
    6. Wrap SRU call in try/except: on `GovernmentAPIError`, log warning and return `enrichment_data={"vergunningen": [], "error": str(e)}`

    Import `sru_client` from `app.government_apis.sru_bekendmakingen`.
    Import `ParcelCache` model.

    IMPORTANT: This endpoint uses the URL prefix `/api/scans/parcels/{parcel_id}/enrich` which nests under the existing scans router. Make sure the route pattern does not conflict with `/{scan_id}/results` (it won't -- "parcels" is not a valid UUID so FastAPI won't match it against `{scan_id}`).

    Run `ruff check backend/app/scans/router.py` and `ruff check backend/app/scans/schemas.py` to verify.

      parcelId: string,
      accessToken: string | null
    ): Promise<ParcelEnrichmentResponse> {
      return apiFetch<ParcelEnrichmentResponse>(
        `${SCANS_BASE}/parcels/${parcelId}/enrich`,
        { method: 'GET', accessToken }
      )
    }

    **3. React Query hook** (`frontend/src/hooks/useScans.ts`):
    ```typescript
    export function useParcelEnrichment(
      parcelId: string | null,
      options?: { enabled?: boolean }
    ) {
      const { accessToken } = useAuth()

      return useQuery<ParcelEnrichmentResponse, Error>({
        queryKey: ['parcel-enrichment', parcelId],
        queryFn: () => fetchParcelEnrichment(parcelId!, accessToken),
        enabled: (options?.enabled ?? true) && !!parcelId && !!accessToken,
        staleTime: 7 * 24 * 60 * 60 * 1000, // 7 days (matches backend cache)
      })
    }
    ```
    Import `fetchParcelEnrichment` from `@/lib/api` and `ParcelEnrichmentResponse` from types.
