Create `backend/app/tools/backfill_scan_scores_v3.py` modeled on `backfill_scan_scores_v2.py` with these specifics:

1. **CLI args** (argparse): `--organization-id` (optional UUID), `--scan-id` (optional UUID), `--batch-size` (default 500), `--dry-run` (flag)

2. **Main loop**: iterate organizations (all if no --organization-id), for each org:
   - `SET app.current_tenant_id` (f-string with validated UUID per project pattern)
   - If --scan-id, filter to that scan only
   - Keyset pagination: `SELECT ScanResult JOIN ParcelCache ON parcel_id, WHERE sr.id > last_id, ORDER BY sr.id, LIMIT batch_size`

3. **Per-batch**: load `neighborhood_metrics` for unique scan_ids in batch via separate query on `AreaScan` table. Build a `dict[scan_id -> neighborhood_metrics]`.

4. **Per-row**: build `parcel_data` dict matching area_scan.py Phase 6 (lines 910-936) EXACTLY:
   - From ParcelCache: area_m2, has_pand, bouwjaar, pand_status, bestemmingen
   - From flags: vacancy_signal, building_metrics, market_signals, bodem, bodemtype, funderingsrisico, energielabel, vergunningen, natura2000, overstromingsrisico, geluid, luchtkwaliteit, woz
   - neighborhood_metrics from nbhd_map (pass None if absent)

5. **Score and merge**: call `compute_score_v3(parcel_data, neighborhood_metrics)`, then:
   - Set `flags["scores"]` = `{"potentie": v3.potentie_score, "risico": v3.risico_score, "overall": v3.overall}`
   - Set `flags["score_breakdown"]` = `{name: asdict(factor) for name, factor in v3.score_breakdown.items()}`
   - Set `flags["score_model_version"]` = `"score-v3.0"`
   - Set `flags["category"]` = `v3.category`
   - Pop old keys: `flags.pop("factors", None)`, `flags.pop("subscores", None)`
   - Update `sr.score` = `max(0.0, min(100.0, v3.overall))`
   - Update `sr.flags` = flags
   - `session.add(sr)` (direct pattern, NOT async with db.begin())

6. **Batch commit**: `await session.flush()` then `await session.commit()` after each batch

7. **Logging**: Use stdlib logging. Log per-batch: count processed, count changed (score != old score), elapsed time. Log totals at end.

8. **Dry-run**: When --dry-run, compute scores and log what would change but skip session.add/flush/commit.

9. **Entry point**: `if __name__ == "__main__"` with `asyncio.run(main())`

Use `datetime.utcnow()` (naive UTC) per project convention. Import `async_session_factory` from `app.database` (same as v2 backfill). Use `from dataclasses import asdict` for FactorResult conversion.
