    3. **Create DoorlooptijdService** (`backend/app/services/doorlooptijd.py`):
       - `DUTCH_MONTHS` dict mapping Dutch month names to integers (januari=1 through december=12)
       - `_FILING_PATTERNS`: list of compiled regex patterns for extracting filing dates from Dutch legal text:
         * `beroepschrift\s+(?:is\s+)?ingediend\s+(?:op\s+)?(\d{1,2})\s+(\w+)\s+(\d{4})` (Dutch month name)
         * `bezwaarschrift\s+van\s+(\d{1,2})\s+(\w+)\s+(\d{4})` (Dutch month name)
         * `(?:ingekomen|ontvangen)\s+op\s+(\d{1,2})[-/](\d{1,2})[-/](\d{4})` (numeric date)
       - `extract_filing_date(text: str) -> str | None`: search first 3000 chars for filing date patterns, return ISO date string (YYYY-MM-DD) or None
       - `compute_doorlooptijd(datum_uitspraak: str, datum_indiening: str) -> int | None`: parse both dates, return difference in days if positive, else None
       - `extract_relevant_sections(full_text: str, max_chars: int = 15000) -> str`: find OVERWEGINGEN/BEOORDELING/HET GESCHIL section marker, return text from there capped at max_chars. Fallback: last 60% of text.
       - `async def get_doorlooptijd_stats(db: AsyncSession, gemeente_naam: str) -> dict`: SQL aggregation query grouping by vergunningstype where doorlooptijd_dagen IS NOT NULL, returning avg/min/max per type. Use minimum sample size of 3; below that return `insufficient_data: true`.

    4. **Update AI prompt** (`backend/app/ai/prompts.py`):
