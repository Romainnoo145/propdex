function phaseLabel(phase: string | null): string {

**MapLibre transformRequest for authenticated tile requests:**
In the MapView onMapReady callback or via the mapRef, set up transformRequest to add auth headers for tile requests:

Actually, this is tricky because MapView creates the map internally. Two approaches:
1. Add `transformRequest` to MapView's map initialization
2. Use `map._requestManager` to set it after creation

Better: Add a prop to MapView or handle it in the map.tsx after map is ready. MapLibre supports `map.setTransformRequest()` after initialization.

In map.tsx, after `setMapReady(true)`, add:
```typescript
const handleMapReady = useCallback((map: maplibregl.Map) => {
  setMapReady(true)
  // No transformRequest needed -- Vite proxy forwards /api/* with cookies
}, [])
```

Wait -- since we use the Vite dev proxy, all `/api/*` requests go through `localhost:9300/api/*` -> Vite proxy -> `localhost:8000/api/*`. MapLibre tile requests to `/api/scans/{id}/tiles/...` WILL be proxied by Vite since they match `/api`. And the `credentials: 'include'` is set at the browser level. But MapLibre's fetch doesn't include credentials by default.

Use MapLibre's `transformRequest` to add credentials:
```typescript
// In map initialization (MapView.tsx), OR after map ready
// Since MapView is a shared component, better to use map.setTransformRequest in map.tsx
if (mapRef.current) {
  // This doesn't exist as a setter in MapLibre...
}
```

Actually, `transformRequest` is a constructor option in MapLibre, not settable after init. So we need to modify MapView.tsx to accept it as a prop. Add an optional `transformRequest` prop to MapView.

**In MapView.tsx:** Add optional `transformRequest` prop to `MapViewProps`:
```typescript
interface MapViewProps {
  mapRef?: React.MutableRefObject<maplibregl.Map | null>;
  onMapReady?: (map: maplibregl.Map) => void;
  transformRequest?: (url: string, resourceType: string) => { url: string; headers?: Record<string, string>; credentials?: string } | undefined;
}
```

Pass it to the Map constructor: `transformRequest: transformRequest ?? undefined`.

**In map.tsx:** Pass a transformRequest that adds credentials for API tile requests:
```typescript
const { accessToken } = useAuth()

const transformRequest = useCallback((url: string, resourceType: string) => {
  // Add auth for tile requests to our backend
  if (url.startsWith('/api/') && resourceType === 'Tile') {
    return {
      url,
      headers: accessToken ? { 'Authorization': `Bearer ${accessToken}` } : {},
      credentials: 'include' as const,
    }
  }
  return { url }
}, [accessToken])
```

Pass `transformRequest={transformRequest}` to `<MapView>`.
