**Create `frontend/src/hooks/useScans.ts`** following useReports.ts and usePropertyLookup.ts patterns:

1. **`useTriggerScan()`** -- useMutation hook:
   - mutationFn: calls `triggerScan(request, accessToken)`
   - Returns mutation with `mutate`, `isPending`, `data` (ScanResponse with scan_id)
   - Follow usePropertyLookup pattern (useMutation with useAuth)

2. **`useScanPolling(scanId: string | null)`** -- useQuery with refetchInterval:
   - queryKey: `['scan-status', scanId]`
   - queryFn: calls `fetchScanStatus(scanId!, accessToken)`
   - `enabled: !!scanId && !!accessToken`
   - `refetchInterval`: Use function form per research Pattern 4:
     ```typescript
     refetchInterval: (query) => {
       const data = query.state.data
       if (query.state.error) return false
       if (!data) return 2000  // Initial poll
       if (data.status === 'completed' || data.status === 'failed' || data.status === 'cancelled') {
         return false  // Stop polling
       }
       return 2000  // Poll every 2 seconds
     }
     ```
   - `refetchIntervalInBackground: true` (keep polling even if tab not focused)
   - Returns useQuery result with `data: ScanStatusResponse`
   - NOTE: TanStack Query v5 `refetchInterval` function receives the query object, not (data, query). Check the installed version (5.90.20) and use the correct signature.

3. **`useCancelScan()`** -- useMutation hook:
   - mutationFn: calls `cancelScan(scanId, accessToken)`
   - Takes `string` (scanId) as mutation variable
   - On success: invalidate `['scan-status', scanId]` to trigger re-fetch

4. **`useScanResults(scanId: string | null, filters: ScanResultsFilters = {})`** -- useQuery hook:
   - queryKey: `['scan-results', scanId, filters]`
   - queryFn: calls `fetchScanResults(scanId!, filters, accessToken)`
   - `enabled: !!scanId && !!accessToken`
   - `staleTime: 30 * 1000` (30 seconds -- results don't change after scan completes)

All hooks use `useAuth()` for accessToken. Import all API functions from `@/lib/api`. Import all types from `@/lib/types/scan`.
