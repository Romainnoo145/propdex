<objective>
Introduce a document-level cache sentinel so woonvisie_match extraction produces exactly 1 Claude call per policy_document (not 1 per parcel). Bump SCHEMA_VERSION 2→3 to invalidate existing parcel-keyed v2 entries. Add unit + integration tests per TEST-05. No DB migration.

Purpose: At Venlo scale (100k+ parcelen) the current pipeline would fire 100k Claude calls for a single woonvisie — each returning the same document-scoped payload. The sentinel reduces that to 1 call per (policy_document_id, factor_id, SCHEMA_VERSION) tuple.

Output: SCHEMA_VERSION=3, DOCUMENT_SENTINEL constant, single caller edit in cascade_enrichment_service, full test coverage (2 unit + 1 integration + updated existing assertions + retired stale iron-rule test).
</objective>
