    Create utility functions for managing PDOK kadastrale kaart vector tiles on the map.

    **PDOK Kadastrale Kaart vector tiles:**
    The PDOK API provides pre-rendered vector tiles (MVT format) for cadastral parcels. Use the BRK Kadastrale Kaart OGC API.

    Tile URL: `https://service.pdok.nl/kadaster/kadastralekaart/wmts/v1_0/Kadastralekaart/EPSG:3857/{z}/{x}/{y}.pbf`

    If the above URL does not work (PDOK may have different endpoints), try these alternatives:
    - `https://service.pdok.nl/kadaster/kadastralekaart/wmts/v1_0?service=WMTS&request=GetTile&version=1.0.0&layer=Kadastralekaart&style=default&tilematrixset=EPSG:3857&tilematrix={z}&tilerow={y}&tilecol={x}&format=application/vnd.mapbox-vector-tile`

    As a pragmatic fallback, if vector tiles prove difficult at implementation time, use the PDOK WMS raster tiles instead:
    - `https://service.pdok.nl/kadaster/kadastralekaart/wms/v5_0?service=WMS&version=1.1.1&request=GetMap&layers=Perceel&styles=&srs=EPSG:3857&bbox={bbox-epsg-3857}&width=256&height=256&format=image/png&transparent=true`

    **Functions to export:**

    ```typescript
    // - Set minzoom: 14 (only show when zoomed in enough for detail)

    // - Sets layout.visibility to 'visible' or 'none' on both layers
    ```
