    **1. Create `frontend/src/components/map/PropertyGeometryLayer.tsx`:**

    Utility functions for rendering property geometry on the map.

    ```typescript
    import type maplibregl from 'maplibre-gl';
    import type { PropertyReportResponse } from '@/lib/types/property';

    const PROPERTY_SOURCE = 'selected-property';
    const PROPERTY_FILL_LAYER = 'selected-property-fill';
    const PROPERTY_LINE_LAYER = 'selected-property-line';
    const PARCEL_SOURCE = 'selected-parcels';
    const PARCEL_FILL_LAYER = 'selected-parcels-fill';
    const PARCEL_LINE_LAYER = 'selected-parcels-line';
    ```

    Functions:

    `updatePropertyGeometry(map, data: PropertyReportResponse)`:
    - Clear existing property/parcel layers first (call clearPropertyGeometry)
    - If `data.map_data?.property_geometry` exists:
      - Add GeoJSON source with property_geometry
      - Add fill layer: color var(--color-primary) (#2563eb), opacity 0.15
      - Add line layer: color var(--color-primary), width 2, opacity 0.8
    - If `data.cadastral_parcels` has parcels with geometry:
      - Create FeatureCollection from parcel geometries
      - Add GeoJSON source
      - Add fill layer: color #f59e0b (amber), opacity 0.08
      - Add dashed line layer: color #f59e0b, width 1.5, dasharray [4, 2]
    - Fly to center: if `data.map_data?.center_wgs84` exists, call `map.flyTo({ center, zoom: 17 })`

    `clearPropertyGeometry(map)`:
    - Remove all 4 layers + 2 sources if they exist
    - Always check existence before removing (prevents errors)

    **IMPORTANT:** Always remove layers before sources. Check `map.getLayer(id)` / `map.getSource(id)` before each removal.
