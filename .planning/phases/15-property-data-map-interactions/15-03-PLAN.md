  <action>
    Create `frontend/src/components/search/AddressSearch.tsx`:

    **Props:**
    ```typescript
    interface AddressSearchProps {
      onSelect: (suggestion: SuggestResult) => void;
      className?: string;
    }
    ```

    **Component structure:**
    ```
    <div ref={containerRef} className="absolute top-4 left-1/2 -translate-x-1/2 z-[var(--z-search-bar)] w-full max-w-md px-4">
      <div className="glassmorphism search-container">
        <SearchIcon />
        <input ... />
        {isLoading && <Spinner />}
      </div>
      {showDropdown && suggestions.length > 0 && (
        <ul className="dropdown z-[var(--z-dropdown)]">
          {suggestions.map((s, i) => (
            <li key={s.id} className={highlighted === i ? 'highlighted' : ''}>
              {s.weergavenaam}
            </li>
          ))}
        </ul>
      )}
    </div>
    ```

    **State management:**
    - `query` (string) — controlled input value
    - `highlightedIndex` (number) — keyboard navigation index (-1 = none)
    - `showDropdown` (boolean) — dropdown visibility
    - Use `useAddressSuggest(query)` for data fetching

    **Keyboard navigation:**
    - `ArrowDown` — increment highlightedIndex (wrap to 0 at end)
    - `ArrowUp` — decrement highlightedIndex (wrap to end at 0)
    - `Enter` — select highlighted suggestion, call onSelect, close dropdown, set input to weergavenaam
    - `Escape` — close dropdown, clear highlightedIndex

    **Click-outside handling:**
    - Use a ref on the container div
    - Add mousedown listener on document in useEffect
    - If click target is outside containerRef, close dropdown
    - Cleanup listener on unmount

    **Styling (glassmorphism, matching LayerToggle):**
    - Container: `bg-black/30 backdrop-blur-md rounded-xl border border-white/20 shadow-lg`
    - Input: transparent background, white text, `placeholder:text-white/50`
    - Search icon: `text-white/70` (use inline SVG — magnifying glass)
    - Dropdown: `bg-black/40 backdrop-blur-md rounded-xl border border-white/20 mt-1 shadow-lg overflow-hidden`
    - Dropdown item: `px-4 py-3 text-white/90 text-sm cursor-pointer hover:bg-white/10`
    - Highlighted item: `bg-white/15`
    - Loading spinner: small spinning circle icon, `animate-spin text-white/50`

    **Behavior details:**
    - On input change: update query, show dropdown if 3+ chars
    - On suggestion click: call onSelect, set input to weergavenaam, close dropdown
    - On Enter with highlighted: same as click
    - Dropdown only shows when: query.length >= 3 AND suggestions exist AND showDropdown is true
    - When data is loading (isLoading from useAddressSuggest): show spinner in input, keep dropdown open if it was open
    - When no results and query >= 3 chars and not loading: show "Geen resultaten" message in dropdown

    **Add to `frontend/src/styles/index.css`** (if not already present):
    No new CSS variables needed — the existing z-index scale has --z-search-bar: 100 and --z-dropdown: 400.

    **IMPORTANT:** Do NOT add role="combobox" or aria-* attributes that require additional libraries. Use basic semantic HTML with proper keyboard event handlers. Focus stays on the input at all times (dropdown items are not focusable — highlighted state is visual only, controlled by keyboard from input).
