    **Search → Lookup flow:**
    ```typescript
    const handleAddressSelect = useCallback((suggestion: SuggestResult) => {
      // 1. Extract postcode and huisnummer from suggestion
      //    PDOK suggest docs have fields: weergavenaam, id, type
      //    The id field typically contains nummeraanduiding URL
      //    Since we need postcode + huisnummer for backend, and PDOK suggest
      //    may not always have these as separate fields, parse from weergavenaam
      //    OR use the suggestion's id to call PDOK lookup endpoint.
      //
      //    PRAGMATIC APPROACH: The backend suggest endpoint returns raw PDOK docs.
      //    PDOK docs for type:adres include fields like postcode, huis_nlt, straatnaam.
      //    Extract directly: suggestion.postcode, suggestion.huis_nlt
      //    Cast suggestion to Record<string, unknown> for flexible access.
      //    If postcode/huis_nlt missing, fall back to parsing weergavenaam.

      const postcode = (suggestion as Record<string, unknown>).postcode as string | undefined;
      const huisnummer = parseInt(
        String((suggestion as Record<string, unknown>).huis_nlt ?? '0'),
        10
      );

      if (!postcode || !huisnummer) {
        console.warn('Could not extract postcode/huisnummer from suggestion:', suggestion);
        return;
      }

      // 2. Trigger property lookup mutation
      lookup.mutate(
        { postcode, huisnummer },
        {
          onSuccess: (data) => {
            // 3. Show detail panel
            setShowPanel(true);
            // 4. Render geometry on map
            if (mapRef.current) {
              updatePropertyGeometry(mapRef.current, data);
            }
          },
        }
      );

      // Show panel immediately (for loading state)
      setShowPanel(true);
    }, [lookup]);
    ```

    **Close panel handler:**
    ```typescript
    const handleClosePanel = useCallback(() => {
      setShowPanel(false);
      if (mapRef.current) {
        clearPropertyGeometry(mapRef.current);
      }
    }, []);
    ```

    **JSX structure:**
    ```tsx
    <AppLayout>
      <MapView mapRef={mapRef} />
      <AddressSearch onSelect={handleAddressSelect} />
      {showPanel && (
        <PropertyDetailPanel
          data={lookup.data ?? null}
          isLoading={lookup.isPending}
          error={lookup.error}
          onClose={handleClosePanel}
        />
      )}
      <LayerToggle mapRef={mapRef} />
    </AppLayout>
    ```
