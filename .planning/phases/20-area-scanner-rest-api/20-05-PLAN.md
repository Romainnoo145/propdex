**2. POST /api/scans/{scan_id}/cancel -- Cancel running scan**

```python
@router.post("/{scan_id}/cancel")
@limiter.limit("10/minute")
async def cancel_scan(
    request: Request,
    scan_id: uuid.UUID,
    current_user: User = Depends(get_current_active_user),
    organization_id: uuid.UUID = Depends(get_current_organization_id),
    db: AsyncSession = Depends(get_db),
):
```

Logic:
- Get scan via `service.get_scan_by_id(scan_id, organization_id, db)`
- If not found: raise HTTPException(404)
- If scan.status != "running": raise HTTPException(400, "Scan is not running")
- Abort ARQ job:
  ```python
  from arq.jobs import Job
  arq_pool = request.app.state.arq_pool
  job = Job(scan.job_id, arq_pool)
  await job.abort()
  ```
- Return `{"message": "Scan cancellation requested", "scan_id": str(scan_id)}`
- Note: actual status update to "cancelled" happens in the job's CancelledError handler (20-04)

Import `ScanStatusResponse` from schemas and `from arq.jobs import Job` for cancellation.

**Part A: Add list_scan_results to service.py**

Add function to `backend/app/scans/service.py` following the `list_reports` pattern in `backend/app/reports/service.py`:

```python
async def list_scan_results(
    scan_id: uuid.UUID,
    organization_id: uuid.UUID,
    has_pand: bool | None,
    bestemming_type: str | None,
    min_area_m2: float | None,
    max_area_m2: float | None,
    score_category: str | None,
    sort_by: str,
    sort_order: str,
    offset: int,
    limit: int,
    session: AsyncSession,
) -> tuple[list[tuple], int]:
```

Implementation:
1. Base query: `select(ScanResult, ParcelCache).join(ParcelCache, ScanResult.parcel_id == ParcelCache.id).where(ScanResult.scan_id == scan_id, ScanResult.organization_id == organization_id)`
2. Apply optional filters:
   - `has_pand is not None`: `.where(ParcelCache.has_pand == has_pand)`
   - `bestemming_type is not None`: Use JSONB contains check -- `.where(ParcelCache.bestemmingen.cast(String).contains(bestemming_type))` or use `func.jsonb_path_exists` if available. Simpler approach: use `text("bestemmingen::text LIKE :pattern")` with `%bestemming_type%` since it's a display filter, not exact match.
   - `min_area_m2 is not None`: `.where(ParcelCache.area_m2 >= min_area_m2)`
   - `max_area_m2 is not None`: `.where(ParcelCache.area_m2 <= max_area_m2)`
   - `score_category is not None`: Filter by score ranges (High >=70, Medium 40-69, Low <40) using ScanResult.score
3. Count total before pagination: `select(func.count()).select_from(query.subquery())`
4. Sort: default "score" DESC (user decision: most promising first)
   - sort_field_map: {"score": ScanResult.score, "area_m2": ParcelCache.area_m2, "address": ParcelCache.address}
   - Apply asc/desc based on sort_order
5. Apply offset/limit
6. Return (rows, total)

Use `from sqlalchemy import select, func, asc, desc, String` and `from sqlalchemy.ext.asyncio import AsyncSession`.
