**Part B: Create Excel export service**

Create `backend/app/services/excel_exporter.py`:

```python
async def export_scan_results_to_excel(
    results: list[tuple],  # list of (ScanResult, ParcelCache) tuples
    scan: AreaScan,
    filters_applied: dict,
) -> BytesIO:
```

Implementation:
1. Create `Workbook()`, get active worksheet, set title "Scan Resultaten"
2. Add metadata rows at top:
   - Row 1: `f"Gemeente: {scan.gemeente_naam} ({scan.gemeente_code})"`
   - Row 2: `f"Scandatum: {scan.created_at.strftime('%d-%m-%Y')}"` (Dutch date format)
   - Row 3: `f"Filters: {_format_filters(filters_applied)}"` (or "Geen filters" if empty)
   - Row 4: Empty (spacer)
3. Add header row (Row 5) with Dutch column names and styling:
   - Headers: ["Adres", "Gemeente", "Oppervlakte (m²)", "Bestemming", "Bebouwd", "Score", "Categorie"]
   - Style: Bold white font on dark blue fill (PatternFill with "366092")
4. Add data rows:
   - For each (scan_result, parcel):
     - Adres: `parcel.address or "Onbekend"`
     - Gemeente: `parcel.gemeente_code or ""`
     - Oppervlakte: `parcel.area_m2 or 0` (numeric, not string -- for Excel sorting)
     - Bestemming: Join bestemmingen types with ", " (e.g., "Wonen, Waarde - Archeologie")
     - Bebouwd: "Ja" if parcel.has_pand else "Nee"
     - Score: `round(scan_result.score, 1) if scan_result.score else 0.0` (numeric)
     - Categorie: `scan_result.flags.get("category", "Low") if scan_result.flags else "Low"`
5. Auto-size columns:
   - Iterate columns, find max content length, set column width = max_length + 2
   - Cap at 50 chars max width
6. Save to BytesIO, seek(0), return

Helper function `_format_filters(filters: dict) -> str`:
- If empty: return "Geen filters"
- Build parts list from non-None filter values:
  - has_pand: "Bebouwd=Ja" or "Bebouwd=Nee"
  - bestemming_type: f"Bestemming={value}"
  - min_area_m2: f"Min oppervlakte={value}m²"
  - max_area_m2: f"Max oppervlakte={value}m²"
  - score_category: f"Score={value}"
- Return parts joined by ", "

Use `from io import BytesIO`, `from openpyxl import Workbook`, `from openpyxl.styles import Font, PatternFill`.

Note: This function is NOT async-heavy (CPU-bound Excel generation). For 2000 rows it takes ~2-3 seconds. Acceptable for direct response. If it becomes a bottleneck, wrap in `asyncio.to_thread()` later.
