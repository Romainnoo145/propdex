**Part B: Gemeente bbox service**

Create `backend/app/services/gemeente_service.py`:

```python
async def get_gemeente_bbox(gemeente_code: str, client: httpx.AsyncClient) -> dict:
```

This function:
1. Queries CBS gebiedsindelingen WFS: `https://service.pdok.nl/cbs/gebiedsindelingen/2024/wfs/v1_0` (use 2024 since 2026 may not exist yet -- check research for correct year, fall back to latest available)
2. Uses WFS GetFeature with CQL_FILTER `gemeentecode='${gemeente_code}'` (NOT XML Filter which is complex to serialize)
3. Requests `outputFormat=application/json` for GeoJSON response
4. Extracts bbox from the returned feature's geometry (use the geometry bounds)
5. Returns `{"minx": float, "miny": float, "maxx": float, "maxy": float}` in EPSG:28992
6. Raises `ValueError` if gemeente not found (no features returned)

Use shared httpx client passed as parameter (following existing API client pattern). Use `from shapely.geometry import shape` to compute bounds from the GeoJSON geometry. The CBS WFS returns geometries in EPSG:28992 by default.

Log at info level: `f"Gemeente {gemeente_code} bbox: {minx},{miny},{maxx},{maxy}"`
