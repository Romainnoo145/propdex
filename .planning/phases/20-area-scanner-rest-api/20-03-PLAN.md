**Part A: Create `backend/app/scans/router.py`**

Create router with `router = APIRouter(prefix="/api/scans", tags=["scans"])`.

Implement `POST /api/scans` endpoint:

```python
@router.post("", response_model=ScanResponse, status_code=201)
@limiter.limit("10/minute")
async def trigger_scan(
    request: Request,
    scan_request: ScanCreateRequest,
    current_user: User = Depends(get_current_active_user),
    organization_id: uuid.UUID = Depends(get_current_organization_id),
    db: AsyncSession = Depends(get_db),
):
```

Logic flow:
1. Check for existing scan via `service.get_existing_scan(org_id, gemeente_code, db)`
2. If existing scan found AND `force_rescan=False`:
   - Compute days_old from `(datetime.utcnow() - existing.created_at).days`
   - Return ScanResponse with status="existing", needs_rescan=(days_old > 30)
   - This implements the user decision: "show existing results with re-scan option"
3. If existing AND `force_rescan=True`:
   - Call `service.reset_scan_for_rescan(existing, db)` to clear results
   - Use the reset scan record (re-scan overwrites in-place per user decision)
4. If no existing scan (or after reset): fetch gemeente bbox
   - Get httpx client from `request.app.state.http_client`
   - Call `get_gemeente_bbox(gemeente_code, client)` -- wrap in try/except ValueError for invalid gemeente
   - Pre-check parcel count: `await bag_wfs_client.get_pand_count_in_bbox(bbox, client)`
   - If count > 10000, raise HTTPException(400, "Scan would exceed 10,000 parcel limit. Found {count} parcels in {gemeente_naam}.")
   - This implements SCAN-06 requirement
5. Create scan record via `service.create_scan(...)` (or use reset scan)
6. Enqueue ARQ job:
   ```python
   arq_pool = request.app.state.arq_pool
   job = await arq_pool.enqueue_job("area_scan_job", str(scan.id), str(organization_id))
   scan.job_id = job.job_id
   db.add(scan)
   await db.flush()
   await db.commit()
   ```
7. Return ScanResponse with status="pending"

Use `from app.auth.dependencies import get_current_active_user, get_current_organization_id` and `from app.middleware.rate_limit import limiter` following existing router patterns.

Import `from app.government_apis.bag_wfs import bag_wfs_client` for count pre-check and `from app.services.gemeente_service import get_gemeente_bbox`.
