  'https://service.pdok.nl/kadaster/plu/wms/v1_0' +

**2. Create `frontend/src/components/map/BestemmingsplanLayer.tsx`:**

Follow ParcelBoundariesLayer.tsx pattern exactly. Module-level constants for source/layer IDs. Three exported functions:

- `addBestemmingsplanLayer(map)` — Adds WMS raster source (PDOK_BESTEMMINGSPLAN_WMS) with minzoom 10, maxzoom 19, tileSize 256. Adds raster layer with opacity 0.6, visibility 'none' (hidden by default). Guard: if source already exists, return early. Layer insertion: add at default position (no beforeLayer needed -- raster WMS layers sit below vector overlays automatically). Layer ID: `'bestemmingsplan-layer'`, source ID: `'pdok-bestemmingsplan'`.

- `removeBestemmingsplanLayer(map)` — Remove layer then source (same pattern as ParcelBoundariesLayer).

- `setBestemmingsplanVisibility(map, visible)` — Set layout visibility property.

Use minzoom 10 (not 12 like research suggested) so users see zoning at gemeente overview level. This is important for area-first workflow where users want zoning context before zooming in.
