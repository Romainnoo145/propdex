**1. Extend `frontend/src/lib/geo-utils.ts`** — add a `geoJsonToSvgPath` export below the existing `calculateBboxFromGeometry` function:

```typescript
export function geoJsonToSvgPath(
  geometry: GeoJSON.Polygon | GeoJSON.MultiPolygon,
  width = 200,
  height = 120,
  padding = 4
): { d: string; viewBox: string }
```

Implementation details (follow the research pseudocode in 43-RESEARCH.md):
- Collect all **exterior rings only** (`[0]` index of each polygon) — holes are ignored for a silhouette.
- For `Polygon`: one ring (`geometry.coordinates[0]`). For `MultiPolygon`: iterate `geometry.coordinates` and take `poly[0]` from each.
- Compute bounding box across all ring coordinates (minLon, maxLon, minLat, maxLat).
- Compute `lonRange` and `latRange` (guard against zero with `|| 1`).
- Compute `drawW = width - padding * 2` and `drawH = height - padding * 2`.
- Uniform scale: `scale = Math.min(drawW / lonRange, drawH / latRange)` — preserves aspect ratio.
- Center the projection: `offsetX = padding + (drawW - projW) / 2`, `offsetY = padding + (drawH - projH) / 2` where `projW = lonRange * scale`, `projH = latRange * scale`.
- Project function: `x = offsetX + (lon - minLon) * scale`, `y = offsetY + (maxLat - lat) * scale` — note `maxLat - lat` inverts Y axis (SVG Y grows downward, geographic latitude grows upward).
- Build SVG path string: for each ring, `M x0 y0 L x1 y1 ... Z`. Use `.toFixed(2)` for coordinate precision.
- Return `{ d: pathString, viewBox: \`0 0 ${width} ${height}\` }`.
