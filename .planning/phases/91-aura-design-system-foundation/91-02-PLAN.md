Add to `frontend/src/styles/index.css` (after the @theme block and typography utilities from plan 01):

**1. Micro-interaction utility classes:**
```css
/* Aura micro-interactions */
.aura-hover-pod {
  transition: transform 250ms cubic-bezier(0.4, 0, 0.2, 1),
              box-shadow 250ms cubic-bezier(0.4, 0, 0.2, 1);
}
.aura-hover-pod:hover {
  transform: scale(1.02);
  box-shadow: 0 0 20px rgba(249, 168, 38, 0.15);
}

.aura-hover-nav {
  transition: transform 200ms cubic-bezier(0.4, 0, 0.2, 1),
              background-color 200ms cubic-bezier(0.4, 0, 0.2, 1);
}
.aura-hover-nav:hover {
  transform: scale(1.05);
}

/* Floating panel GPU compositing hint */
.aura-float {
  will-change: transform;
}
```

**2. Performance fallback for prefers-reduced-motion:**
```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    transition-duration: 0ms !important;
    animation-duration: 0ms !important;
  }

  /* Disable all glass blur — solid white fallback */
  [class*="backdrop-blur"] {
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    background: white !important;
    border-color: #E2E8F0 !important;
  }

  /* Disable hover transforms */
  .aura-hover-pod:hover,
  .aura-hover-nav:hover {
    transform: none !important;
    box-shadow: none !important;
  }

  /* Disable will-change hints */
  .aura-float {
    will-change: auto;
  }
}
```

**3. Update the existing `.animate-slide-up` animation** to use the Aura timing:
```css
@keyframes slide-up {
  from { transform: translateY(100%); opacity: 0; }
  to { transform: translateY(0); opacity: 1; }
}
.animate-slide-up {
  animation: slide-up 300ms cubic-bezier(0.4, 0, 0.2, 1);
}
```

**4. Add fly-in animation for panels** (used by later phases):
```css
@keyframes fly-in-right {
  from { transform: translateX(100%); opacity: 0; }
  to { transform: translateX(0); opacity: 1; }
}
.animate-fly-in-right {
  animation: fly-in-right 300ms cubic-bezier(0.4, 0, 0.2, 1);
}
```

**Key rules:**
- The 250ms cubic-bezier timing is per user decision (Material-style glide)
- `scale-[1.02]` for pods (subtle professional), `scale(1.05)` for nav icons (slightly more pronounced) — differentiated per element type as allowed by Claude's discretion
- `will-change: transform` ONLY on `.aura-float` class (applied to floating panels), not globally
- The `@media (prefers-reduced-motion: reduce)` block uses `[class*="backdrop-blur"]` selector to catch all blur elements without knowing specific class names — per user decision for "full flat fallback"
