**1. Slide-up transition (overview to detail layer):**
Per CONTEXT.md: "detail content slides up over bento grid. Hero + address stay fixed."

Use Framer Motion AnimatePresence inside the panel:
```tsx
import { AnimatePresence, motion } from 'framer-motion'

// In the content area (below hero + address header):
<AnimatePresence mode="wait">
  {view.kind === 'overview' ? (
    <motion.div
      key="overview"
      initial={{ opacity: 1 }}
      exit={{ y: -20, opacity: 0 }}
      transition={{ duration: 0.2 }}
    >
      <ParcelBentoOverview ... />
    </motion.div>
  ) : (
    <motion.div
      key={view.kind}
      initial={{ y: 40, opacity: 0 }}
      animate={{ y: 0, opacity: 1 }}
      exit={{ y: 40, opacity: 0 }}
      transition={{ type: 'spring', stiffness: 400, damping: 30 }}
      className="overflow-y-auto flex-1"
    >
      {renderDetailLayer()}
    </motion.div>
  )}
</AnimatePresence>
```

- Overview exits with subtle upward slide + fade
- Detail layer enters with slide-up from below + spring
- `mode="wait"` ensures exit completes before enter starts
- `prefers-reduced-motion`: check and skip animation if needed
