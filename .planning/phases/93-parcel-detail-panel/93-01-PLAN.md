  <name>Task 1: Backend aerial crop endpoint</name>
  <files>backend/app/scans/router.py</files>
  <action>
Add a GET endpoint at `/parcels/{parcel_id}/aerial-crop` to the scans router.

Implementation:
1. Query `ParcelCache` for the parcel's geometry centroid using PostGIS `ST_Centroid` + `ST_X`/`ST_Y` (in EPSG:28992 since geometry is stored in RD)
2. Build a PDOK WMS GetMap URL:
   - Base: `https://service.pdok.nl/hwh/luchtfotorgb/wms/v1_0`
   - Params: `SERVICE=WMS&VERSION=1.3.0&REQUEST=GetMap&LAYERS=Actueel_orthoHR&STYLES=&CRS=EPSG:28992&FORMAT=image/jpeg`
   - BBOX: centroid +/- 75m width, height scaled to 380x160 aspect ratio (half_h = 75 * 160/380 = ~31.6m)
   - WIDTH=760, HEIGHT=320 (2x for retina)
3. Fetch via `request.app.state.http_client` with timeout=10s
4. Return `Response(content=resp.content, media_type="image/jpeg", headers={"Cache-Control": "public, max-age=86400"})`
5. Add rate limit `60/minute` via `@limiter.limit`
6. Require auth via `get_current_active_user` + `get_current_organization_id`
7. Return 404 if parcel not found, 502 if PDOK unavailable

Use `ST_X(ST_Centroid(ParcelCache.geometry))` and `ST_Y(ST_Centroid(ParcelCache.geometry))` from `geoalchemy2.functions` to get coordinates directly as floats (no regex parsing of WKT needed).

Filter by `organization_id` for multi-tenant security.
