  **1. find_parcels_in_bbox()** -- Find parcels within a bounding box

  ```python
  async def find_parcels_in_bbox(
      minx: float, miny: float, maxx: float, maxy: float,
      db: AsyncSession,
      limit: int = 10000,
  ) -> list[ParcelCache]:
  ```
  - Create envelope with `func.ST_MakeEnvelope(minx, miny, maxx, maxy, 28992)`
  - Two-stage filter: `ParcelCache.geometry.op("&&")(bbox)` for GIST index pre-filter, then `func.ST_Intersects(ParcelCache.geometry, bbox)` for precise check
  - Apply `.limit(limit)` to prevent unbounded queries
  - Return `result.scalars().all()`

  **2. get_parcel_as_geojson()** -- Get single parcel as EPSG:4326 GeoJSON dict

  ```python
  async def get_parcel_as_geojson(
      parcel_id: uuid.UUID,
      db: AsyncSession,
  ) -> dict | None:
  ```
  - Select ParcelCache.id, address, parcel_id (kadaster id), gemeente_code, area_m2, has_pand, bestemmingen
  - Add `func.ST_AsGeoJSON(func.ST_Transform(ParcelCache.geometry, 4326)).label("geojson")`
  - Return GeoJSON Feature dict with properties and geometry, or None if not found
  - Parse geometry string with `json.loads(row.geojson)`

  **3. get_parcels_as_feature_collection()** -- Get multiple parcels as GeoJSON FeatureCollection

  ```python
  async def get_parcels_as_feature_collection(
      parcel_ids: list[uuid.UUID],
      db: AsyncSession,
  ) -> dict:
  ```
  - Batch query with `ParcelCache.id.in_(parcel_ids)`
  - Transform each to Feature, wrap in FeatureCollection
  - Return `{"type": "FeatureCollection", "features": [...]}`

  **4. validate_and_fix_geometry()** -- Validate geometry and auto-repair if invalid

  ```python
  async def validate_and_fix_geometry(
      geom_wkt: str,
      srid: int = 28992,
      db: AsyncSession,
  ) -> str:
  ```
  - Parse WKT to geometry: `func.ST_GeomFromText(geom_wkt, srid)`
  - Check validity: `func.ST_IsValid(geom)`
  - If invalid, log reason via `func.ST_IsValidReason(geom)` and repair with `func.ST_MakeValid(geom)`
  - Return WKT of validated/repaired geometry via `func.ST_AsText(geom)`

  **5. Python-side coordinate helpers** (no DB needed, module-level):

  ```python
  from pyproj import Transformer

  # Module-level transformers (thread-safe, reusable)
  _transformer_to_4326 = Transformer.from_crs("EPSG:28992", "EPSG:4326", always_xy=True)
  _transformer_to_28992 = Transformer.from_crs("EPSG:4326", "EPSG:28992", always_xy=True)

  def transform_point_to_wgs84(x: float, y: float) -> tuple[float, float]:
      """Transform EPSG:28992 (RD New) point to EPSG:4326 (WGS84). Returns (lon, lat)."""
      lon, lat = _transformer_to_4326.transform(x, y)
      return lon, lat

  def transform_point_to_rd(lon: float, lat: float) -> tuple[float, float]:
      """Transform EPSG:4326 (WGS84) point to EPSG:28992 (RD New). Returns (x, y)."""
      x, y = _transformer_to_28992.transform(lon, lat)
      return x, y

  def transform_bbox_to_wgs84(
      minx: float, miny: float, maxx: float, maxy: float,
  ) -> tuple[float, float, float, float]:
      """Transform EPSG:28992 bbox to EPSG:4326. Returns (min_lon, min_lat, max_lon, max_lat)."""
      min_lon, min_lat = _transformer_to_4326.transform(minx, miny)
      max_lon, max_lat = _transformer_to_4326.transform(maxx, maxy)
      return min_lon, min_lat, max_lon, max_lat

  def transform_bbox_to_rd(
      min_lon: float, min_lat: float, max_lon: float, max_lat: float,
  ) -> tuple[float, float, float, float]:
      """Transform EPSG:4326 bbox to EPSG:28992. Returns (minx, miny, maxx, maxy)."""
      minx, miny = _transformer_to_28992.transform(min_lon, min_lat)
      maxx, maxy = _transformer_to_28992.transform(max_lon, max_lat)
      return minx, miny, maxx, maxy
  ```
