**useWijkGeoJSON hook** (`frontend/src/hooks/useWijkGeoJSON.ts`):
- TanStack Query hook wrapping `fetchWijken` from `@/lib/api`
- Signature: `useWijkGeoJSON(gemeenteCode: string | null)`
- Returns `useQuery<GeoJSON.FeatureCollection, Error>`
- Query key: `['wijk-geojson', gemeenteCode]`
- `enabled: !!accessToken && !!gemeenteCode` (use `useAuth()` for accessToken)
- `staleTime: 30 * 60 * 1000` (30 minutes -- CBS WFS data is stable)
- Pass `gemeenteCode` directly to `fetchWijken` (do NOT strip GM prefix -- backend handles it per wijk_service.py)

**WijkCardGrid component** (`frontend/src/components/projects/WijkCardGrid.tsx`):

Props interface `WijkCardGridProps`:
- `gemeente: ProjectResponse` -- the selected gemeente-level project
- `wijkProjects: ProjectResponse[]` -- wijk children (filtered by parent from allProjects)
- `unreadData: UnreadDetailResponse | undefined` -- from useUnreadCounts (passed from parent)
- `onBack: () => void` -- callback to clear selectedGemeenteId
- `onWijkClick: (wijk: ProjectResponse) => void` -- callback for wijk card click (parent handles navigation)

Import types: `ProjectResponse` from `@/lib/types/project`, `UnreadDetailResponse` from `@/lib/types/monitoring`.

Implementation:
1. Call `useWijkGeoJSON(gemeente.gemeente_code)` to fetch wijk boundaries
2. Render breadcrumb header:
   - `<div className="flex items-center gap-2">`
   - Back button: `<button onClick={onBack} className="text-sm text-grey-400 hover:text-grey-100 transition-colors">` with left arrow character and "Gemeenten" text
   - Separator: `<span className="text-grey-600">/</span>`
   - Current: `<span className="text-sm font-medium text-grey-100">{gemeente.name}</span>`
3. Loading state: if `isLoading` from useWijkGeoJSON, render `<GemeenteCardGridSkeleton count={wijkProjects.length || 3} />`
4. Grid: reuse `<GemeenteCardGrid>` wrapper (the responsive grid). For each wijk in `wijkProjects`:
   - Compute `unreadCount` from `unreadData?.per_project.find(p => p.project_id === wijk.id)?.unread_count ?? 0`
   - Match wijk to CBS WFS feature by name: `wijkGeojson?.features.find(f => f.properties?.statnaam === wijk.wijk_naam)` (use statnaam NOT statcode per Research Pitfall 1)
   - Compute svgData: `feature ? geoJsonToSvgPath(feature.geometry as GeoJSON.Polygon | GeoJSON.MultiPolygon) : null`
   - Render `<WijkCard key={wijk.id} wijk={wijk} svgData={svgData} unreadCount={unreadCount} onClick={() => onWijkClick(wijk)} />`
