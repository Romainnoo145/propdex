**Change 2 — Create `backend/app/admin/data_source_probe_orchestrator.py`** (~50 lines).

This module exports one async function `run_opportunistic_probes`:

```python
"""Opportunistic probe orchestrator for the data-sources GET endpoint."""
import asyncio
from datetime import datetime

from sqlalchemy import BigInteger, func, select, type_coerce
from sqlalchemy.ext.asyncio import AsyncSession

from app.admin.data_source_probes import compute_lock_key, probe_type_a_cascade
from app.admin.data_sources_helpers import (
    _load_or_create_row,
    _row_from_db,
    _synthesize_missing_row,
)
from app.admin.data_sources_schemas import DataSourceRow
from app.models.data_source_status import DataSourceStatus
from app.policy_documents.data_source_keys import DATA_SOURCE_KEYS


async def run_opportunistic_probes(
    gemeente_code: str,
    cascade_uploads: list[DataSourceRow],
    db: AsyncSession,
    name_map: dict[str, str],  # passed for future use; currently unused
) -> list[DataSourceRow]:
    ...
```

Logic inside `run_opportunistic_probes`:
1. Identify missing Type A keys: `missing_keys = [row.source_key for row in cascade_uploads if row.status == "missing"]`. If empty, return `cascade_uploads` unchanged immediately.
2. For each missing key, attempt advisory lock acquisition using the same pattern as `refresh_source` in the router (compute_lock_key + pg_try_advisory_xact_lock). Collect keys where lock was acquired into `locked_keys`.
3. If `locked_keys` is empty, return `cascade_uploads` unchanged.
4. Run `asyncio.gather(*[probe_type_a_cascade(key, gemeente_code, db) for key in locked_keys])` to get a list of `ProbeResult` dicts.
5. For each `(key, probe_result)` pair: if `probe_result["status"] != "missing"`, call `_load_or_create_row(gemeente_code, key, db)`, set `row.status = probe_result["status"]`, `row.error_message = probe_result["error_message"]`, `row.last_checked = datetime.utcnow()`.
6. Call `await db.commit()` once after all updates.
7. Re-fetch all `DataSourceStatus` rows for the gemeente: `db_rows = (await db.execute(select(DataSourceStatus).where(DataSourceStatus.gemeente_code == gemeente_code))).scalars().all()`. Build `by_key` dict.
8. Rebuild and return `cascade_uploads` for Type A entries only, using `_row_from_db` / `_synthesize_missing_row` and `DATA_SOURCE_KEYS`.

Advisory lock acquisition loop (step 2) — do this sequentially, one scalar call per key:
```python
locked_keys: list[str] = []
for key in missing_keys:
    lock_key = compute_lock_key(gemeente_code, key)
    acquired = bool(
        await db.scalar(
            select(func.pg_try_advisory_xact_lock(type_coerce(lock_key, BigInteger())))
        )
    )
    if acquired:
        locked_keys.append(key)
```
