  <action>
    Create `backend/app/services/category_classifier.py` with a `classify_bekendmaking(title: str, change_type: str) -> str` function.

    The function returns a human-readable Dutch label based on keyword matching in the title and the change_type:

    For change_type == "permit":
      - Title contains "aangevraagde" or "aanvraag" -> "Omgevingsvergunning aangevraagd"
      - Title contains "verleende" or "verleend" or "vergunning verleend" -> "Omgevingsvergunning verleend"
      - Title contains "geweigerde" or "geweigerd" -> "Omgevingsvergunning geweigerd"
      - Title contains "ingetrokken" -> "Omgevingsvergunning ingetrokken"
      - Title contains "buiten behandeling" -> "Buiten behandeling gesteld"
      - Title contains "bezwaar" or "bezwaarschrift" -> "Bezwaar ingediend"
      - Title contains "ontwerpbesluit" or "ter inzage" -> "Ontwerpbesluit ter inzage"
      - Title contains "reguliere" -> "Reguliere omgevingsvergunning"
      - Title contains "melding" and ("sloop" or "brandveilig") -> "Sloop-/brandveiligheidmelding"
      - Title contains "kapvergunning" or "kappen" -> "Kapvergunning"
      - Fallback for permit: "Omgevingsvergunning"

    For change_type == "zoning":
      - Title contains "nieuw plan" or "Nieuw plan" -> "Nieuw bestemmingsplan"
      - Title contains "gewijzigd" or "Plan gewijzigd" -> "Bestemmingsplan gewijzigd"
      - Title contains "vastgesteld" -> "Bestemmingsplan vastgesteld"
      - Title contains "ontwerp" -> "Ontwerpbestemmingsplan"
      - Fallback for zoning: "Bestemmingsplanwijziging"

    Use case-insensitive matching (title.lower()). Check keywords in order of specificity (most specific first).

    Write tests in `backend/tests/unit/test_category_classifier.py`:
      - Test each permit category (aangevraagd, verleend, geweigerd, ingetrokken, etc.)
      - Test each zoning category (nieuw plan, gewijzigd, vastgesteld)
      - Test fallback for unclassifiable permit title
      - Test fallback for unclassifiable zoning title
      - Test case-insensitive matching
      - At least 12 test cases
  </action>
