<feature>
  <name>Dutch address extraction from SRU bekendmaking titles</name>
  <files>backend/app/services/address_extractor.py, backend/tests/unit/test_address_extractor.py</files>
  <behavior>
    extract_address_from_title(title: str) -> dict | None

    Returns a dict with keys: street, huisnummer, huisnummer_toevoeging, postcode, city, full_address
    Returns None when no address can be extracted.

    Real SRU title formats to handle (from Officiële Bekendmakingen):

    Format A — "Address, keyword Type (date)"
      "Kerkstraat 42, 1234AB Venlo, aangevraagde Omgevingsvergunning (15-02-2026)"
      -> {street: "Kerkstraat", huisnummer: 42, postcode: "1234AB", city: "Venlo", ...}

    Format B — "Keyword Type Address, Postcode City"
      "Verleende Omgevingsvergunning - Marktplein 7, 5935 BG Steyl"
      -> {street: "Marktplein", huisnummer: 7, postcode: "5935BG", city: "Steyl", ...}

    Format C — "Keyword for activity, Address, Postcode City"
      "Aanvraag omgevingsvergunning voor het kappen van een boom, Dorpsstraat 15a, 3812 KV Amersfoort"
      -> {street: "Dorpsstraat", huisnummer: 15, huisnummer_toevoeging: "a", postcode: "3812KV", city: "Amersfoort", ...}

    Format D — "Address without postcode, keyword Type"
      "Hoofdweg 123, aangevraagde Omgevingsvergunning"
      -> {street: "Hoofdweg", huisnummer: 123, postcode: None, city: None, ...}

    Format E — "Keyword Type Address (no postcode, no comma)"
      "Omgevingsvergunning Parkweg 88"
      -> {street: "Parkweg", huisnummer: 88, postcode: None, city: None, ...}

    Format F — With huisnummer additions
      "Reguliere omgevingsvergunning Laan van Meerdervoort 123-A, 2517 AZ Den Haag"
      -> {street: "Laan van Meerdervoort", huisnummer: 123, huisnummer_toevoeging: "A", postcode: "2517AZ", city: "Den Haag", ...}

    Format G — "Bestemmingsplan naam" (no address — should return None)
      "Bestemmingsplan Buitengebied 2020, herziening 3"
      -> None

    Format H — Prefix with bekendmaking source
      "Gemeente Venlo - Omgevingsvergunning, Kaldenkerkerweg 88, 5913AE Venlo"
      -> {street: "Kaldenkerkerweg", huisnummer: 88, postcode: "5913AE", city: "Venlo", ...}

    Format I — "ter inzage" / "ontwerpbesluit" patterns
      "Ontwerpbesluit omgevingsvergunning Stationsweg 5, 6811 MH Arnhem"
      -> {street: "Stationsweg", huisnummer: 5, postcode: "6811MH", city: "Arnhem", ...}

    extract_huisnummer(address_str: str) -> int | None
      "Kerkstraat 42" -> 42
      "Laan van Meerdervoort 123-A" -> 123
      "No number here" -> None
  </behavior>
  <implementation>
    1. Create backend/app/services/address_extractor.py as a standalone module:
       - Use a multi-strategy approach (not a single giant regex):
         a. Try postcode-anchored extraction first (most reliable when postcode present)
         b. Try keyword-anchored extraction (before ", aangevraagde"  etc.)
         c. Try dash-separator extraction ("Type - Address")
         d. Try "gemeente prefix" extraction (after "Gemeente X - ")
         e. Try bare street+number fallback
       - Normalize postcodes to "1234AB" (strip spaces)
       - Parse huisnummer and huisnummer_toevoeging separately
       - Return structured dict, not just raw string
    2. Update change_detector.py to import from address_extractor instead of using inline _extract_address_from_title
    3. Store the structured dict's full_address in ChangeRecord.address (same as before) plus the individual fields in metadata_json for Phase 48 matching
  </implementation>
</feature>
