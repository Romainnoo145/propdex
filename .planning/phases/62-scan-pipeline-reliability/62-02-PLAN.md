<objective>
Make the gemeente wijk scan orchestrator's --force-all flag perform a full clean-slate re-scan (delete existing results, re-fetch all API data, re-score) and print an end-of-run summary table for scan operators.

Purpose: Existing scans used `ON CONFLICT DO NOTHING` which means stale data from previous broken runs persists even when re-running. The --force-all flag already exists in the CLI but uses `reset_scan_for_rescan` which deletes ScanResult rows — this is correct. What's missing is the end-of-run summary that gives operators visibility into scan quality, and ensuring the reset also clears the new coverage fields.

Output: Updated orchestrator with summary table, updated service to reset new fields.
</objective>

    if existing_scan_id is not None:
        existing_scan = await session.get(AreaScan, uuid.UUID(existing_scan_id))

        # Count existing results for logging
        from sqlalchemy import func as sqla_func

    **Part C: Add end-of-run summary table**

    In `run_gemeente_wijk_scans.py`, add a `@dataclass` for tracking scan outcomes:

    ```python
    @dataclass(slots=True)
    class WijkOutcome:
        wijk_naam: str
        status: str
        parcel_count: int = 0
        coverage_ratio: float | None = None
        address_resolution_ratio: float | None = None
    ```

    After the main loop in `main()`, collect outcomes and print a summary table. Track outcomes as scans complete:

    1. Add `outcomes: list[WijkOutcome] = []` before the queue processing loop.
    2. For each completed scan (after `_wait_for_scan` returns), load the scan to get stats:
       ```python
       async with session_factory() as session:
           scan = await session.get(AreaScan, uuid.UUID(scan_id))
           outcome = WijkOutcome(
               wijk_naam=item.wijk_naam,
               status=final_status,
               parcel_count=scan.parcels_total if scan else 0,
               coverage_ratio=scan.coverage_ratio if scan else None,
               address_resolution_ratio=scan.address_resolution_ratio if scan else None,
           )
       outcomes.append(outcome)
       ```
    3. For skipped wijken, add a simpler outcome:
       ```python
       outcomes.append(WijkOutcome(wijk_naam=item.wijk_naam, status=item.action))
       ```

    4. After the loop, print a summary table:
       ```python
       print("\n" + "=" * 80)
       print("SCAN SUMMARY")
       print("=" * 80)
       print(f"{'Wijk':<30} {'Status':<25} {'Parcels':>8} {'Coverage':>10} {'Addresses':>10}")
       print("-" * 80)
       for o in outcomes:
           cov = f"{o.coverage_ratio * 100:.0f}%" if o.coverage_ratio is not None else "-"
           addr = f"{o.address_resolution_ratio * 100:.0f}%" if o.address_resolution_ratio is not None else "-"
           status_icon = {"completed": "OK", "completed_with_warnings": "WARN", "failed": "FAIL"}.get(o.status, o.status[:10])
           print(f"{o.wijk_naam:<30} {status_icon:<25} {o.parcel_count:>8} {cov:>10} {addr:>10}")
       print("=" * 80)

       completed = sum(1 for o in outcomes if o.status in {"completed", "completed_with_warnings"})
       failed = sum(1 for o in outcomes if o.status == "failed")
       skipped = sum(1 for o in outcomes if o.status.startswith("skip"))
       print(f"Completed: {completed}  Failed: {failed}  Skipped: {skipped}  Total: {len(outcomes)}")
       ```

    5. If the batch stopped early due to failure, also show remaining wijken as "not_started" in the summary.

    **Part D: Stop-on-failure → continue-on-failure for --force-all**

    Currently the orchestrator breaks out of the loop on first failure. For `--force-all` mode, change this to continue (log the failure, record outcome, move to next wijk) since the operator wants a complete run. Keep the break behavior for normal (non-force) runs.

    Change:
    ```python
    if final_status != "completed":
        print("Stopping batch after failure.")
        break
    ```
    To:
    ```python
    if final_status not in {"completed", "completed_with_warnings"}:
        if args.force_all or args.force_failed:
            print(f"  [{item.wijk_naam}] failed — continuing batch (force mode)")
        else:
            print("Stopping batch after failure.")
            break
    ```
