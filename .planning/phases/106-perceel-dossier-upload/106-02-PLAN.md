Create `frontend/src/lib/types/document.ts`:
```typescript
export interface ParcelDocumentMeta {
  id: string
  parcel_id: string
  document_type: string
  filename: string
  content_type: string
  file_size: number
  uploaded_at: string
  uploaded_by_user_id: string | null
}
```

Add to `frontend/src/lib/api.ts` (append, do not modify existing functions):

1. `fetchParcelDocuments(parcelId: string, accessToken: string): Promise<{ documents: ParcelDocumentMeta[], total: number }>` — GET /api/documents/{parcelId}/documents using apiFetch

2. `uploadParcelDocument(parcelId: string, documentType: string, file: File, accessToken: string): Promise<ParcelDocumentMeta>` — POST with FormData. MUST use raw `fetch` (NOT apiFetch) because apiFetch auto-sets Content-Type to application/json which breaks multipart. Same pattern as fetchAerialCrop. Include Authorization Bearer header manually.

3. `deleteParcelDocument(parcelId: string, documentId: string, accessToken: string): Promise<void>` — DELETE /api/documents/{parcelId}/documents/{documentId} using apiFetch

4. `getDocumentDownloadUrl(parcelId: string, documentId: string): string` — Returns the URL string `/api/documents/${parcelId}/documents/${documentId}` (for <a href> download links, auth handled by cookie/header)

Create `frontend/src/hooks/useDocuments.ts`:
- `useParcelDocuments(parcelId: string | undefined)` — useQuery with queryKey ['parcel-documents', parcelId], enabled when parcelId and accessToken truthy. Uses useAuth() for token.
- `useUploadDocument()` — useMutation wrapping uploadParcelDocument. On success: invalidate ['parcel-documents', vars.parcelId] query. Uses useAuth() for token.
- `useDeleteDocument()` — useMutation wrapping deleteParcelDocument. On success: invalidate ['parcel-documents', vars.parcelId] query. Uses useAuth() for token.

Follow the useParcelEnrichment pattern from hooks/useScans.ts for auth token injection.
