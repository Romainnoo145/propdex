Create `backend/app/documents/router.py` with APIRouter(prefix="/api/documents", tags=["Documents"]):

1. **POST /{parcel_id}/documents** — Upload document
   - Params: parcel_id (path), document_type (query), file (UploadFile)
   - Dependencies: get_current_active_user, get_current_organization_id, get_db
   - Rate limit: 10/minute
   - Validate: document_type in VALID_DOCUMENT_TYPES set (the 22 keys from BronnenLayer: bestemmingscheck, perceeldata, vergunninghistorie, woz, quickscan, bodem, fundering, asbest, bouwkundig, energielabel, bestemmingsplan, milieuzones, geluid, stikstof, kadaster, eigendom, erfpacht, documenten, correspondentie, ideeen)
   - Validate: file.content_type in ALLOWED_CONTENT_TYPES (application/pdf, image/jpeg, image/png, image/webp, application/vnd.openxmlformats-officedocument.wordprocessingml.document, application/vnd.openxmlformats-officedocument.spreadsheetml.sheet)
   - Validate: file size <= 25MB (read bytes, check len)
   - Create ParcelDocument, db.add(), await db.commit()
   - Return DocumentResponse (201)

2. **GET /{parcel_id}/documents** — List documents for parcel
   - Filter by organization_id AND parcel_id
   - Use `defer(ParcelDocument.file_data)` to avoid loading bytes
   - Optional query param: document_type (filter by card key)
   - Return DocumentListResponse

3. **GET /{parcel_id}/documents/{document_id}** — Download/preview
   - Filter by organization_id, parcel_id, document_id
   - Return Response(content=doc.file_data, media_type=doc.content_type) with Content-Disposition inline header
   - 404 if not found

4. **DELETE /{parcel_id}/documents/{document_id}** — Delete document
   - Filter by organization_id, parcel_id, document_id
   - Any org member can delete (simplest permission model)
   - await db.delete(doc), await db.commit()
   - Return 204
