  <action>
    1. Install rollup-plugin-visualizer as dev dependency:
       Run: `npm install --save-dev rollup-plugin-visualizer` in the frontend/ directory.

    2. Update frontend/vite.config.ts. Read the current file first to preserve all existing config exactly. Make these targeted changes:

       a. Add import at the top: `import { visualizer } from 'rollup-plugin-visualizer';`

       b. Change `TanStackRouterVite()` to `TanStackRouterVite({ autoCodeSplitting: true })` in the plugins array.

       c. Add visualizer to the plugins array (conditional, after existing plugins):
          ```typescript
          ...(process.env.ANALYZE ? [visualizer({ open: false, filename: 'dist/stats.html' })] : []),
          ```
          Note: Use `open: false` (not `open: true`) — opening a browser window is not useful in headless execution.

       d. Add build config AFTER the plugins array but BEFORE the server config:
          ```typescript
          build: {
            rollupOptions: {
              output: {
                manualChunks(id) {
                  if (id.includes('node_modules')) {
                    if (id.includes('react') && !id.includes('react-hook-form')) return 'vendor-react';
                    if (id.includes('maplibre-gl')) return 'vendor-maplibre';
                    if (id.includes('@tanstack')) return 'vendor-tanstack';
                    if (id.includes('lucide-react')) return 'vendor-icons';
                    return 'vendor';
                  }
                },
              },
            },
          },
          ```

       CRITICAL: Only apply manualChunks to node_modules (vendor code). Never return a chunk name for app code — leave autoCodeSplitting to handle route splitting. This avoids Pitfall 2 (conflicting chunk assignments).

       CRITICAL: The plugins order must remain: TanStackRouterVite FIRST, then react(), then tailwindcss(), then optional visualizer. TanStack plugin must precede react() for correct transform order.

       Preserve ALL existing server config (port: 9300, proxy), resolve.alias, and test config exactly as-is.
  </action>
