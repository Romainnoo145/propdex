<objective>
Disable backdrop-blur glassmorphism effects on mobile for all floating map UI elements, replacing with solid Industrial Amber backgrounds. Desktop glass effects are preserved per DS-04 design decisions.

Purpose: backdrop-filter: blur() is GPU-intensive and causes janky animations and low framerates on mid-range mobile devices. The DS-04 rule already established that floating map cards use glass; this plan makes that glass mobile-conditional.
Output: 5 files updated with responsive glassmorphism — solid on mobile (<768px), blur on desktop (md: breakpoint).
</objective>
