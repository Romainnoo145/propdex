  - bouwjaar < 1970 + leem → middel (variable bearing capacity)
  - bouwjaar < 1970 + zand → laag (op staal foundation)
  - bouwjaar < 1970 + onbekend soil → onbekend
  - Each branch returns Dutch-language `reden` text explaining the derivation
  - hoog/middel risk includes `recommended_action` text

- `estimate_kcaf_cost(*, risk: str, oppervlakte_m2: int | None) -> KCAFCostIndication | None` — static lookup:

  - laag/onbekend/other: return None
  - oppervlakte_m2 is None or <= 0: return None
  - Disclaimer includes per-m2 range and "Dit is geen offerte" text
  - Note in disclaimer that oppervlakte is gebruiksoppervlakte (BAG), werkelijke kosten mogelijk lager

  - Risk order: hoog=3, middel=2, laag=1, geen=0
  - "onbekend" risks are excluded from worst-of (don't drag overall down)
  - bodem_data with dossiers = at least middel
  - Returns FysiekRisicoProfiel with all fields populated
