<task type="auto">
  <name>Task 2: Configure Vite, TypeScript, ESLint, Tailwind, z-index scale, and PDOK constants</name>
  <files>
    frontend/vite.config.ts

  <action>
    1. Configure vite.config.ts:
       ```typescript
       import { defineConfig } from 'vite';
       import react from '@vitejs/plugin-react';
       import tailwindcss from '@tailwindcss/vite';

       export default defineConfig({
         plugins: [react(), tailwindcss()],
         server: {
           port: 9300,
           proxy: {
             '/api': {
               target: 'http://localhost:8000',
               changeOrigin: true,
             },
           },
         },
         resolve: {
           alias: {
             '@': '/src',
           },
         },
       });
       ```

    2. Configure tsconfig.json as project references root:
       ```json
       {
         "files": [],
         "references": [
           { "path": "./tsconfig.app.json" },
           { "path": "./tsconfig.node.json" }
         ]
       }
       ```

    3. Configure tsconfig.app.json with strict mode:
       ```json
       {
         "compilerOptions": {
           "target": "ES2022",
           "lib": ["ES2022", "DOM", "DOM.Iterable"],
           "module": "ESNext",
           "moduleResolution": "bundler",
           "jsx": "react-jsx",
           "strict": true,
           "noImplicitAny": true,
           "strictNullChecks": true,
           "strictFunctionTypes": true,
           "noImplicitReturns": true,
           "noFallthroughCasesInSwitch": true,
           "noUncheckedIndexedAccess": true,
           "esModuleInterop": true,
           "skipLibCheck": true,
           "forceConsistentCasingInFileNames": true,
           "resolveJsonModule": true,
           "isolatedModules": true,
           "noEmit": true,
           "paths": {
             "@/*": ["./src/*"]
           }
         },
         "include": ["src"]
       }
       ```

    4. Configure tsconfig.node.json for Vite config:
       ```json
       {
         "compilerOptions": {
           "target": "ES2022",
           "lib": ["ES2022"],
           "module": "ESNext",
           "moduleResolution": "bundler",
           "strict": true,
           "noEmit": true,
           "skipLibCheck": true,
           "isolatedModules": true,
           "esModuleInterop": true
         },
         "include": ["vite.config.ts"]
       }
       ```

    5. Configure eslint.config.js (flat config, ESLint 9):
       ```javascript
       import js from '@eslint/js';
       import tseslint from 'typescript-eslint';
       import reactHooks from 'eslint-plugin-react-hooks';

       export default tseslint.config(
         { ignores: ['dist'] },
         {
           extends: [js.configs.recommended, ...tseslint.configs.recommended],
           files: ['**/*.{ts,tsx}'],
           plugins: {
             'react-hooks': reactHooks,
           },
           rules: {
             ...reactHooks.configs.recommended.rules,
             '@typescript-eslint/no-unused-vars': ['error', { argsIgnorePattern: '^_' }],
           },
         },
       );
       ```

    6. Create src/styles/index.css with Tailwind import and z-index scale:
       ```css
       @import "tailwindcss";

       :root {
         /* Z-index scale (steps of 100 for flexibility) */
         --z-map-canvas: 0;
         --z-map-controls: 10;
         --z-search-bar: 100;
         --z-sidebar: 200;
         --z-property-panel: 300;
         --z-dropdown: 400;
         --z-modal: 1000;
         --z-toast: 2000;

         /* Brand colors as CSS variables (NEVER hardcode) */
         --color-primary: #2563eb;
         --color-primary-hover: #1d4ed8;
         --color-surface: #ffffff;
         --color-surface-secondary: #f8fafc;
         --color-text: #0f172a;
         --color-text-secondary: #64748b;
         --color-border: #e2e8f0;
       }
       ```

    7. Create src/lib/pdok.ts with tile URL constants:
       ```typescript
       /**
        * PDOK tile service URLs for MapLibre GL JS.
        *
        * Tile services (WMTS) are safe for direct browser access.
        * Data APIs (BAG, DSO, Kadaster) must be proxied through the backend.
        *
        * @see https://www.pdok.nl/introductie/-/article/pdok-luchtfoto-rgb-open-
        */

       /** PDOK Aerial imagery (Luchtfoto RGB) — latest orthophotos */
       export const PDOK_AERIAL_TILES =
         'https://service.pdok.nl/hwh/luchtfotorgb/wmts/v1_0/Actueel_ortho8RGB/EPSG:3857/{z}/{x}/{y}.jpeg';

       /** PDOK Topographic map (BRT Achtergrondkaart) — standard Dutch topo */
       export const PDOK_TOPO_TILES =
         'https://service.pdok.nl/brt/achtergrondkaart/wmts/v2_0/standaard/EPSG:3857/{z}/{x}/{y}.png';

       /** Attribution text for PDOK layers */
       export const PDOK_AERIAL_ATTRIBUTION = '© PDOK - Actuele luchtfoto';
       export const PDOK_TOPO_ATTRIBUTION = '© PDOK - BRT Achtergrondkaart';

       /** Default map center: Netherlands (Amsterdam area) */
       export const DEFAULT_CENTER: [number, number] = [4.9, 52.37];

       /** Default zoom level (shows Amsterdam metro area) */
       export const DEFAULT_ZOOM = 12;
       ```

    8. Add scripts to package.json:
       ```json
       "scripts": {
         "dev": "vite",

         "lint": "eslint .",
         "check": "tsc -b --noEmit && eslint .",
         "typecheck": "tsc -b --noEmit"
       }
       ```

    9. Run `pnpm run check` from frontend/ and fix ALL errors before continuing.
