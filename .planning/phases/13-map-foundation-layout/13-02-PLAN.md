<task type="auto">
  <name>Task 1: Create MapView component with imperative state and memory cleanup</name>
  <files>
    frontend/src/components/map/MapView.tsx
  </files>
  <action>
    Create `frontend/src/components/map/MapView.tsx` — the core map component.

    Requirements:
    - Use `useRef<maplibregl.Map | null>` for map instance (NOT useState — causes re-render loops)
    - Use `useRef<HTMLDivElement>` for map container DOM element
    - Initialize map in useEffect with empty dependency array (mount once)
    - Import MapLibre CSS: `import 'maplibre-gl/dist/maplibre-gl.css'`

    Map initialization:
    - Use inline style object (version 8) with TWO sources:
      - `'pdok-aerial'`: raster source using `PDOK_AERIAL_TILES` from `@/lib/pdok`
      - `'pdok-topo'`: raster source using `PDOK_TOPO_TILES` from `@/lib/pdok`
    - Both sources: `tileSize: 256`, proper attribution from pdok.ts constants
    - TWO layers:
      - `'pdok-aerial-layer'`: raster, source 'pdok-aerial', visibility 'visible' (default)
      - `'pdok-topo-layer'`: raster, source 'pdok-topo', visibility 'none'
    - Center: `DEFAULT_CENTER` from pdok.ts
    - Zoom: `DEFAULT_ZOOM` from pdok.ts

    Map controls (added after initialization):
    - `NavigationControl` at 'top-right' (zoom + compass + rotation)
    - `GeolocateControl` at 'top-right' (browser geolocation)

    Expose map ref:
    - Accept an optional `onMapReady?: (map: maplibregl.Map) => void` callback prop
    - Call `onMapReady` in the map's 'load' event handler
    - Also expose `mapRef` via `useImperativeHandle` with a forwarded ref, OR simply accept a `mapRef` prop of type `React.MutableRefObject<maplibregl.Map | null>` so parent can access the map instance. Prefer the prop approach (simpler).

    Memory cleanup (CRITICAL):
    - In useEffect cleanup function:
      1. Call `map.remove()` to destroy the map instance and release WebGL context
      2. Set `mapRef.current = null`
    - This prevents MapLibre Worker class memory leaks documented in issues #4811 and #3733

    Styling:
    - Container div: `className="w-full h-full"` (parent controls dimensions)
    - Do NOT set height/width inline — let AppLayout handle viewport sizing

    Type the component props:
    ```typescript
    interface MapViewProps {
      mapRef?: React.MutableRefObject<maplibregl.Map | null>;
      onMapReady?: (map: maplibregl.Map) => void;
    }
    ```

    Keep the file under 100 lines (it's initialization + cleanup, no business logic).

    - File imports from `@/lib/pdok` (PDOK_AERIAL_TILES, PDOK_TOPO_TILES, etc.)
    - File uses `useRef` for map instance (grep for `useRef<maplibregl.Map`)

  </verify>
