# Phase 93.1: Potentie Dashboard - Context

**Gathered:** 2026-03-11
**Status:** Ready for planning

<domain>
## Phase Boundary

Redesign the Potentie tab from a scrollable BentoPod list into a no-scroll investor dashboard. A vastgoedinvesteerder sees Go/No-Go verdict, score breakdown, vacancy signals, market friction, headroom visualization, and bestemming compatibility — all on one screen without scrolling. The existing `PotentieLayer.tsx` is replaced entirely.

</domain>

<decisions>
## Implementation Decisions

### Dashboard Layout & Hierarchy
- **Full-width layout**: Use the entire 620px panel width (~550px usable), NOT the narrow 237px pod column
- **Vertical hierarchy** (top→bottom): Verdict Hero → 3-col Deal-Maker Grid → Intelligence Strip → Footer Button
- **Height budget**: ~432px total (Hero 100-140px + gap 16px + Grid 130px + gap 16px + Strip 100px + Button 60px). Must fit on 1080p+ without scrolling
- **Own identity**: Potentie tab is the "rekenmachine" (calculator), NOT a repeat of the Overview "brochure". Different visual language — heavy typography, horizontal track bar instead of circular gauge, analytical authority

### Verdict Hero (Full Width)
- **Score (left)**: `text-7xl font-black tracking-tighter text-slate-900` — enormous, commanding
- **Verdict + one-liner (center)**: Verdict in `text-xl font-bold uppercase`, one-liner summary below in `text-[13px] text-slate-500`
- **Go/No-Go badge (right)**: Large circle (size-12) with verdict icon — green check (GO), amber question (ONDERZOEK), red stop (NO-GO)
- **Horizontal score bar**: Full-width `h-3` track under the verdict, amber fill representing score percentage. "Liquid fill" animation on load
- **Background**: Soft `bg-slate-50/50` with `border-b border-slate-100` — open, analytical feel

### Go/No-Go Verdict Thresholds (STRICT — Conservative)
- **≥75**: ZEER KANSRIJK / GO — `text-green-600`, green badge
- **50-74**: MOGELIJKHEDEN / ONDERZOEK — `text-amber-500`, amber badge
- **<50**: BEPERKT POTENTIEEL / NO-GO — `text-red-500`, red badge
- Rationale: Higher bar for GO protects credibility. Most deals land in ONDERZOEK — that's where investors add value

### One-liner Summary
- Template-based (deterministic, no AI call): top-2 factors concatenated
- Examples: "47% vrije ruimte · +3 lagen headroom", "Wonen-bestemming · leegstandsignaal", "Beperkte data — bouwjaar-heuristiek"

### 3-Column Deal-Maker Grid (Static)
- **No interactivity**: Cards are purely informational — no click, no hover expand. "Röntgenfoto" principle
- **Grid**: `grid grid-cols-3 gap-3 w-full`
- **Each card**: `bg-white border border-slate-100 rounded-[20px] p-5 h-[130px] flex flex-col justify-between`
- **Card 1 — Vrije Grond (Land)**: Label "VRIJE GROND", value `text-3xl font-black` (e.g. "47%"), sub-text "± 2.070 m² onbebouwd"
- **Card 2 — Optoppotentie (Vertical)**: Label "OPTOPPOTENTIE", value `text-3xl font-black` (e.g. "+3 LAGEN"), sub-text "Max. 15m vs. huidig 6m"
- **Card 3 — Bestemming (Legal)**: Label "BESTEMMING", value `text-xl font-black text-green-600` (e.g. "WONEN ✓"), sub-text "Gemengd-1 (functiewijziging ok)"
- **Typography-driven**: No icons cluttering the space. Values aligned horizontally across all three cards
- **Contribution badges**: Top-right of each card, `text-[9px] font-black px-1.5 py-0.5 rounded-md bg-slate-50 text-slate-400 border border-slate-100`. Shows points contributed (e.g. "+32 pts"). Expert detail, must not distract from main value
- **Score mapping**: Card 1 → `score_breakdown.land_potential`, Card 2 → `score_breakdown.vertical_potential`, Card 3 → `score_breakdown.zoning_compatibility`

### Intelligence Strip (Signals)
- **Layout**: Vertical stack `space-y-2` under the grid
- **Each signal**: Horizontal bar `flex items-center gap-3 py-2 px-4 bg-slate-50/50 rounded-lg`
- **Signal 1 — Market Friction**: Show when `market_signals.listing_duration_days > 0`. Text: "{days} dagen op Funda (Frictie gedetecteerd)". Amber dot
- **Signal 2 — Vacancy**: Use `vacancy_signal` + `vacancy_confidence`. Text: "Mogelijk leegstaand ({confidence}% zekerheid)". Amber dot. Primary buy-signal for investors
- **Signal 3 — Transformation Candidate**: Show when score > 60 AND bouwjaar < 1980. Text: "Geschikte transformatiekandidaat (Typologie match)". Green dot
- **Visual**: Small solid colored dots (`size-2 rounded-full`) — no large icons. `text-[11px] font-bold text-slate-700`
- **"Vliegveld-monitor" aesthetic**: Quick, informative, razor-sharp

### Empty Data Handling
- Claude's discretion — prefer dash + subtle explanation ("—" with small "Geen data") over hiding cards. Grid always stays 3-col

### Claude's Discretion
- Exact animation timing for score bar liquid fill
- How to handle edge cases (score exactly on threshold boundaries)
- Mobile responsiveness considerations (desktop-first, but don't break)
- Loading skeleton design during data fetch
- Exact contribution point calculations from score_breakdown fields (may need mapping logic)

</decisions>

<specifics>
## Specific Ideas

- "De Overview is je brochure, de Potentie-tab is je rekenmachine" — identity shift from visual to analytical
- "Elke klik die de investeerder uit het overzicht haalt, verbreekt de concentratie" — zero interaction philosophy
- "142 dagen op Funda → ik kan een lager bod doen" — signals should trigger investor action
- Investment reading pattern: Score → Cijfers → Addertjes (verdict → metrics → signals)
- The software should feel "autoritair" — not a suggestion, but an analysis
- Contribution badges make it feel like "de machine heeft dit tot op de puntjes berekend" — trust through transparency
- Labels in Dutch: VRIJE GROND, OPTOPPOTENTIE, BESTEMMING, ZEER KANSRIJK, MOGELIJKHEDEN, BEPERKT POTENTIEEL

</specifics>
