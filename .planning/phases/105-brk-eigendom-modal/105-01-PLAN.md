```
GET /parcels/{parcel_id}/eigendom
```

Implementation flow:
1. Accept `parcel_id: uuid.UUID` path param. Require `get_current_active_user` dependency for auth.
2. Rate limit: `@limiter.limit("30/minute")` (BRK calls are expensive, prevent abuse).
3. Look up `ParcelCache` by `parcel_id`. Validate `organization_id` matches `current_user.organization_id`. Return 404 if not found or wrong org.
4. Extract centroid in EPSG:28992 using PostGIS:
   ```python
   result = await db.execute(
       select(
           func.ST_X(func.ST_Centroid(ParcelCache.geometry)),
           func.ST_Y(func.ST_Centroid(ParcelCache.geometry)),
       ).where(ParcelCache.id == parcel_id)
   )
   x, y = result.one()
   ```
5. Call `PDOKCadastralClient().get_parcels_by_point(x, y, client, distance=1.0)` using a fresh `httpx.AsyncClient()`. If no features returned, return `BRKOwnership(status="unavailable", reason="Kadastraal perceel niet gevonden in PDOK")`.
6. Extract `identificatie` from `features[0]["properties"]["identificatie"]`. If missing, return unavailable.
7. Build `CadastralParcel(identificatie=identificatie)` and call `await fetch_brk_ownership([parcel_obj])`.
8. Return `ownership.model_dump(mode="json")` directly. NEVER store or log the BRK response payload.
