<objective>
Replace all raw Tailwind default-palette color classes (blue-N, green-N, red-N, emerald-N, purple-N) with semantic CSS variable tokens (success, error, info, warning) and fix undefined grey scale values (grey-200, grey-500).

Purpose: Raw palette colors don't adapt between dark and light modes, causing jarring visuals (light-pink error boxes on dark backgrounds, etc.). The semantic tokens already exist and correctly invert -- this plan wires components to use them. It also cleans up undefined grey values that produce no CSS output in Tailwind v4.

Output: All UI components use semantic color tokens. `grep` for raw Tailwind palette classes returns matches only in map layers (intentionally hardcoded) and ProjectEditModal/ProjectCreateModal (intentionally light-themed).
</objective>
