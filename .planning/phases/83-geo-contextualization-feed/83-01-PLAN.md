    **extract_gemeente_from_text(text: str) -> str | None:**
    - Import `GEMEENTE_TO_RECHTBANK` from `app.government_apis.ecli_registry`
    - Build `KNOWN_GEMEENTEN: set[str]` from `GEMEENTE_TO_RECHTBANK.keys()` at module level
    - Define regex patterns in priority order (most specific first):
      a) `college van burgemeester en wethouders van (de gemeente )? {gemeente}`
      b) `raad van de gemeente {gemeente}`
      c) `gemeente {gemeente}` (word boundary)
      d) `gelegen in/te {gemeente}`
      e) `te {gemeente}` (location indicator)
    - For each pattern match, strip trailing punctuation `.,;:` and common suffixes (" heeft", " is", " een", " het", " de", " op")
    - Validate candidate against `KNOWN_GEMEENTEN` (exact match, then title-cased)
    - Return first validated match or None
    - Pattern type: `list[re.Pattern[str]]` compiled at module level for performance
    - Use `re.IGNORECASE` on all patterns
    - Filter out `[adres]` and `[locatie]` matches (anonymized addresses)

    **extract_uitkomst(text: str, summary: str) -> str:**
    - Combine summary + first 2000 chars of text, lowercased
    - Check keywords in order (most specific first):
      a) "gedeeltelijk gegrond" -> "gedeeltelijk"
      b) "niet-ontvankelijk" -> "afgewezen"
      c) "beroep gegrond" -> "toegewezen"
      d) "beroep ongegrond" -> "afgewezen"
      e) "gegrond" (and NOT "ongegrond" in same text) -> "toegewezen"
      f) "ongegrond" -> "afgewezen"
    - Return "onbekend" if no keyword matches
    - This is lightweight keyword matching -- Phase 84 AI will improve accuracy
