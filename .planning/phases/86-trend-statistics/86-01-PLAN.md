  <action>
Add a new `GET /trend/{gemeente_naam}` endpoint to the existing jurisprudence router. This endpoint:

1. Computes `twelve_months_ago` as `(datetime.utcnow() - timedelta(days=365)).strftime("%Y-%m-%d")` (string comparison against VARCHAR datum_uitspraak, matching existing `_periode_to_date()` pattern).

2. Runs a monthly aggregation query on `ruling_cache`:
   - Filter: `(gemeente_query == gemeente_naam) | (extracted_gemeente == gemeente_naam)` AND `datum_uitspraak IS NOT NULL` AND `datum_uitspraak >= twelve_months_ago`
   - Group by: `to_char(to_date(datum_uitspraak, 'YYYY-MM-DD'), 'YYYY-MM')` as `month`
   - Select: `count()` as total, conditional counts for toegewezen/afgewezen/gedeeltelijk (using `case()` pattern from existing line 278), `avg(doorlooptijd_dagen)` as avg_doorlooptijd
   - Order by: month ASC

3. Computes per-month `klimaat_score` in Python: `round(100 - (100 * afgewezen / max(total, 1)))` (reuse existing formula from line 278).

4. Computes summary stats across ALL months:
   - `total_rulings`: sum of all month totals
   - `avg_doorlooptijd`: weighted average across months (or None if no doorlooptijd data)
   - `succes_pct`: `round(100 * total_toegewezen / max(total_rulings, 1))`
   - `months_with_data`: count of months returned

5. Returns response shape:
```json
{
    "gemeente_naam": "Venlo",
    "months": [
        {"month": "2025-04", "total": 5, "toegewezen": 2, "afgewezen": 2, "gedeeltelijk": 1, "klimaat_score": 60, "avg_doorlooptijd": 245},
    ],
    "summary": {
        "total_rulings": 42,
        "avg_doorlooptijd": 198,
        "succes_pct": 45,
        "months_with_data": 9
    }
}
```

6. Uses the same auth dependency `get_current_active_user` and rate limiter as other endpoints.

7. Returns empty months list + zero summary if no rulings found (NOT 404 -- absence of trend data is valid).

IMPORTANT: Use `func.to_date(RulingCache.datum_uitspraak, text("'YYYY-MM-DD'"))` for PostgreSQL date parsing from VARCHAR. Use `func.to_char(...)` for month formatting. Wrap the format string in `text()` or use `literal_column` to avoid SQLAlchemy quoting issues with PostgreSQL format strings.

Do NOT add any new dependencies. Do NOT create a separate service file -- this is a single query endpoint that fits in the existing router.
