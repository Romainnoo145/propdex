    **database.py:** Create async SQLAlchemy setup:
    - `engine = create_async_engine(settings.DATABASE_URL)` with pool_size=5, max_overflow=10
    - `async_session_factory = async_sessionmaker(engine, expire_on_commit=False)`
    - `async def get_db()` dependency that yields AsyncSession (request-scoped)
    - `async def init_db()` that creates engine and verifies connection

    **base.py:** Create declarative base with:
    - `class Base(DeclarativeBase)` using SQLAlchemy 2.x mapped_column syntax
    - `TenantMixin` class with `organization_id: Mapped[uuid.UUID]` as non-nullable FK to organizations.id, indexed

    **organization.py:** Organization model:
    - `id`: UUID primary key (server_default=gen_random_uuid())
    - `name`: String(255), not nullable
    - `created_at`: DateTime with timezone, server_default=now()
    - `updated_at`: DateTime with timezone, onupdate=now()
    - NO RLS on organizations table (it's the root tenant entity)

    **user.py:** User model (uses TenantMixin):
    - `id`: UUID primary key
    - `email`: String(320), unique, not nullable (320 = max email length per RFC)
    - `hashed_password`: String(255), nullable (nullable for Google OAuth users who have no password)
    - `full_name`: String(255), nullable
    - `organization_id`: from TenantMixin
    - `email_verified`: Boolean, default False
    - `email_verified_at`: DateTime, nullable
    - `auth_provider`: String(20), default "email" (values: "email", "google")
    - `google_id`: String(255), nullable, unique (for Google OAuth linking)
    - `is_active`: Boolean, default True
    - `created_at`: DateTime with timezone
    - `updated_at`: DateTime with timezone
    - Composite indexes: (organization_id, id), (organization_id, email), (organization_id, created_at DESC)
    - Unique constraint on email (global, not per-org — email is identity)

    **refresh_token.py:** RefreshToken model (uses TenantMixin):
    - `id`: UUID primary key
    - `jti`: String(36), unique, not nullable, indexed (JWT token ID for rotation tracking)
    - `user_id`: UUID FK to users.id, not nullable
    - `organization_id`: from TenantMixin
    - `expires_at`: DateTime with timezone, not nullable
    - `revoked`: Boolean, default False
    - `revoked_at`: DateTime, nullable
    - `created_at`: DateTime with timezone
    - Composite indexes: (organization_id, user_id), (jti,) — jti needs fast lookup
    - Index on (user_id, revoked) for "revoke all user tokens" operation

    **models/__init__.py:** Import and re-export all models so Alembic can discover them:
    ```python
    from app.models.base import Base
    from app.models.organization import Organization
    from app.models.user import User
    from app.models.refresh_token import RefreshToken
    __all__ = ["Base", "Organization", "User", "RefreshToken"]
    ```

    **Alembic setup:**
    - Run `alembic init alembic` in backend/ directory
    - Configure alembic.ini to use async driver
    - Configure alembic/env.py to:
      - Import all models from app.models
      - Use async engine from app.core.database
      - Set target_metadata = Base.metadata
    - Create initial migration (001_initial_schema.py) that creates all three tables with indexes

    **sql/rls_policies.sql:** Create SQL file with RLS setup (to be run after migrations):
    - Enable RLS on `users` table
    - Enable RLS on `refresh_tokens` table
    - Create tenant_isolation policy on each: `USING (organization_id = current_setting('app.current_tenant_id')::uuid)`
    - Create app_role if not exists, grant SELECT/INSERT/UPDATE/DELETE on tenant tables
    - Add comment explaining: RLS is defense-in-depth; application-level filtering is primary defense for now, RLS catches bugs
    - NOTE: For MVP, the application connects as superuser (bypasses RLS). RLS policies are set up for when we switch to app_role in production hardening. Document this clearly in the SQL file.

    **Important implementation note:** Use SQLAlchemy 2.x `Mapped` and `mapped_column` syntax throughout (NOT the old Column() syntax). Example:
    ```python
    class User(TenantMixin, Base):
        __tablename__ = "users"
        id: Mapped[uuid.UUID] = mapped_column(primary_key=True, server_default=text("gen_random_uuid()"))
        email: Mapped[str] = mapped_column(String(320), unique=True, nullable=False)
    ```
