    **Update jwt.py** — Add two new token creators (per research: JWT-based, no DB storage needed):
    - `create_email_verification_token(user_id: str, email: str) -> str` — payload: sub=user_id, email, type="email_verification", exp=48h
    - `create_password_reset_token(user_id: str) -> str` — payload: sub=user_id, type="password_reset", exp=1h (shorter than verification — security)

    **email.py** — Email sending with fastapi-mail:
    - Configure FastMail connection using settings (MAIL_SERVER, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD, MAIL_FROM)
    - `async def send_verification_email(email: str, token: str)` — sends email with verification URL: `{FRONTEND_URL}/verify-email?token={token}`
    - `async def send_password_reset_email(email: str, token: str)` — sends email with reset URL: `{FRONTEND_URL}/reset-password?token={token}`
    - Both functions should be called as background tasks (FastAPI BackgroundTasks) to not block the response
    - If email sending fails (e.g., no mail server configured), log warning but don't crash the endpoint. Email is best-effort in dev.
    - Use simple HTML templates (inline, no external template engine). Keep them minimal but professional.

    **Update schemas.py** — Add new schemas:
    - `PasswordResetRequest(BaseModel)`: email (EmailStr)
    - `PasswordResetConfirm(BaseModel)`: token (str), new_password (str, min_length=8)
    - `EmailVerifyRequest(BaseModel)`: token (str)

    **Update router.py** — Add new endpoints:

    **POST /auth/verify-email** — Verify user's email:
    - Accept EmailVerifyRequest
    - Decode JWT token (must be type="email_verification")
    - Find user by id from token payload, verify email matches
    - Set email_verified=True, email_verified_at=now()
    - Return MessageResponse "Email verified successfully"
    - Handle expired token: return 400 "Verification link expired. Request a new one."
    - Handle invalid token: return 400 "Invalid verification link"
    - If already verified, return 200 "Email already verified" (idempotent)

    **POST /auth/resend-verification** — Resend verification email:
    - Requires authentication (Depends get_current_active_user)
    - If already verified, return 200 "Email already verified"
    - Create new verification token, send email as background task
    - Return MessageResponse "Verification email sent"

    **POST /auth/password-reset/request** — Request password reset:
    - Accept PasswordResetRequest (just email)
    - Look up user by email. If found AND auth_provider="email", create reset token and send email
    - ALWAYS return 200 "If the email exists, a reset link has been sent" — prevents user enumeration (per research)
    - If user has auth_provider="google" (no password), still return success (don't leak that they use Google)

    **POST /auth/password-reset/confirm** — Set new password:
    - Accept PasswordResetConfirm (token + new_password)
    - Decode JWT token (must be type="password_reset")
    - Find user by id from token payload
    - Hash new password, update user's hashed_password
    - Revoke ALL refresh tokens for this user (security: force re-login everywhere after password change)
    - Return MessageResponse "Password reset successfully"

    **Update POST /auth/register** (from Plan 02):
    - After creating user, create email verification token
    - Send verification email as BackgroundTask
    - Log the verification URL to console for dev testing (so developer can click it without email server)

    ```python
    from httpx_oauth.clients.google import GoogleOAuth2

    google_oauth_client = GoogleOAuth2(
        client_id=settings.GOOGLE_CLIENT_ID,
        client_secret=settings.GOOGLE_CLIENT_SECRET,
    )
    ```
    - Only initialize if GOOGLE_CLIENT_ID is set (non-empty). Otherwise, log warning and set client to None.
    - Helper function: `async def get_google_user_info(access_token: str) -> dict` that fetches user profile from Google.

    **Update router.py** — Add Google OAuth endpoints:

    **GET /auth/google** — Redirect to Google authorization:
    - Generate authorization URL with scopes: ["email", "profile"]
    - Redirect URI: `{FRONTEND_URL}/auth/google/callback` (frontend handles the callback, passes code to backend)
    - Actually, for API-first approach: return the authorization URL as JSON so the frontend can redirect. Do NOT do server-side redirect.
    - Format: `{"authorization_url": "https://accounts.google.com/o/oauth2/v2/auth?..."}`
    - If Google OAuth not configured, return 501 "Google OAuth not configured"

    **POST /auth/google/callback** — Handle Google OAuth callback:
    - Accept `{"code": "...", "redirect_uri": "..."}` from frontend
    - Exchange code for Google access token via httpx-oauth
    - Fetch user info (email, name, google_id)
    - Check if user exists by email:
      - If exists with auth_provider="google": login, return tokens
      - If exists with auth_provider="email": return 400 "Email already registered with email/password. Please sign in with your password." (per research: no auto-linking for MVP)
      - If not exists: create new Organization (name from Google profile name), create User (auth_provider="google", google_id set, email_verified=True — Google already verified), return tokens
    - Return TokenResponse

    **rate_limit.py** — Configure slowapi rate limiter:
    ```python
    from slowapi import Limiter
    from slowapi.util import get_remote_address

    limiter = Limiter(key_func=get_remote_address, default_limits=["100/minute"])
    ```
    - Use in-memory storage for MVP (no Redis dependency required for dev). Can switch to Redis later.
    - If Redis URL is configured in settings, use Redis backend. Otherwise, fall back to in-memory.

    **Update router.py** — Apply rate limits to auth endpoints:
    - POST /auth/register: `@limiter.limit("3/hour")` (3 registrations per hour per IP)
    - POST /auth/login: `@limiter.limit("10/minute")` (10 login attempts per minute per IP)
    - POST /auth/refresh: `@limiter.limit("30/minute")` (generous — auto-refresh is normal)
    - POST /auth/password-reset/request: `@limiter.limit("3/hour")` (prevent spam)
    - POST /auth/resend-verification: `@limiter.limit("3/hour")` (prevent spam)
    - POST /auth/google/callback: `@limiter.limit("10/minute")` (same as login)
    - GET /auth/google: `@limiter.limit("10/minute")`
    - GET /auth/me: no rate limit (authenticated, non-sensitive)
    - POST /auth/logout: no rate limit (self-destructive action)

    **Update main.py:**
    - Add slowapi exception handler for 429 responses
    - Add limiter to app state: `app.state.limiter = limiter`
    - Add SlowAPIMiddleware

    **Error handling for rate limits:** Return 429 with:
    ```json
    {"detail": "Too many requests. Please try again later.", "retry_after": 60}
    ```
