  <action>
    **password.py:** Password hashing utilities using pwdlib with Argon2id (per research — NOT passlib/bcrypt):
    ```python
    from pwdlib import PasswordHash
    from pwdlib.hashers.argon2 import Argon2Hasher

    password_hash = PasswordHash((Argon2Hasher(),))

    def hash_password(password: str) -> str: ...
    def verify_password(plain_password: str, hashed_password: str) -> bool: ...
    ```
    verify_password must handle None hashed_password gracefully (for Google OAuth users without password) — return False.

    **jwt.py:** Token creation and validation:
    - `create_access_token(user_id: str, organization_id: str) -> str` — payload: sub=user_id, organization_id, type="access", exp=15min
    - `create_refresh_token(user_id: str, organization_id: str) -> tuple[str, str]` — returns (token, jti). Payload: sub=user_id, organization_id, type="refresh", jti=uuid4, exp=7days
    - `decode_token(token: str) -> dict` — decodes with algorithms=["HS256"] explicitly (prevent algorithm confusion attack per research). Raises appropriate exceptions.
    - Use `import jwt` (PyJWT), NOT python-jose.
    - Import SECRET_KEY and ALGORITHM from settings.

    **schemas.py:** Pydantic v2 schemas:
    - `UserCreate(BaseModel)`: email (EmailStr), password (str, min_length=8), full_name (str, optional), organization_name (str, min_length=1, max_length=255)
    - `UserResponse(BaseModel)`: id (UUID), email, full_name, organization_id (UUID), email_verified, auth_provider, created_at. Use model_config = ConfigDict(from_attributes=True)
    - `TokenResponse(BaseModel)`: access_token (str), refresh_token (str), token_type (str, default="bearer")
    - `LoginRequest(BaseModel)`: email (EmailStr), password (str)
    - `RefreshRequest(BaseModel)`: refresh_token (str)
    - `MessageResponse(BaseModel)`: message (str)

    **dependencies.py:** FastAPI auth dependencies:
    - `oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/auth/login", auto_error=False)` — auto_error=False for custom error handling
    - `async def get_current_user(token, db) -> User` — decode access token (must be type="access"), fetch user from DB, raise 401 if invalid/expired/not found
    - `async def get_current_active_user(current_user) -> User` — check is_active=True, raise 403 if disabled
    - `async def get_current_organization_id(request: Request) -> uuid.UUID` — extract from request.state.organization_id (set by middleware), raise 403 if missing
    - Error messages must be generic: "Could not validate credentials" (not "user not found" or "token expired" — prevents enumeration)

    **tenant.py:** TenantContextMiddleware (Starlette BaseHTTPMiddleware):
    - On each request, extract Authorization header
    - If Bearer token present, decode JWT (silently — don't fail on public endpoints)
    - Store organization_id in request.state.organization_id
    - If token invalid/missing, do nothing (public endpoints should work)
    - The get_db dependency should check for request.state.organization_id and SET LOCAL app.current_tenant_id for RLS if present
    - NOTE: Update get_db in database.py to accept Request dependency and set RLS context when available

    **Important:** Keep middleware lightweight. Don't query the database in middleware — that happens in dependencies.

  <action>
    **router.py:** Create APIRouter with prefix="/auth", tags=["auth"]. Implement these endpoints:

    **POST /auth/register** — Create new user and organization:
    - Accept UserCreate schema
    - Check if email already exists globally (not per-org — email is identity). If exists, return 400 "Email already registered"
    - Create new Organization with provided organization_name
    - Create new User with hashed password, organization_id, email_verified=False, auth_provider="email"
    - Create refresh token in DB (jti stored in refresh_tokens table)
    - Return TokenResponse (access_token + refresh_token)
    - Send email verification in background (for now, just log the verification URL — actual email sending comes in Plan 03)
    - Use a single transaction: if any step fails, rollback everything

    **POST /auth/login** — Authenticate and return tokens:
    - Accept LoginRequest schema (email, password)
    - Find user by email (case-insensitive lookup: `func.lower(User.email) == email.lower()`)
    - Verify password using verify_password. If user not found OR password wrong, return 401 "Incorrect email or password" (generic message per research — prevents enumeration)
    - Check grace period: if email not verified AND created_at > 48 hours ago, return 403 "Email verification required"
    - If user has auth_provider="google" and no password, return 400 "Please sign in with Google" (but keep message somewhat generic)
    - Create new refresh token in DB, create access token
    - Return TokenResponse

    **POST /auth/refresh** — Refresh access token using refresh token:
    - Accept RefreshRequest schema
    - Decode refresh token (must be type="refresh")
    - Look up JTI in refresh_tokens table — must exist, not revoked, not expired
    - Revoke old refresh token (set revoked=True, revoked_at=now)
    - Create new refresh token in DB
    - Create new access token
    - Return TokenResponse
    - SECURITY: If JTI not found (already used), this indicates token theft — revoke ALL refresh tokens for this user and return 401. Log a security warning.

    **POST /auth/logout** — Revoke current refresh token:
    - Accept RefreshRequest schema
    - Decode refresh token, find JTI in DB
    - Set revoked=True, revoked_at=now
    - Return MessageResponse "Logged out successfully"
    - If token already revoked or not found, still return 200 (idempotent)

    **GET /auth/me** — Get current user info:
    - Requires authentication (Depends get_current_active_user)
    - Return UserResponse with current user data
    - This serves as the "am I still logged in?" check

    **Update main.py:**
    - Import and include auth_router: `app.include_router(auth_router)`
    - Add TenantContextMiddleware: `app.add_middleware(TenantContextMiddleware)`
    - Middleware must be added AFTER CORS middleware (order matters in Starlette)

    **Transaction handling:** Each endpoint that writes should use:
    ```python
    async with db.begin():
        # ... all writes ...
    ```
    Or use explicit commit/rollback in the get_db dependency. Choose the pattern that's cleaner — but be consistent.

    **Important edge cases to handle:**
    - Registration with email that only differs by case (treat as same email)
    - Login attempt for Google OAuth user (no password set)
    - Refresh with already-revoked token (token theft detection)
    - Logout with invalid/expired refresh token (be graceful, return 200)
  </action>
