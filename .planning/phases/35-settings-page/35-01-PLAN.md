   - Import schemas from `app.users.schemas`: `UserProfileUpdate`, `PasswordChange`, `UserPreferences`, `UserPreferencesUpdate`
   - Import `UserResponse`, `MessageResponse` from `app.auth.schemas`

   **PATCH /me** (update profile):
   - Depends: `get_current_active_user`, `get_db`, `BackgroundTasks`
   - If `data.full_name is not None`: update `current_user.full_name`
   - If `data.email is not None and data.email != current_user.email`:
     - Check email uniqueness: `select(User).where(func.lower(User.email) == data.email.lower())` — if exists, raise HTTPException(400, "E-mailadres al in gebruik")
     - Update `current_user.email = data.email`
     - Set `current_user.email_verified = False`, `current_user.email_verified_at = None`
     - Create verification token and send email in background
   - `await db.commit()`
   - `await db.refresh(current_user)` to get updated state
   - Return `UserResponse.model_validate(current_user)`

   **PUT /me/password** (change password):
   - Depends: `get_current_active_user`, `get_db`
   - If `current_user.auth_provider != "email"`: raise HTTPException(400, "Gebruik je Google-account om je wachtwoord te wijzigen")
   - If not `verify_password(data.current_password, current_user.hashed_password)`: raise HTTPException(400, "Huidig wachtwoord onjuist")
   - Set `current_user.hashed_password = hash_password(data.new_password)`
   - `await db.commit()`
   - Return `MessageResponse(message="Wachtwoord gewijzigd")`

   **GET /me/preferences** (get preferences):
   - Depends: `get_current_active_user`
   - `prefs = current_user.preferences or {}`
   - Return `UserPreferences(**prefs)`

   **PATCH /me/preferences** (update preferences):
   - Depends: `get_current_active_user`, `get_db`
   - `current_prefs = current_user.preferences or {}`
   - `update_data = data.model_dump(exclude_unset=True)`
   - `current_user.preferences = {**current_prefs, **update_data}`
   - `await db.commit()`
   - Return `UserPreferences(**current_user.preferences)`
