<task type="auto">
  <name>Task 1: Transform InspectorPanel to bottom sheet on mobile</name>
  <files>
    frontend/src/components/layout/InspectorPanel.tsx
  </files>
  <action>
Refactor InspectorPanel to use bottom-sheet pattern on mobile, matching the existing Drawer.tsx responsive approach.

1. Change the root `<div>` positioning from `absolute` to `fixed` on mobile, `md:absolute` on desktop:
   - Mobile classes: `fixed inset-x-0 bottom-0 max-h-[65vh] rounded-t-xl border-t border-grey-800`
   - Desktop classes (md:): `md:absolute md:inset-x-auto md:right-0 md:top-0 md:bottom-0 md:h-full md:w-80 md:max-h-none md:rounded-none md:border-t-0 md:border-l`
   - Common: `bg-grey-900 border-grey-800 flex flex-col shadow-lg transition-transform duration-300 ease-out`

2. Update the open/close animation:
   - Open state: `translate-y-0 md:translate-y-0 md:translate-x-0`
   - Closed state: `translate-y-full md:translate-y-0 md:translate-x-full`
   - This makes the panel slide up from bottom on mobile, slide in from right on desktop

3. Add mobile drag handle (same pattern as Drawer.tsx):
   - Before the header div, add: `<div className="flex justify-center py-2 md:hidden shrink-0"><div className="w-10 h-1 bg-grey-700 rounded-full" /></div>`

4. Add touch event isolation on the scrollable content div (same as Drawer.tsx):
   - On the `<div className="flex-1 overflow-y-auto p-4">`, add:
     `onTouchStart={(e) => e.stopPropagation()}`
     `onTouchMove={(e) => e.stopPropagation()}`
   - This prevents MapLibre from capturing touch events when scrolling the panel

5. Remove `max-w-[90vw]` — no longer needed since mobile is full-width bottom sheet and desktop has explicit `md:w-80`

6. Keep `style={{ zIndex: 'var(--z-property-panel)' }}` and `aria-hidden` unchanged.

7. Verify the close button has sufficient touch target. Current: `p-1` which is too small on mobile. Change the close button to `p-2 -m-1` to increase touch target to ~40px while keeping visual size. Add `min-h-[44px] min-w-[44px] flex items-center justify-center` to the button wrapper to ensure 44px touch target (MOB-03).
  </action>
  <verify>
Run `npm run check`. At 375px viewport: InspectorPanel appears as bottom sheet from bottom, max 65vh, with drag handle visible. At 1024px: panel slides from right as before with w-80. Close button meets 44px touch target.
  </verify>
  <done>
InspectorPanel renders as bottom sheet on mobile (fixed, inset-x-0, bottom-0, max-h-[65vh]) with drag handle and touch event isolation. Desktop behavior unchanged (absolute right-0 w-80). Close button has 44px touch target.
  </done>
