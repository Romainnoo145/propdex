  <action>
1. Create `frontend/src/hooks/useIsMobile.ts`:
   - Export function `useIsMobile(): boolean`
   - Use `window.matchMedia('(max-width: 767px)')` — matches Tailwind `md:` breakpoint (768px)
   - Initialize with `useState(() => ...)` form reading matchMedia synchronously to avoid flicker
   - Add SSR guard: `typeof window !== 'undefined'` in initializer (returns false if no window)
   - useEffect listener: `mql.addEventListener('change', handler)` — NOT deprecated `addListener`
   - Cleanup: `mql.removeEventListener('change', handler)`

2. Create `frontend/src/components/layout/BottomTabNav.tsx`:
   - Import `Link`, `useMatchRoute` from `@tanstack/react-router`
   - Import `Map`, `ListOrdered`, `FolderOpen` from `lucide-react` (same icons as SideRailNav)
   - Define `navItems` array with same 3 primary routes as SideRailNav: `/map` (Kaart), `/resultaten` (Resultaten), `/projecten` (Projecten)
   - Render fixed bottom nav: `fixed inset-x-0 bottom-0 flex md:hidden border-t border-grey-800 bg-grey-900`
   - z-index via inline style: `zIndex: 'var(--z-bottom-nav)'`
   - Each nav item: `flex flex-1 flex-col items-center justify-center min-h-[56px] gap-0.5`
   - Active state: `text-amber-accent` (matches amber accent system); inactive: `text-grey-400`
   - Use `useMatchRoute()` for active detection, same pattern as SideRailNav
   - Icon size={20}, label as `text-xs`
   - All touch targets exceed 44px minimum (56px height, full flex-1 width)

3. Add `--z-bottom-nav: 250` to `:root` in `frontend/src/styles/index.css`:
   - Add after `--z-side-rail: 250;` line — same level since they never coexist
