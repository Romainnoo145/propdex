    **3. WijkValidation dataclass:**
    ```python
    @dataclass(slots=True)
    class WijkValidation:
        wijk_naam: str
        scan_status: str
        total_parcels: int
        parcels_with_buildings: int
        bouwjaar_populated: int
        bouwjaar_null: int
        addresses_resolved: int
        addresses_missing: int
        pand_status_populated: int
        pand_status_null: int
        avg_score: float | None
        coverage_ratio: float | None
        address_resolution_ratio: float | None

        @property
        def bouwjaar_rate(self) -> float:
            return self.bouwjaar_populated / self.parcels_with_buildings if self.parcels_with_buildings > 0 else 0.0

        @property
        def address_rate(self) -> float:
            return self.addresses_resolved / self.parcels_with_buildings if self.parcels_with_buildings > 0 else 0.0

        @property
        def pand_status_rate(self) -> float:
            return self.pand_status_populated / self.parcels_with_buildings if self.parcels_with_buildings > 0 else 0.0
    ```

    **4. Core validation query (single query, grouped by wijk):**
    Join ScanResult -> ParcelCache and ScanResult -> AreaScan. Filter by gemeente_code and status IN ('completed', 'completed_with_warnings'). Group by AreaScan.wijk_naam. Use `func.count().filter(...)` pattern from the research for conditional counts:
    - total_parcels: count all
    - parcels_with_buildings: count where has_pand=True
    - bouwjaar_populated: count where has_pand=True AND bouwjaar IS NOT NULL
    - addresses_resolved: count where has_pand=True AND address IS NOT NULL
    - pand_status_populated: count where has_pand=True AND pand_status IS NOT NULL
    - avg_score: avg(ScanResult.score)
    Also select AreaScan.coverage_ratio and AreaScan.address_resolution_ratio for display.
    Also select AreaScan.status.

    sloop/niet in gebruik|   12  |   72.3
    buiten gebruik       |   45  |   65.1
    (no building)        |  320  |   61.0
    unknown              |   80  |   55.2
    in_gebruik           | 1200  |   42.5
    ```
    The ordering should show higher-vacancy statuses scoring higher. If `in_gebruik` avg > `buiten gebruik` avg, print a WARNING.

    ...
    ================================================================================
    TOTAL                                      8234   4521   96.2%    72.1%    98.5%
    ```
    Status = OK if all rates >= thresholds, WARN if any below, FAIL if scan status is failed.
