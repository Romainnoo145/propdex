## Context

Plan 111-01 delivers the full drill-down from province to wijk level with a placeholder parcel list at the deepest level. This plan replaces that placeholder with the actual `FavoritedParcelCard` grid and adds the `PipelineStagePill` component. At the wijk level, the user sees individual favorited parcel cards showing Kadaster ID, gemeente, wijk, pipeline stage, and a "Bekijk op kaart" ghost button.

Key data constraints from RESEARCH.md:
- `FavoriteResponse` does NOT include address text or score — only `parcel_id` (Kadaster string), `gemeente_naam`, `wijk_naam`, `pipeline_stage`, `created_at`
- Parcel ghost button navigates to `/map?gemeente_code=...` without pre-selecting the parcel (no coordinate-based lookup available from favorites data)
- `wijk_naam` can be null — display as "Onbekende wijk"
