## Context

Phase 110 delivered the ProjectenPage refactor + HeartButton. Phase 109 delivered the backend with `GET /api/portfolio` (grouped by gemeente/wijk) and `GET /api/parcels/favorites` (flat list). All TypeScript types exist in `portfolio.ts`. This plan adds the portfolio navigation mode to the Projecten page — a full drill-down from 12 provinces down to wijk-level parcel lists.

Key architectural decisions from RESEARCH.md:
- Portfolio mode is toggled via `portfolio_mode` URL search param (not a new route)
- Separate `portfolio_*` URL params to avoid collision with workspace mode
- Province assignment uses `allGemeenteCards[].provinceCode` from `useMunicipalityWorkspaceStats` (no re-derivation)
- Portfolio uses two existing API endpoints — no backend changes needed
- Dedicated `PortfolioBreadcrumb` (not extending the existing workspace breadcrumb)
