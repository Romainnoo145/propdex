  **In `ResultsTable.tsx`:**

  1. Import `RowSelectionState` from `@tanstack/react-table`.

  2. Add `onSelectionChange` and `selectionKey` props to `ResultsTableProps`:
     ```typescript
     onSelectionChange?: (selectedParcelIds: string[]) => void
     selectionKey?: number
     ```
     `selectionKey` is a counter the parent increments when it wants to force-clear the table's internal `RowSelectionState` (e.g., when the "Deselecteren" button is clicked). Without this, `onClearSelection` only resets the parent's `selectedParcelIds[]` but the checkboxes inside the table remain visually checked.

  3. Add `RowSelectionState` to component state:
     ```typescript
     const [rowSelection, setRowSelection] = useState<RowSelectionState>({})
     ```

  4. Add checkbox column as the FIRST column (before `parcel_code`). Use HTML `<input type="checkbox">` with Tailwind styling (no Radix/Headless UI):
     ```typescript
     columnHelper.display({
       id: 'select',
       size: 40,
       enableSorting: false,
       header: ({ table }) => (
         <input
           type="checkbox"
           checked={table.getIsAllPageRowsSelected()}
           ref={(el) => {
             if (el) el.indeterminate = table.getIsSomePageRowsSelected()
           }}
           onChange={table.getToggleAllPageRowsSelectedHandler()}
           className="w-4 h-4 rounded border-grey-700 bg-grey-900 accent-amber-accent cursor-pointer"
         />
       ),
       cell: ({ row }) => (
         <input
           type="checkbox"
           checked={row.getIsSelected()}
           onChange={row.getToggleSelectedHandler()}
           onClick={(e) => e.stopPropagation()}
           className="w-4 h-4 rounded border-grey-700 bg-grey-900 accent-amber-accent cursor-pointer"
         />
       ),
     })
     ```
     CRITICAL: `onClick={(e) => e.stopPropagation()}` prevents the checkbox click from also triggering `onRowClick`.

  5. Update `useReactTable` config:
     ```typescript
     const table = useReactTable({
       // ...existing
       enableRowSelection: true,
       getRowId: (row) => row.parcel_id, // Key by parcel UUID, not row index
       state: {
         sorting,
         pagination,
         rowSelection,
       },
       onRowSelectionChange: setRowSelection,
     })
     ```
     CRITICAL: `getRowId: (row) => row.parcel_id` ensures selection state is keyed by parcel UUID (not row index). This is essential for paginated tables (Pitfall 1 from research).

  6. Notify parent when selection changes via useEffect:
     ```typescript
     useEffect(() => {
       const selectedIds = Object.keys(rowSelection).filter((k) => rowSelection[k])
     ```
