Make the data freshness threshold configurable per organization, replacing the hardcoded 24-hour threshold in freshness detection. Enforce a system-wide minimum to prevent organizations from hammering external government APIs.

Purpose: CFG-02 requirement. Organizations have different data freshness needs — a developer checking a property daily needs different thresholds than one doing monthly portfolio reviews. The minimum prevents API abuse of BAG, PDOK, DSO, and RCE services.

Output: Updated Organization model with freshness_threshold_hours, updated freshness.py with per-org threshold + minimum enforcement, Alembic migration.
