2. **Add a canvas-based hatch pattern image** at the top of the file. Create a helper function:

```typescript
function createHatchPattern(): HTMLCanvasElement {
  const size = 16;
  const canvas = document.createElement('canvas');
  canvas.width = size;
  canvas.height = size;
  const ctx = canvas.getContext('2d')!;
  ctx.clearRect(0, 0, size, size);
  ctx.strokeStyle = '#555555';
  ctx.lineWidth = 1;
  ctx.beginPath();
  ctx.moveTo(0, size);
  ctx.lineTo(size, 0);
  ctx.moveTo(-size / 2, size / 2);
  ctx.lineTo(size / 2, -size / 2);
  ctx.moveTo(size / 2, size + size / 2);
  ctx.lineTo(size + size / 2, size / 2);
  ctx.stroke();
  return canvas;
}
```

3. **Register the hatch pattern with the map** inside `addParcelScoreLayer()`, AFTER the source is added but BEFORE the hatch layer is added. Use `map.addImage()`:


Note: `map.addImage()` accepts an `HTMLCanvasElement` directly (no need to extract ImageData). This is cleaner than passing `{ data, width, height }`.

4. **Add a hatch overlay fill layer** — this is a SEPARATE layer on top of the score fill layer (because `fill-pattern` replaces `fill-color` in MapLibre). Add it right after the `PARCEL_SCORE_FILL_LAYER_ID` layer:

```typescript
const PARCEL_EMPTY_HATCH_LAYER_ID = 'parcel-empty-hatch';

  id: PARCEL_EMPTY_HATCH_LAYER_ID,
  type: 'fill',
  source: SOURCE_ID,
  'source-layer': sourceLayer,
  filter: [
    'all',
    ['has', 'score'],
    ['==', ['downcase', ['to-string', ['coalesce', ['get', 'has_pand'], 'false']]], 'false'],
  ],
  paint: {
    'fill-pattern': 'parcel-hatch',
    'fill-opacity': 0.4,
  },
  minzoom: 14,
});
```

The filter selects parcels that have a score but where `has_pand` is false (empty land parcels). The `coalesce` + `downcase` + `to-string` chain handles missing/null values safely (matching the existing pattern used for `PARCEL_BUILT_STATUS_FILL_LAYER_ID`).
