   - Layer ID: `'bag-pand-layer'`
   - Import `PDOK_BAG_PAND_WMS` from `@/lib/pdok`

   - `paint: { 'raster-opacity': 0.35 }` — WMS renders filled polygons (not outline-only — WMS raster tiles do not support outline-only rendering via STYLES parameter for the BAG pand layer). Starting at 0.35 keeps parcel score colors clearly visible underneath while building outlines remain discernible. The locked decision intent is "outline-only, keeps parcel score colors visible underneath" — 0.35 opacity is the closest WMS-raster approximation since the dark borders remain visible while the fill becomes nearly transparent. If buildings are too faint at 0.35, executor may increase to 0.45-0.5 max.
   - Export three functions: `addBAGPandLayer(map)`, `removeBAGPandLayer(map)`, `setBAGPandVisibility(map, visible)`
   - `removeBAGPandLayer` MUST remove layer before source (MapLibre throws otherwise)
   - `setBAGPandVisibility` uses `layout.visibility` (not `raster-opacity: 0`) to prevent unnecessary tile loading

Note: Building footprint clicks are handled automatically — the raster WMS layer is transparent to mouse events, so clicks pass through to the parcel fill layer underneath. No separate click handler needed per locked decision ("clicking a building footprint selects the parent parcel").
