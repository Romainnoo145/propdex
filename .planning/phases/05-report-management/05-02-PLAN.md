  <action>
    Create the report service module with centralized query logic.

    **backend/app/reports/__init__.py**: Empty init file.

    **backend/app/reports/service.py** — Report service functions:

    All functions are async, take `session: AsyncSession` and `organization_id: uuid.UUID` parameters. Use direct `db.add()/db.flush()/db.commit()` pattern (NOT `async with db.begin()`). Use `datetime.utcnow()` for naive UTC timestamps.

    **Helper function:**
    - `active_reports_query(organization_id: uuid.UUID) -> Select` — Returns base query for active (non-deleted) reports filtered by organization_id. All list/get operations MUST use this helper to prevent deleted reports from leaking. Pattern: `select(SavedReport).where(SavedReport.organization_id == organization_id, SavedReport.deleted_at.is_(None))`.

    **CRUD functions:**

    1. `save_report(report_data: dict, notes: str | None, project_id: uuid.UUID | None, organization_id: uuid.UUID, session: AsyncSession) -> SavedReport`:
       - Validate report_data by parsing as PropertyReportResponse (import from app.schemas.property). If invalid, raise ValueError.
       - Generate report_name from address: `"{straatnaam} {huisnummer}, {woonplaats}"` (locked decision: auto-generated, not user-editable)
       - Extract denormalized fields: postcode from `report_data["address"]["postcode"]`, city from `report_data["address"]["woonplaats"]`
       - Store validated dict via `PropertyReportResponse(**report_data).model_dump(mode="json")`
       - If project_id provided, verify project exists and belongs to same organization (raise HTTPException 404 if not)
       - Create SavedReport, session.add(), session.flush(), session.commit(), return report

    2. `list_reports(organization_id, city, project_id, search_query, sort_by, sort_order, offset, limit, session) -> tuple[list[SavedReport], int]`:
       - Start from `active_reports_query(organization_id)`
       - Apply optional filters: city (exact match), project_id (exact match), search_query (ILIKE on report_name, uses GIN trigram index)
       - Apply sorting: sort_by Literal["created", "updated", "address"] maps to created_at, updated_at, report_name. sort_order Literal["asc", "desc"]. Default: updated desc.
       - Apply pagination: offset (default 0), limit (default 50, max 100)
       - Return (reports, total_count) — total_count via separate count query for pagination

    3. `get_report(report_id: uuid.UUID, organization_id: uuid.UUID, session: AsyncSession) -> SavedReport`:
       - Query using active_reports_query + filter by id
       - Raise HTTPException 404 if not found
       - Return full SavedReport (including report_data JSONB)

    4. `soft_delete_report(report_id, organization_id, session) -> SavedReport`:
       - Query active report by id + org
       - Set deleted_at = datetime.utcnow()
       - Commit and return report

    5. `restore_report(report_id, organization_id, session) -> SavedReport`:
       - Query DELETED reports: where deleted_at.is_not(None) + organization_id + id
       - Set deleted_at = None
       - Commit and return report

    6. `update_report_notes(report_id, organization_id, notes: str | None, session) -> SavedReport`:
       - Query active report, update notes field, commit

    7. `assign_report_to_project(report_id, organization_id, project_id: uuid.UUID | None, session) -> SavedReport`:
       - Query active report
       - If project_id provided, verify project exists in same organization
       - Update project_id (None removes from project), commit

    8. `update_report_data(report_id, organization_id, fresh_data: dict, session) -> SavedReport`:
       - Validate fresh_data as PropertyReportResponse
       - Query active report, update report_data JSONB, update denormalized fields, set updated_at = datetime.utcnow()
       - Commit and return

    9. `get_distinct_cities(organization_id, session) -> list[str]`:
       - Query distinct city values from active reports for filter dropdown
       - Return sorted list of cities

    **Import patterns from existing code:**
    - `from sqlalchemy import select, func, desc, asc`
    - `from sqlalchemy.ext.asyncio import AsyncSession`
    - `from fastapi import HTTPException, status`
    - `from app.models.report import SavedReport`
    - `from app.models.project import Project`
    - `from app.schemas.property import PropertyReportResponse`

    Create API routers following patterns from existing properties/router.py and auth/router.py.

    **backend/app/reports/router.py** — Report management endpoints:

    All endpoints require `current_user = Depends(get_current_active_user)` and `organization_id = Depends(get_current_organization_id)` for auth + tenant isolation. Use `@limiter.limit()` for rate limiting. Import dependencies from app.auth.dependencies.

    Endpoints:

    1. `POST /api/reports` — Save a new report
       - Request body: ReportSaveRequest (report_data dict, notes, project_id)
       - Rate limit: 30/minute
       - Calls service.save_report()
       - Returns ReportDetailResponse with 201 status
       - Handles ValueError (invalid report_data) -> 400

    2. `GET /api/reports` — List saved reports
       - Query params: city (str, optional), project_id (UUID, optional), search (str, optional), sort_by (Literal, default "updated"), sort_order (Literal, default "desc"), offset (int, default 0), limit (int, default 50)
       - Rate limit: 60/minute
       - Calls service.list_reports()
       - Returns ReportListResponse with reports + total count

    3. `GET /api/reports/cities` — Get distinct cities for filter dropdown
       - Rate limit: 60/minute
       - Returns list[str] of distinct city names

    4. `GET /api/reports/{report_id}` — Get full report details
       - Rate limit: 60/minute
       - Calls service.get_report()
       - Returns ReportDetailResponse (includes full report_data JSONB)

    5. `DELETE /api/reports/{report_id}` — Soft-delete a report
       - Rate limit: 30/minute
       - Calls service.soft_delete_report()
       - Returns {"message": "Report deleted", "report_id": str(id)} with 200

    6. `POST /api/reports/{report_id}/restore` — Restore a soft-deleted report
       - Rate limit: 30/minute
       - Calls service.restore_report()
       - Returns ReportDetailResponse

    7. `PATCH /api/reports/{report_id}/notes` — Update report notes
       - Request body: ReportUpdateNotes
       - Rate limit: 30/minute
       - Calls service.update_report_notes()
       - Returns ReportDetailResponse

    8. `PATCH /api/reports/{report_id}/project` — Assign report to project
       - Request body: ReportAssignProject
       - Rate limit: 30/minute
       - Calls service.assign_report_to_project()
       - Returns ReportDetailResponse

    9. `PUT /api/reports/{report_id}/refresh` — Update report with fresh data
       - Request body: ReportSaveRequest (fresh report_data)
       - Rate limit: 10/minute (triggers API calls)
       - Calls service.update_report_data()
       - Returns ReportDetailResponse
