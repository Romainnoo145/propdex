    **1. Create freshness detection service:**

    **backend/app/reports/freshness.py:**

    ```python
    async def check_report_freshness(
        report: SavedReport,
        organization_id: uuid.UUID,
        session: AsyncSession,
    ) -> dict:
    ```

    Logic:
    - Extract section_sources from report.report_data (list of SectionSourceInfo dicts)
    - For each section with a cached_at timestamp:
      - Query CachedAPIResponse for latest entry matching that section's source pattern
      - Use pattern: cache_key LIKE '%{section_identifier}%' or match by source name
      - Compare saved section's cached_at with latest cache's fetched_at
      - If latest cache is newer than saved snapshot by more than 24 hours (Claude's discretion: 24h threshold per research recommendation), flag as "update available"
    - Return ReportFreshnessResponse-compatible dict:
      ```python
      {
          "report_id": str(report.id),
          "has_updates": bool,
          "updated_sections": [
              {"section": "zoning", "saved_at": "...", "latest_at": "...", "age_hours": int}
          ]
      }
      ```

    Section-to-cache-key mapping:
    - "address" / "building" -> source contains "bag" or "pdok_locatieserver"
    - "cadastral" -> source contains "pdok_cadastral"
    - "zoning" -> source contains "dso"
    - "monuments" -> source contains "rce"
    - "ai_parsing" -> source contains "ai_parsed"

    Import: `from app.models.cached_response import CachedAPIResponse`, `from app.models.report import SavedReport`, standard sqlalchemy select imports.

    **2. Add PDF export and freshness endpoints to reports router:**

    Add these endpoints to the EXISTING `backend/app/reports/router.py` (created in Plan 02):

    **GET /api/reports/{report_id}/export/pdf** — Export report as PDF:
    - Rate limit: 10/minute (PDF generation is expensive)
    - Fetch report using service.get_report() (validates tenant + exists + not deleted)
    - Call `await asyncio.to_thread(generate_report_pdf, report.report_data, report.report_name)` — CRITICAL: use asyncio.to_thread to avoid blocking event loop (research pitfall #3)
    - Return StreamingResponse with media_type="application/pdf"
    - Set Content-Disposition header: `attachment; filename="rapport-{postcode_no_space}.pdf"`
    - Import `asyncio`, `io`, `StreamingResponse` from fastapi.responses

    **GET /api/reports/{report_id}/freshness** — Check data freshness:
    - Rate limit: 30/minute
    - Fetch report using service.get_report()
    - Call freshness.check_report_freshness()
    - Return ReportFreshnessResponse
