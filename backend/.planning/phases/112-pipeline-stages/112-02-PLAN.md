4. **Level 4 (parcel cards):** Replace the existing `(favorites ?? []).filter(...)` with filtering from `filteredFavorites` instead. The wijk_naam/gemeente_code matching stays the same, but the source array becomes `filteredFavorites`.

5. **Level 3 (wijk view):** When `activeStageFilter` is set, compute filtered wijk data from `filteredFavorites` instead of using `wijkenForGemeente` from the portfolio API. Create a new memo:
   ```
   const filteredWijkenForGemeente = useMemo(() => {
     if (!activeStageFilter || !selectedGemeenteCode) return wijkenForGemeente
     // Group filteredFavorites by wijk_naam for the selected gemeente
     const countMap = new Map<string, number>()
     for (const f of filteredFavorites) {
       if (f.gemeente_code !== selectedGemeenteCode) continue
       const key = f.wijk_naam ?? 'Onbekende wijk'
       countMap.set(key, (countMap.get(key) ?? 0) + 1)
     }
     // Convert to PortfolioWijkGroup format, hiding zero-count wijken
     return Array.from(countMap.entries())
       .filter(([, count]) => count > 0)
       .map(([wijk_naam, parcel_count]) => ({
         wijk_naam: wijk_naam === 'Onbekende wijk' ? null : wijk_naam,
         parcel_count,
       }))
   }, [activeStageFilter, selectedGemeenteCode, wijkenForGemeente, filteredFavorites])
   ```
   Pass `filteredWijkenForGemeente` to `<PortfolioWijkView wijken={...}>` instead of `wijkenForGemeente`.

6. **Level 2 (gemeente view):** When `activeStageFilter` is set, filter `gemeenteCardsForProvince` to only include gemeenten that have at least 1 filtered favorite, and override `total_count` with the filtered count. Create a memo:
   ```
   const filteredGemeenteCards = useMemo(() => {
     if (!activeStageFilter) return gemeenteCardsForProvince
     const countMap = new Map<string, number>()
     for (const f of filteredFavorites) {
       if (!f.gemeente_code) continue
       countMap.set(f.gemeente_code, (countMap.get(f.gemeente_code) ?? 0) + 1)
     }
     return gemeenteCardsForProvince
       .map((g) => ({ ...g, total_count: countMap.get(g.gemeente_code ?? '') ?? 0 }))
       .filter((g) => g.total_count > 0)
   }, [activeStageFilter, gemeenteCardsForProvince, filteredFavorites])
   ```
   Pass `filteredGemeenteCards` to `<PortfolioGemeenteView gemeenten={...}>`.

7. **Level 1 (province view):** When `activeStageFilter` is set, recompute `favoriteCountByProvince` using `filteredFavorites` instead of portfolio data. Update the existing `favoriteCountByProvince` memo to factor in `activeStageFilter`:
