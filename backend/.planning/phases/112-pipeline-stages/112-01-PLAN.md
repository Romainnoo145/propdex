1. In `useFavorites.ts`, add `useUpdatePipelineStage()` mutation hook below existing hooks:
   - `mutationFn`: PATCH `/api/parcels/favorites/${encodeURIComponent(parcelId)}/pipeline` with body `{ stage, afgerond_reden, notitie }`
   - `onMutate`: cancel `['favorites']` queries, snapshot previous, optimistically patch the matching favorite in cache. When stage is NOT Afgerond, set `afgerond_reden: null` and `notitie: null`.
   - `onError`: rollback to previous snapshot, `toast.error('Kan fase niet bijwerken')`
   - `onSettled`: invalidate `['favorites']` only (NOT `['portfolio']` -- portfolio has no pipeline data)
   - Generic types: `useMutation<FavoriteResponse, Error, { parcelId: string; stage: PipelineStage; afgerondReden?: string | null; notitie?: string | null }, { previousFavorites: FavoriteResponse[] | undefined }>`

2. Update `PipelineStagePill.tsx`:
   - Add optional `onClick?: () => void` and `afgerondReden?: string | null` to props interface
   - When `onClick` is provided, render `<button>` with `cursor-pointer hover:opacity-80 transition-opacity` instead of `<span>`
   - When `afgerondReden` is truthy and stage is `'Afgerond'`, render a sub-label below the pill: `<span className="text-[10px] text-neutral-400">{afgerondReden}</span>`
   - Export `STAGE_STYLES` as a named export (needed by PipelineStageSelector for consistent colors)

3. Create `PipelineStageSelector.tsx`:
   - Props: `{ currentStage: PipelineStage; parcelId: string; onClose: () => void; onAfgerond: () => void }`
   - Renders a floating `div` positioned absolutely (top-full mt-1 right-0) within a relative wrapper
   - Shows 5 stage options in order: Gesignaleerd, Onderzoek, Contact, Besluit, Afgerond
   - Each option: `<button>` with the stage's color from `STAGE_STYLES`, a checkmark icon (Lucide `Check`, size 14) when it matches `currentStage`
   - Clicking a non-Afgerond stage: calls `useUpdatePipelineStage().mutate({ parcelId, stage })` then `onClose()`
   - Clicking Afgerond: calls `onAfgerond()` then `onClose()` -- does NOT call mutate (modal handles that)
   - Outside-click detection: `useEffect` with `document.addEventListener('mousedown', handler)` on a ref, calling `onClose()` if click is outside
   - Styling: `bg-white rounded-xl shadow-lg border border-neutral-200 p-1 min-w-[180px] z-50`

4. Create `AfgerondModal.tsx`:
   - Props: `{ parcelId: string; isOpen: boolean; onClose: () => void }`
   - Uses `createPortal(content, document.body)` for z-index safety (same pattern as EigendomModal)
   - Content: backdrop `fixed inset-0 bg-black/40 z-[100]`, centered card `bg-white rounded-2xl p-6 max-w-md mx-auto mt-[20vh] space-y-4`
   - Title: "Perceel afronden" in `text-lg font-bold text-aura-ink`
   - Two radio-style buttons for reden: "Gekocht" and "Afgewezen" -- styled as selectable cards (`border-2 rounded-xl p-3`, selected gets `border-aura-amber bg-aura-amber/10`)
   - Optional textarea for notitie: `<textarea>` with placeholder "Optionele notitie..." max 500 chars, `rounded-xl border border-neutral-200 p-3 w-full resize-none`
   - Confirm button: disabled until reden is selected. `bg-aura-obsidian text-white rounded-full px-6 py-2.5 text-sm font-semibold`. On click: call `useUpdatePipelineStage().mutate({ parcelId, stage: 'Afgerond', afgerondReden: selectedReden, notitie })` then `onClose()`
   - Cancel button: `text-neutral-500 hover:text-neutral-700`. On click: `onClose()` without mutation
   - Do NOT render anything when `isOpen` is false
