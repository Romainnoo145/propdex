    **Backend — schemas.py:**
    Add a new Pydantic response model `FavoriteCentroidResponse` with fields:
    - `parcel_code: str`
    - `lon: float`
    - `lat: float`

    **Backend — router.py:**
    Add a new GET endpoint at `/favorites/centroids` on the existing `router` (prefix `/api/parcels`), so full path is `GET /api/parcels/favorites/centroids`.

    Authentication: `get_current_active_user` + `get_current_organization_id` (same pattern as `list_favorites`).
    Rate limit: `@limiter.limit("30/minute")`.

    SQL query using `sqlalchemy.text()`:
    ```sql
    SELECT
        pf.parcel_id AS parcel_code,
        ST_X(ST_Transform(ST_Centroid(pc.geometry), 4326)) AS lon,
        ST_Y(ST_Transform(ST_Centroid(pc.geometry), 4326)) AS lat
    FROM parcel_favorites pf
    JOIN parcel_cache pc
      ON pc.parcel_id = pf.parcel_id
     AND pc.organization_id = :org_id
    WHERE pf.user_id = :user_id
      AND pf.organization_id = :org_id
    ```

    Bind params: `{"org_id": str(organization_id), "user_id": str(current_user.id)}`.
    Return `list[FavoriteCentroidResponse]` by mapping `row._mapping` for each row.

    IMPORTANT: Both `parcel_favorites.parcel_id` and `parcel_cache.parcel_id` are Kadaster strings (e.g. "HTT02-A-1234") — the JOIN is on these string columns, NOT UUIDs. The `pc.organization_id = :org_id` filter is mandatory for multi-tenant isolation.

    **Frontend — useFavoriteCentroids.ts:**
    Create a new hook `useFavoriteCentroids()` that:
    1. Imports `useQuery` from `@tanstack/react-query`, `useAuth` from `@/lib/auth/useAuth`, `apiFetch` from `@/lib/api`
    2. Uses query key `['favorites', 'centroids']` — this automatically invalidates when `['favorites']` is invalidated (TanStack Query partial key matching)
    3. Fetches `GET /api/parcels/favorites/centroids` via `apiFetch`
    4. `staleTime: 5 * 60 * 1000` (same as favorites)
    5. `enabled: !!accessToken`
    6. Returns the query result typed as `FavoriteCentroid[]` where `FavoriteCentroid = { parcel_code: string; lon: number; lat: number }`

    Export the `FavoriteCentroid` type and `useFavoriteCentroids` hook.
